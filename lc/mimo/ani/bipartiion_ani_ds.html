📖 原理简介 · 匈牙利算法如何找到最大匹配？

二分图匹配：把左部节点和右部节点按边配对，每个节点最多与一条匹配边相邻。 匈牙利算法按顺序为每个左部节点 u 尝试匹配，用 DFS 找一条从 u 出发的增广路径——以未匹配点为起点和终点、中间边交替"未匹配/已匹配"的路径。 找到就翻转路径上的所有边，匹配数 +1；否则 u 本轮无法匹配，跳过。最终得到的就是最大匹配。

核心 1
增广路径
一条从未匹配左节点出发、到未匹配右节点结束的路径，
路径上的边交替为"未匹配 / 匹配"。
找到一条，匹配数就能 +1。
核心 2
DFS 递归找增广路径
dfs(u)：枚举 u 的邻居 v
· v 未匹配 → 匹配，返回成功
· v 已匹配给 u' → 递归 dfs(u')
用 visited[v] 避免死循环。
核心 3
"悔棋"—— 翻转匹配
当 v 已匹配给 u'，递归让 u' 去别处，成功的话
就把 v 从 u' 手中"抢过来"给 u。
这就是增广路径的"翻转"。
正确性
Berge 定理
匹配 M 是最大匹配 ⇔ 不存在增广路径。
匈牙利算法反复找增广路径，直到找不到为止。
复杂度
O(V·E)
每个左部节点做一次 DFS：O(E)
总复杂度 O(V·E)。
Dinic 可做到 O(E√V)，但代码复杂。
应用
典型场景
· 任务分配：工人 ↔ 任务
· 棋盘覆盖：多米诺骨牌
· 最小路径覆盖：DAG 路径覆盖
· 最小点覆盖：= 最大匹配（König）

🐍 Python 实现 · 匈牙利算法 邻接表 + DFS 增广路径 
"""
二分图最大匹配 · 匈牙利算法（Kuhn's Algorithm）。

问题：
    给定二分图 G = (L ∪ R, E)，求一个匹配 M ⊆ E，
    使得 M 中任意两条边不共享端点，且 |M| 尽可能大。

核心概念：增广路径（Augmenting Path）
    一条从"未匹配的左节点"出发，到"未匹配的右节点"结束的路径，
    路径上的边交替为"未匹配边"和"匹配边"。
    翻转路径上的所有边（未匹配↔匹配），匹配数 +1。

Berge 定理：
    匹配 M 是最大匹配 ⇔ G 中不存在关于 M 的增广路径。

复杂度：O(V · E)
"""


class Hungarian:
    def __init__(self, n_left, n_right, adj):
        self.n_left = n_left
        self.n_right = n_right
        self.adj = adj
        self.matchL = [-1] * n_left
        self.matchR = [-1] * n_right
        self.max_match = 0

    def _dfs(self, u, visited):
        # 从 u 出发找增广路径
        for v in self.adj[u]:
            if visited[v]:
                continue
            visited[v] = True

            # v 未匹配 → 直接匹配
            # 或 v 已匹配给 u2 → 递归让 u2 去找替代
            if self.matchR[v] == -1 or self._dfs(self.matchR[v], visited):
                self.matchR[v] = u
                self.matchL[u] = v
                return True
        return False

    def solve(self):
        for u in range(self.n_left):
            visited = [False] * self.n_right
            if self._dfs(u, visited):
                self.max_match += 1
        return self.max_match


if __name__ == '__main__':
    # 需要递归回溯才能找到最大匹配的教学图
    #   L1 - R1, R2
    #   L2 - R1
    #   L3 - R2, R3
    #   L4 - R3, R4
    n_left, n_right = 4, 4
    adj = [
        [0, 1],    # L1 → R1, R2
        [0],       # L2 → R1
        [1, 2],    # L3 → R2, R3
        [2, 3],    # L4 → R3, R4
    ]

    h = Hungarian(n_left, n_right, adj)
    result = h.solve()

    print(f'最大匹配数 = {result}')
    for u in range(n_left):
        if h.matchL[u] != -1:
            print(f'  L{u+1} — R{h.matchL[u]+1}')
        else:
            print(f'  L{u+1} 未匹配')
