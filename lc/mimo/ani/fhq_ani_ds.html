FHQ Treap（无旋 Treap）· 分裂 / 合并 / 增删 动画

两种分裂并列共存：split_by_key 按值域拆 · split_by_rank 按位置拆 · 无旋转

📖 原理简介 · 为什么 FHQ Treap 不需要旋转？

Treap = Tree + Heap。每个节点同时满足 BST 性质（key 左 < 根 < 右） 和 堆性质（prio 父小于子）。FHQ Treap 用 split + merge 两个操作取代旋转，代码更短、可持久化。它同时提供两种分裂方式，服务于不同场景： split_by_key 用于有序集合，split_by_rank 用于序列 / 区间。

核心 1
split_by_key —— 按值域拆
左树所有 key ≤ 阈值，右树 key > 阈值。
用途：有序集合（map / set）、按值查找。
核心 2
split_by_rank —— 按位置拆
左树是中序前 k 小，右树是剩余节点。
用途：区间操作（翻转、区间加）、可持久化序列。
核心 3
merge —— 合树
前提：左树 key 全部 < 右树 key。
比较根 prio，小者当新根，另一棵递归接入。
性质 1
两者不冲突
它们依据不同的维度（值域 / 位置），可以共存于同一棵树。 同一个节点既能在 split_by_key 里按 key 归类，也能在 split_by_rank 里按位置归类。
性质 2
组合成一切操作
插入：split → 新节点 → merge
删除：split 三段 → 丢弃中间 → merge
区间翻转：split_by_rank 出区间 → 打标记 → merge
性质 3
可持久化
split / merge 只修改路径上 O(log N) 个节点。 复制路径节点即得历史版本，旋转 Treap 做不到。
基本操作
值

按 key 分裂 key = 左树所有 key ≤ 输入值，右树所有 key > 输入值
按 size 分裂 k = 左树中序前 k 小，右树剩余节点
