📖 原理简介 · 二叉堆为什么能用数组存？

二叉堆是一棵完全二叉树，除了最后一层外每一层都填满，最后一层从左到右连续填。 这个结构上的约束使得它可以用数组存储：下标 i 的父节点是 ⌊i/2⌋， 左孩子是 2i，右孩子是 2i+1。堆同时满足堆性质：大根堆中 a[parent] ≥ a[i]，小根堆反之。所有操作都只沿一条从根到叶的路径修改， 路径长度就是树高 O(log N)，所以插入和弹出都是 O(log N)。

核心 1
完全二叉树 = 数组
用数组 a[1..N] 存储，父子关系由下标算出：
· parent(i) = ⌊i/2⌋
· left(i) = 2i，right(i) = 2i+1
不需要显式指针，省空间也快。
核心 2
堆性质：父 ≥ 子（或 ≤）
大根堆：a[parent] ≥ a[i]，堆顶最大
小根堆：a[parent] ≤ a[i]，堆顶最小
只约束父子关系，兄弟之间没有顺序要求。
核心 3
上浮 sift-up 与 下沉 sift-down
上浮：与父节点比较，违反堆性质就交换，一路向上。
下沉：与较小的孩子比较，违反就交换，一路向下。
两者都是 O(log N)，是堆所有操作的基础。
操作
插入：先放末尾，再上浮
1. 把新元素放到数组末尾 a[++n]
2. 沿父链向上：若 a[i] 违反堆性质，与 a[parent] 交换
3. 直到根或满足堆性质
操作
弹出堆顶：末尾顶上，再下沉
1. 记录 a[1]，把 a[n] 移到堆顶，n--
2. 沿较小孩子向下：若违反堆性质就交换
3. 直到叶子或满足堆性质
进阶
建堆 O(N) 与堆排序
建堆：从最后一个非叶节点开始，逐个下沉，O(N)
堆排序：建堆 + n 次弹出，O(N log N)，原地排序
优先队列：堆的典型应用
基本 类型 堆大小 N = 0 蓝色圆形是树视图，下方灰色条带是数组视图 a[1..n]
