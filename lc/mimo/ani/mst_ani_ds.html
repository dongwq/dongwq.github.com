📖 原理简介 · 两种算法如何找到最小生成树？

最小生成树（MST）是一棵连接图中所有节点、边权和最小的树。 两种经典算法都基于贪心 + 割性质： Prim 从某个起点开始"长大"，每次选一条连接"树内与树外"的最小边； Kruskal 把所有边按权排序，从小到大逐条尝试，用并查集避免成环。 两者都保证最优，但适用场景不同。

核心 1
Prim：从点扩展 O(E log V)
维护已加入树的点集 S。
每轮从"一端在 S、另一端不在 S"的边中选最小的一条。
适合稠密图（用邻接矩阵可做到 O(V²)）。
核心 2
Kruskal：从边合并 O(E log E)
所有边按权排序，逐条检查：
· 两端不在同一集合 → 加入
· 已连通 → 跳过（会成环）
用并查集维护连通性，适合稀疏图。
核心 3
割性质：贪心为什么正确
对任意割（把点集分成两部分），
横跨割的最小边一定属于某棵 MST。
Prim 每步都在"树内-树外"这个割上取最小边，Kruskal 每步都在"两集合"这个割上取最小边。
不变量
两者都保证最优
Prim 维护"一棵树 + 若干未访问点"
Kruskal 维护"森林 + 逐步合并成树"
最终都得到 n−1 条边、总权最小、无环、连通。
比较
什么时候用哪个
· 稀疏图 / 边少 → Kruskal（排序方便）
· 稠密图 / 边多 → Prim（堆优化或矩阵）
· 需要中间过程查询 → Prim 更自然
· 需要处理"动态加边" → Kruskal 更灵活
应用
典型场景
· 网络设计：用最少光缆连接所有城市
· 聚类分析：单链接聚类
· 近似 TSP：MST 双倍遍历是 2-近似
· 图像分割：基于 MST 的区域合并
· STP 协议：交换机间生成树防环

"""
最小生成树（Minimum Spanning Tree）—— Prim + Kruskal。

给定带权无向图 G = (V, E)，选出一棵包含所有点、
总权重最小的树（恰好 |V|-1 条边）。

两种经典算法都基于割性质（Cut Property）：
    对任意把 V 分成两部分的割，横跨割的最小边
    一定属于某棵最小生成树。

Prim    —— 从点出发，每步把"树外最近的点"加入树
Kruskal —— 从边出发，按权排序，用并查集避免成环
"""

import heapq


# ============================================================
# 算法 1：Prim（堆优化）—— O(E log V)
# ============================================================
def prim(n, adj, start=0):
    """
    adj[u] = [(v, w), ...]
    返回 (mst_weight, mst_edges)，mst_edges 是 [(u, v, w), ...]
    """
    INF = float('inf')
    in_tree = [False] * n
    dist = [INF] * n
    parent = [-1] * n

    dist[start] = 0
    pq = [(0, start)]
    mst_edges = []
    total = 0

    while pq:
        d, u = heapq.heappop(pq)
        if in_tree[u]:
            continue
        in_tree[u] = True
        total += d
        if parent[u] != -1:
            mst_edges.append((parent[u], u, d))

        for v, w in adj[u]:
            if not in_tree[v] and w < dist[v]:
                dist[v] = w
                parent[v] = u
                heapq.heappush(pq, (w, v))

    return total, mst_edges


# ============================================================
# 算法 2：Kruskal（并查集）—— O(E log E)
# ============================================================
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True


def kruskal(n, edges):
    """
    edges = [(u, v, w), ...]
    返回 (mst_weight, mst_edges)
    """
    edges_sorted = sorted(edges, key=lambda e: e[2])
    dsu = DSU(n)
    mst_edges = []
    total = 0

    for u, v, w in edges_sorted:
        if dsu.union(u, v):
            mst_edges.append((u, v, w))
            total += w
            if len(mst_edges) == n - 1:
                break

    return total, mst_edges

# ============================================================
if __name__ == '__main__':
    # 7 个节点、10 条边的教学图
    n = 7
    edges = [
        (0, 1, 2),  # A-B
        (0, 3, 1),  # A-D
        (1, 2, 3),  # B-C
        (1, 3, 4),  # B-D
        (1, 4, 5),  # B-E
        (2, 4, 6),  # C-E
        (3, 4, 7),  # D-E
        (4, 5, 3),  # E-F
        (4, 6, 2),  # E-G
        (5, 6, 8),  # F-G
    ]

    # 邻接表
    adj = [[] for _ in range(n)]
    for u, v, w in edges:
        adj[u].append((v, w))
        adj[v].append((u, w))

    print('=== Prim（从 A 出发） ===')
    w1, m1 = prim(n, adj, start=0)
    print(f'MST 总权重 = {w1}')
    for u, v, w in m1:
        print(f'  {chr(65+u)} — {chr(65+v)}  (w={w})')

    print()
    print('=== Kruskal ===')
    w2, m2 = kruskal(n, edges)
    print(f'MST 总权重 = {w2}')
    for u, v, w in m2:
        print(f'  {chr(65+u)} — {chr(65+v)}  (w={w})')

    assert w1 == w2, '两种算法应得到相同的总权重'
    print('\n✔ 两种算法总权重一致')
