Tarjan 算法 · 强连通分量（SCC）动画

一次 DFS · dfn[u] 时间戳 · low[u] 能回溯到的最早时间 · 栈维护候选节点 · 单次 O(V+E)

📖 原理简介 · dfn / low / 栈，一个 DFS 求出所有 SCC

Tarjan 算法只做一次 DFS，用三个数据结构识别所有强连通分量： dfn[u] 记录 u 第一次被访问的时间戳；low[u] 记录 u 及其子树能回溯到的最早 dfn； stack 保存"当前还没归属任何 SCC"的节点。 对 u 的每条出边 u→v：若 v 未访问，递归后 low[u] = min(low[u], low[v])； 若 v 已访问且在栈中，则 low[u] = min(low[u], dfn[v])。 当 dfn[u] == low[u] 时，说明 u 是某个 SCC 的"根"，把栈中 u 及其以上的节点全部弹出，它们构成一个 SCC。

核心 1
dfn 与 low
dfn[u]：u 第一次被访问的时间戳
low[u]：u 及其子树能通过至多一条回边到达的最早 dfn
两者相等时，u 是 SCC 的根
核心 2
栈的作用
按访问顺序入栈。
只有"还在栈中"的节点才能作为 low 更新的候选（否则跨 SCC）。
当 u 是根时，从栈顶弹出到 u，这些点构成一个 SCC。
核心 3
三种边
树边：u→v 且 v 未访问，递归
回边：u→v 且 v 在栈中（同一 SCC 内）
横叉边：u→v 且 v 已访问但不在栈中（跨 SCC）
只有前两种会影响 low
为什么
dfn[u] == low[u] 就是根
如果 u 的子树能回到比 u 更早访问的节点，
那 u 一定和那些节点在同一 SCC 里，u 不是根。
反之，若 low[u] == dfn[u]，说明"回不去"更早的点 → u 是 SCC 的入口。
复杂度
O(V + E)
每个点入栈出栈各一次，每条边检查一次。
线性时间，是求 SCC 的最优算法。
Kosaraju 需要两次 DFS + 反图，也是 O(V+E) 但常数更大。

📚 知识模块 · Tarjan 的六大场景 同一套 dfn/low 框架，不同判据

🐍 Python 实现 · Tarjan 三大经典应用 SCC + 割点 + 割边 
"""
Tarjan 算法 · 三大经典应用。

同一套 dfn / low 框架，通过不同的判断条件解决不同问题：

    SCC（有向图）     dfn[u] == low[u]  → u 是 SCC 的根
    割点（无向图）    u 是根: 有 ≥ 2 个 DFS 孩子
                       u 非根: 存在孩子 v 使 low[v] >= dfn[u]
    割边（无向图）    存在孩子 v 使 low[v] > dfn[u]  → 边 u-v 是桥

核心变量：
    dfn[u]   时间戳，u 第一次被访问的时间
    low[u]   u 及其子树能回溯到的最早 dfn
    timer    全局时间戳计数器
"""

import sys
sys.setrecursionlimit(300000)


# ============================================================
# 应用 1：有向图强连通分量（SCC）
# ============================================================
def tarjan_scc(n, adj):
    """
    求有向图的所有强连通分量。

    返回 scc_id[v] = v 所属的 SCC 编号（0-based），scc_count。
    """
    dfn = [-1] * n
    low = [0] * n
    scc_id = [-1] * n
    in_stack = [False] * n
    stack = []
    timer = [0]
    scc_count = [0]

    def dfs(u):
        dfn[u] = low[u] = timer[0]
        timer[0] += 1
        stack.append(u)
        in_stack[u] = True

        for v in adj[u]:
            if dfn[v] == -1:                      # 树边
                dfs(v)
                low[u] = min(low[u], low[v])
            elif in_stack[v]:                     # 回边（同 SCC 内）
                low[u] = min(low[u], dfn[v])
            # 否则是横叉边（跨 SCC），忽略

        # u 是某个 SCC 的根
        if dfn[u] == low[u]:
            while True:
                x = stack.pop()
                in_stack[x] = False
                scc_id[x] = scc_count[0]
                if x == u:
                    break
            scc_count[0] += 1

    for u in range(n):
        if dfn[u] == -1:
            dfs(u)

    return scc_id, scc_count[0]


# ============================================================
# 应用 2：无向图割点（Articulation Point）
# ============================================================
def tarjan_cut_vertex(n, adj):
    """
    求无向图的所有割点。返回 cut[v] = True/False。

    割点定义：去掉该点后，图的连通分量数增加。
    """
    dfn = [-1] * n
    low = [0] * n
    cut = [False] * n
    timer = [0]

    def dfs(u, parent):
        dfn[u] = low[u] = timer[0]
        timer[0] += 1
        children = 0

        for v in adj[u]:
            if v == parent:
                continue                          # 跳过父节点（简单图）
            if dfn[v] == -1:
                children += 1
                dfs(v, u)
                low[u] = min(low[u], low[v])

                # 非根节点：孩子无法回溯到 u 之上
                if parent != -1 and low[v] >= dfn[u]:
                    cut[u] = True
            else:                                 # 回边
                low[u] = min(low[u], dfn[v])

        # 根节点特判：至少 2 个孩子才是割点
        if parent == -1 and children >= 2:
            cut[u] = True

    for u in range(n):
        if dfn[u] == -1:
            dfs(u, -1)
    return cut


# ============================================================
# 应用 3：无向图割边 / 桥（Bridge）
# ============================================================
def tarjan_bridge(n, edges):
    """
    求无向图的所有割边（桥）。返回 list of (u, v)。

    割边定义：去掉该边后，图的连通分量数增加。
    """
    adj = [[] for _ in range(n)]
    for i, (u, v) in enumerate(edges):
        adj[u].append((v, i))
        adj[v].append((u, i))

    dfn = [-1] * n
    low = [0] * n
    timer = [0]
    bridges = []

    def dfs(u, parent_edge):
        dfn[u] = low[u] = timer[0]
        timer[0] += 1

        for v, eid in adj[u]:
            if eid == parent_edge:
                continue                          # 不走同一条边回去
            if dfn[v] == -1:
                dfs(v, eid)
                low[u] = min(low[u], low[v])
                if low[v] > dfn[u]:               # v 无法回溯到 u 或更早
                    bridges.append((u, v))
            else:
                low[u] = min(low[u], dfn[v])

    for u in range(n):
        if dfn[u] == -1:
            dfs(u, -1)
    return bridges

# 演示
# ============================================================
if __name__ == '__main__':
    # -------- SCC 演示 --------
    # 1 → 2 → 1 (SCC1)
    #      ↓
    # 3 → 4 → 3 (SCC2)
    #      ↓
    #      5    (SCC3)
    n_scc = 5
    adj_scc = [
        [1],       # 0(1) → 1(2)
        [0, 2],    # 1(2) → 0(1), 2(3)
        [3],       # 2(3) → 3(4)
        [2, 4],    # 3(4) → 2(3), 4(5)
        [],        # 4(5) 无出边
    ]
    scc_id, cnt = tarjan_scc(n_scc, adj_scc)
    print('=== Tarjan SCC ===')
    print('SCC 数量 =', cnt)
    for i in range(cnt):
        members = [v + 1 for v in range(n_scc) if scc_id[v] == i]
        print(f'  SCC{i}: {members}')

    # -------- 割点演示 --------
    n_cut = 6
    edges_cut = [(0, 1), (1, 2), (2, 3), (3, 4), (1, 5)]
    adj_cut = [[] for _ in range(n_cut)]
    for u, v in edges_cut:
        adj_cut[u].append(v)
        adj_cut[v].append(u)
    cut = tarjan_cut_vertex(n_cut, adj_cut)
    print()
    print('=== Tarjan 割点 ===')
    print('割点 =', [i + 1 for i in range(n_cut) if cut[i]])

    # -------- 割边演示 --------
    n_br = 6
    edges_br = [(0, 1), (1, 2), (2, 3), (3, 4), (1, 5)]
    bridges = tarjan_bridge(n_br, edges_br)
    print()
    print('=== Tarjan 割边 ===')
    print('桥 =', [(u + 1, v + 1) for u, v in bridges])
