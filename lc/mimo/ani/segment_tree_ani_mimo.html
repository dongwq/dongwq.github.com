🧭 线段树基本原理 先读这里 问题 → 思想 → 结构 → 操作 → 复杂度 · 点击可收起

线段树（Segment Tree）是一棵每个节点对应一个区间的二叉树：节点 u 负责区间 [l,r]，它的值就是 a[l..r] 的聚合结果（和、最值、gcd……）。 它把「区间查询」和「单点修改」两类操作同时做到 O(log N)，代价是 O(N) 的空间和建树时间。

1要解决的问题
在数组 a[1..N] 上反复交替两种操作：修改 a[i]、 询问 [l,r] 的聚合值。两者的快慢总是互相牵制：
朴素做法查询 O(N) · 修改 O(1)
前缀和查询 O(1) · 修改 O(N)
线段树查询 O(log N) · 修改 O(log N)
2核心思想：分治 + 预处理
节点 u 管 [l,r]，用 mid = (l+r) >> 1 切成 [l,mid] 与 [mid+1,r] 交给两个孩子。孩子算好后，父亲只要 tree[u] = op(tree[2u], tree[2u+1]) 就得到整段的值。 于是查询时把目标区间拆成若干「整块」，每块的值早就存在节点里，直接合并即可。
3节点与下标
用数组存完全二叉树：父 u>>1、 左孩子 2u、右孩子 2u+1。 每个节点记录 [l,r]；叶子满足 l==r，tree[u]=a[l]。 根是 1，N=8 时共 2N−1 = 15 个节点，深度 log₂N = 3。 层与层之间用带箭头的虚线相连，箭头一律由孩子指向父亲。
4三个基本操作 + 懒标记
build 建树：叶子填 a[i]，内部节点自底向上合并，O(N)。
update 单点更新：沿 mid 走到叶子，改完一路回溯重算，O(log N)。
query 区间查询：不相交→跳过、完全包含→采纳、部分重叠→继续分割，O(log N)。
range_add 区间修改：打懒标记，只改 O(log N) 个节点。
例子：N=8 时，查询 [3,7] 是怎么拆的
根 [1,8] 部分重叠 → 继续分割 → [3,4] 整块采纳 [5,6] 整块采纳 [7,7] 整块采纳 [1,2] 不相交跳过 [8,8] 不相交跳过
结果 = op( op(a[3],a[4]), op(a[5],a[6]), a[7] )。 被「整块采纳」的节点互不相交、合起来正好是 [3,7]，数量不超过 2·log N —— 这就是线段树查询 O(log N) 的来源。
