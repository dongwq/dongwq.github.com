Splay 树 · 自平衡二叉搜索树 动画

每次访问后把节点旋转到根（splay）· 三种旋转 Zig / Zig-Zig / Zig-Zag · 分摊复杂度 O(log N)

📖 原理简介 · 为什么"访问即提升到根"能自平衡？

Splay 树的核心思想只有一句话：每次访问（查找 / 插入 / 删除）后，都把被访问的节点通过旋转一路送到根。 这个把节点提升到根的过程叫 splay。它带来两个关键好处： （1）被频繁访问的节点会停留在离根很近的地方，所以有访问局部性的场景下 Splay 树极快； （2）虽然单次操作最坏可能 O(N)，但所有这些"贵操作"是摊销的——分摊复杂度 O(log N)。 Splay 只有三种旋转情形：Zig、Zig-Zig、Zig-Zag。

核心 1
Zig：x 的父是根
x 的父 p 已是根，直接对 p 做一次单旋。
· x 是 p 的左孩子 → 右旋 p
· x 是 p 的右孩子 → 左旋 p
结束——x 就位。
核心 2
Zig-Zig：同向双旋
x 和 p 同为"左-左"或"右-右"。
先旋 g，再旋 p（从下往上走）。
注意顺序：和 AVL 的双旋不同，不是先旋 x。
核心 3
Zig-Zag：异向双旋
x 和 p 异向（"左-右"或"右-左"）。
先旋 p，再旋 g——实际上是对 x 连续做两次单旋。
最终 x 会升到 g 的位置。
操作
find(x)：查完就 splay
按 BST 规则找到 x，
然后 splay(x) 把 x 提到根。
下次再查 x 就是 O(1)。
操作
insert(x)：插入后 splay
按 BST 规则插入到叶子位置，
然后 splay(新节点) 把它提到根。
最近插入的元素访问最快。
操作
delete(x)：先 splay 再合并
splay(x) 到根，
找左子树最大值 splay 到左子树根，
把右子树挂上去即可。
基本 节点数 N = 0 蓝色圆形是节点，下方小徽章是 size（子树节点数），用于第 k 小 / 区间操作
查找 key = 找到后把目标节点旋转到根
插入 key = 按 BST 插入到叶子，然后 splay 到根
删除 key = splay 到根 → 找左子树最大值 splay → 挂右子树
