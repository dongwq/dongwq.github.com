从根到节点的路径 = 一个字符串前缀 · is_end 标记完整的单词 · 查找复杂度 O(L)（L 为串长）

📖 原理简介 · Trie 用"路径"存字符串

Trie（前缀树 / 字典树）是一棵多叉树：根节点为空，每条边代表一个字符， 从根到某个节点的路径拼起来就是一个字符串前缀。 每个节点额外带一个 is_end 标记，表示"路径到这里是一个完整的单词"。 所有操作——插入、查找、前缀判断、删除——都是沿着字符逐层下降， 时间只与字符串长度 L 有关，与字典里有多少单词无关。

核心 1
节点 = 一个字符
每个节点只存一个字符（根为空）。
边连接父子节点，代表"下一个字符"。
从根往下走的路径 = 一个字符串前缀。
核心 2
is_end 标记单词结尾
路径 c → a → t 存在，并不能说明 "cat" 是单词——
还需在 t 节点上有 is_end = True。 这个标记区分了"前缀"和"完整单词"。
核心 3
共享前缀压缩空间
"cat"、"car"、"card"、"care" 共享路径 c-a-r，
只在分叉处才新建节点。
相同前缀越多，节省的空间越多。
操作
insert(word)
从根开始逐字符下降：
· 子节点已有该字符 → 直接下去
· 没有 → 新建节点
走完所有字符后，在末尾节点标记 is_end = True
操作
search / startsWith
search：沿路径走到末尾，路径存在 且末尾节点 is_end
startsWith：只要路径存在即可（不要求 is_end）
两者复杂度都是 O(L)
操作
delete(word)
先走到末尾节点，把 is_end 改为 False。
如果该节点没有子节点，可以向上回退并逐层删除"只剩自己"的节点。
不能删别的单词的前缀节点。
基本 节点数：0 单词数：0 初始词库：cat, car, card, care, dog, do　金色双圈节点 = 单词结尾（is_end）
insert word = 逐字符下降，遇到不存在的字符就新建节点，末尾标记 is_end
search word = 路径存在 且末尾 is_end = True 才算找到
startsWith prefix = 只要路径存在即返回 True，不要求 is_end
delete word = 先改 is_end 为 False；若末尾节点无子节点，则向上回退删除
