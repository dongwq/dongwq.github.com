图的连通性 · 三大范式 动画

无向图 · 连通分量 = 路径诱导的等价类 · 三种算法：BFS/DFS 染色 · 并查集 · lowlink

📖 原理简介 · 连通性问题到底在问什么？

无向图上定义关系 u ~ v ⇔ 存在 u 到 v 的路径。它是自反、对称、传递的，所以是一个等价关系， 而连通分量正是它的等价类。这个抽象立刻告诉我们所有算法的本质任务： 判定两点是否同属一类 + 把两个类合并。 由此长出三大范式：BFS/DFS 染色（从源点扩散染色）、并查集（边一条条并类）、lowlink（用 dfn/low 识别割点和桥）。 它们是静态连通性问题的三把钥匙，分别对应"一次性全图""流式加边""脆弱性分析"三类场景。

范式 1
BFS/DFS 染色 — O(V+E)
任取未染色点 s，从它能到达的所有点必与它同类，
一次性染成颜色 k，再找下一个未染色点。
特点：一次拿到完整分量信息；迭代版防爆栈。
范式 2
并查集 — O((V+E)α)
每看到一条边就合并两端所在集合。
按秩合并 + 路径压缩 → 均摊 O(α(n))，α ≤ 4。
特点：边可流式输入，不必存图。
范式 3
lowlink — O(V+E)
dfn[u] 记录访问时间，low[u] 记录能回溯到的最早 dfn。
割点判据：根需 ≥ 2 孩子；非根需 low[v] ≥ dfn[u]。
桥判据：low[v] > dfn[u]。
统一
两大范式的根本区别
BFS/DFS：先看到完整图，一次性求出答案
并查集：边一条条来，在线维护"谁和谁连通"
选型：静态、要每个点的归属 → 染色；
流式、只看"是否连通 + 个数" → 并查集
数学
三个等价视角
环秩：m − n + c，其中 c = 分量个数
拉普拉斯：特征值 0 的重数 = 分量个数
闭包：连通分量 = 边集生成的传递闭包

🐍 Python 实现 · 连通性三件套 BFS + DSU + lowlink 
"""
图的连通性 · 三大范式。

无向图连通分量 = 路径诱导的等价类。
求它主要有三条路：
    1. BFS/DFS 染色  O(V+E)
    2. 并查集 DSU     O((V+E)α)
    3. lowlink        O(V+E)（求桥 / 割点）

另附：有向图 SCC（Tarjan，一次 DFS）。
"""

from collections import deque


# ============================================================
# 范式 1：BFS 染色求连通分量
# ============================================================
def connected_components_bfs(n, adj):
    """返回 comp[v] = v 所属分量编号（0-based），以及分量个数。"""
    comp = [-1] * n
    cnt = 0
    for s in range(n):
        if comp[s] != -1:
            continue
        comp[s] = cnt
        q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if comp[v] == -1:
                    comp[v] = cnt
                    q.append(v)
        cnt += 1
    return comp, cnt


# ============================================================
# 范式 2：并查集
# ============================================================
class DSU:
    """
    按秩合并 + 路径压缩的并查集。
    均摊 O(α(n))，α 是 Ackermann 反函数，α(n) ≤ 4。
    """

    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n
        self.count = n               # 当前集合个数

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]     # 路径减半
            x = self.p[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.r[ra] < self.r[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.r[ra] == self.r[rb]:
            self.r[ra] += 1
        self.count -= 1
        return True

    def num_components(self):
        return self.count


def connected_components_dsu(n, edges):
    """
    returns (comp, cnt)
    最后按根归类；n - 成功合并次数 = 分量数（环秩相关的核心恒等式）。
    """
    dsu = DSU(n)
    for u, v in edges:
        dsu.union(u, v)

    root_to_id = {}
    comp = [-1] * n
    for v in range(n):
        r = dsu.find(v)
        if r not in root_to_id:
            root_to_id[r] = len(root_to_id)
        comp[v] = root_to_id[r]
    return comp, dsu.num_components()


# ============================================================
# 范式 3：lowlink 求桥 & 割点
# ============================================================
def tarjan_bridges_articulations(n, edges):
    """
    求无向图的桥和割点。
    返回 (bridges, articulations)，bridges 是边列表，articulations 是点列表。
    """
    adj = [[] for _ in range(n)]
    for eid, (u, v) in enumerate(edges):
        adj[u].append((v, eid))
        adj[v].append((u, eid))

    dfn = [-1] * n
    low = [0] * n
    timer = [0]
    bridges = []
    art = [False] * n

    def dfs(u, pe):
        dfn[u] = low[u] = timer[0]
        timer[0] += 1
        children = 0
        for v, eid in adj[u]:
            if eid == pe:            # 用边编号跳过父边 —— 重边关键
                continue
            if dfn[v] == -1:
                children += 1
                dfs(v, eid)
                low[u] = min(low[u], low[v])
                if low[v] > dfn[u]:
                    bridges.append((u, v))
                if pe != -1 and low[v] >= dfn[u]:
                    art[u] = True
            else:
                low[u] = min(low[u], dfn[v])
        if pe == -1 and children >= 2:
            art[u] = True

    for s in range(n):
        if dfn[s] == -1:
            dfs(s, -1)
    return bridges, [i for i in range(n) if art[i]]


# ============================================================
# 附加：有向图 SCC（Tarjan，一次 DFS）
# ============================================================
def tarjan_scc(n, adj):
    dfn = [-1] * n
    low = [0] * n
    in_stk = [False] * n
    stk = []
    timer = [0]
    scc_id = [-1] * n
    scc_cnt = [0]

    def dfs(u):
        dfn[u] = low[u] = timer[0]
        timer[0] += 1
        stk.append(u)
        in_stk[u] = True
        for v in adj[u]:
            if dfn[v] == -1:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif in_stk[v]:
                low[u] = min(low[u], dfn[v])   # 用 dfn[v] 而非 low[v]
        if dfn[u] == low[u]:
            while True:
                x = stk.pop()
                in_stk[x] = False
                scc_id[x] = scc_cnt[0]
                if x == u:
                    break
            scc_cnt[0] += 1

    for s in range(n):
        if dfn[s] == -1:
            dfs(s)
    return scc_id, scc_cnt[0]

    for u, v in edges:

        adj[v].append(u)

    print('=== BFS 染色 ===')
    comp, c = connected_components_bfs(n, adj)
    print('分量数 =', c)
