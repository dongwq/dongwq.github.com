为什么需要它

数组上反复问「l 到 r 的和是多少」，同时还要改某个位置。朴素做法各占一头，没有一个两全。

FIG.02 · 同一个 query(7)，访问次数从 7 掉到 3
THE TRADE-OFF四种做法的取舍
单点改区间求和
暴力累加O(1)O(n)
前缀和数组O(n)O(1)
分块O(1)O(√n)

KEY IDEA把前缀和分层缓存

前缀和数组「改一下要重算一大片」。树状数组把前缀和切成 log n 层， 改和查都只跨几层，不碰整片。

◆ 用空间换时间：多一层缓存，就少一半扫描

定义与术语

两个数组：a[] 存值，c[] 存一小段前缀的和。整个结构只有一条定义。

FIG.03 · c[6] 只管 a[5..6] 这一小段，不管全部
VOCABULARY五个术语
原数组
a[1..n] · 真实数值
树数组
c[1..n] · 分段前缀和
lowbit
i & -i · i 的管辖长度
单点修改
给 a[i] 加一个值
区间求和
a[l..r] 的总和
DEFINITION唯一的一条定义
c[i] = Σ a[i − lowbit(i) + 1 .. i]

右端点恒为 i，长度恒为 lowbit(i)。其它一切结论都是它的推论。

◆ 下标从 1 开始 · 约定 c[0] = 0 作哨兵
04

lowbit：一句话 i & -i

取 i 二进制下最低位的 1，它就是 c[i] 管辖的元素个数。整个结构全靠这一个位运算。

FIG.04 · 补码取反加一，恰好只留下最低位那个 1
WHY IT WORKS为什么补码能行

−i = ~i + 1。低位的 0 遇到进位全变 0， 最低位那个 1 变 0 后被进位重新点亮，更高位全部翻转回去。与 i 一与，只剩这一位。

取值
只能是 1, 2, 4, 8, …
含义
c[i] 管辖 lowbit(i) 个连续元素
跳步
查 i −= lowbit · 改 i += lowbit
特例
lowbit(0) = 0，正好作查询循环终点
TAB.04 · 前十二个 lowbit 的取值

06

查询 query：向左跳

要算 a[1..i]，就把覆盖这段的几个 c 加起来。跳步方向向左。

7—(−1)→6—(−2)→4—(−4)→0 共 3 步
FIG.06 · 三段无缝拼成 a[1..7]，一段不多一段不少
WHY LEFT为什么向左

已取到的区间一直在 i 的右边，剩下的空缺只能往左补。

第一步
c[i] 补上最后一段
下一步
跳到 i − lowbit(i)，再补一段
结束
i = 0 时 1..原 i 已覆盖全
EXACTLY k STEPS跳几次？

跳的次数 = i 的二进制中 1 的个数（popcount）。 每个 1 恰好贡献一段，所以不多不少，最多 ⌊log₂ n⌋ + 1 次。

query(7)=3 步　query(8)=1 步　 query(15)=4 步

修改 update：向右跳

改 a[i]，就要把所有覆盖了 i 的 c 一起改。这些 c 的下标向右递增。

3—(+1)→4—(+4)→8—(+8)→16 停 共 3 步
FIG.07 · 恰好这三个 c 覆盖了 a[3]，一个不多一个不少
WHY RIGHT为什么向右

只有下标 大于 i 的 c 才可能覆盖到 i；继续往右，段越来越宽， 直到 越界就说明没有更多的 c 了。

序列
i, i+lowbit(i), …
终止
i > n 时越界即停
代价
同样 O(log n) 步
SYMMETRY一张对称表
方向步长用途
query向左i −= lowbit取和
update向右i += lowbit改值
◆ 通常根本不存 a[]，只存 c[]；a 只是概念上的
08

区间查询 与 建树

区间和只是两个前缀和相减；建树有 O(n) 的写法。

FIG.08 · 两段前缀相减，剩下的就是 [4..7]
BUILD · NAIVE朴素建树

对每个 i 做一次 update(i, a[i])，共 O(n log n)。 数据规模 10⁶ 时约 2×10⁷ 次操作，能过但不优雅。

BUILD · LINEARO(n) 建树
for(int i=1;i<=n;i++){
  c[i] += a[i];
  int j = i + (i & -i);     // 父节点
  if(j <= n) c[j] += c[i];
}

每个 i 只把自己的和往上推一层，总代价恰好 n 次。

◆ l = 1 时 sum(0) = 0，循环天然结束，无需特判

11

模板代码

两行循环，背下来即可。下标从 1 开始，这是全篇唯一必须记住的约定。

C++ · 单点改 + 区间和
const int N = 1e6 + 5;
int n, c[N];                    // 只需 c，不必存 a

void add(int i, int v){          // 单点加
  for(; i <= n; i += i & -i) c[i] += v;
}

int sum(int i){                   // 前缀和 1..i
  int s = 0;
  for(; i > 0; i -= i & -i) s += c[i];
  return s;
}

int ask(int l, int r){            // 区间和
  return sum(r) - sum(l - 1);
}
O(n) BUILD
c[i] += a[i]; int j = i+(i&-i); if(j<=n) c[j] += c[i];
PYTHON · 同一套逻辑
c = [0] * (n + 1)

def add(i, v):            # 单点加
    while i <= n:
        c[i] += v
        i += i & -i

def ask(i):              # 前缀和 1..i
    s = 0
    while i > 0:
        s += c[i]
        i -= i & -i
    return s

def rng(l, r):            # 区间和
    return ask(r) - ask(l - 1)
0-INDEXED
下标从 0 起时要换成 (i+1) & -(i+1)，容易写错，建议统一 1-indexed
SIZE
数组至少开 n + 2；要写 c[r+1] 的场合开 n + 5 更稳

扩展：区间加 + 区间和

把「区间加」交给差分数组，再用两个树状数组把前缀和公式凑出来。

FIG.12 · 区间加 = 差分数组上两个单点改
TRICK差分之后

设 d[i] = a[i] − a[i−1]，则区间加 [l,r] += x 变成两个单点改：d[l] += x，d[r+1] −= x。

◆ 「区间加 + 单点查询」只需要 1 个 BIT
TWO TREES为什么是两个 BIT
Σi≤k a[i] = k·Σi≤k d[i] − Σi≤k d[i]·(i−1)

两个 Σ 各开一个 BIT：t1 存 d[i]，t2 存 d[i]·(i−1)。

void add(int i,int v){
  for(;i<=n;i+=i&-i){ t1[i]+=v; t2[i]+=v*(i-1); }
}
void range_add(int l,int r,int v){
  add(l,v); add(r+1,-v);
}
int sum(int k){
  int s=0; for(;k>0;k-=k&-k) s+=t1[k]*k-t2[k];
  return s;
}

扩展：二维树状数组

一维的每条循环套一层，就得到「单点加 + 矩形求和」。

FIG.13 · c[i][j] 管一个 lowbit(i) × lowbit(j) 的小矩形
TWO LOOPS双层循环
void add(int x,int y,int v){
  for(int i=x;i<=n;i+=i&-i)
    for(int j=y;j<=m;j+=j&-j)
      c[i][j] += v;
}
int sum(int x,int y){
  int s=0;
  for(int i=x;i>0;i-=i&-i)
    for(int j=y;j>0;j-=j&-j)
      s += c[i][j];
  return s;
}
RECTANGLE矩形求和 = 容斥
sum(x2,y2) − sum(x1−1,y2)
− sum(x2,y1−1) + sum(x1−1,y1−1)

代价 O(log n · log m)，空间 O(n·m)。

◆ 二维「区间加 + 矩形求和」需要 4 个二维 BIT

套路 · 坑 · 速查

离开这一页之前，把下面这几行带走就够了。

ONE SENTENCE
树状数组 = 用 lowbit 分层缓存前缀和，
让「改」和「查」都只跳 O(log n) 步。
SOLVING ROUTINE五步套路
  1. 题面出现「排名 / 计数 / 逆序对 / 区间和」，先想 BIT。
  2. 确定值域，需要就离散化，下标统一从 1 起。
  3. 每条修改 = 一次 add。
  4. 每个询问 = 一到两次 sum。
  5. 要区间加换差分；要区间加+区间和开两个 BIT。
PITFALLS五个最常见的坑
  • 下标从 0 开始，i & -i 就全错位。
  • 数组开小了：n+2 只是及格，再开一点。
  • 查询写成 i >= 0，死循环在 i = 0。
  • 区间和忘了 sum(l−1) 的 l−1，边界差一位。
  • 两个 BIT 时，t2 忘了乘 (i−1)。
