★统一模型

所有题都在问："若干点的值被修改后，某一段的聚合值是多少？" 树状数组的答案是：把数组折成 log 层，每层的块预先存好聚合值，查询时拼装、修改时更新。

判断口诀：只有"加"与"求和/异或/可逆聚合" → 树状数组；要区间赋值、区间最值、复杂懒标记 → 线段树。

三个判断题

更新是单点还是区间 聚合有没有逆运算 要不要区间最值

三个答案直接决定"用树状数组 / 双 BIT / 还是线段树"。

树状数组的定位

在"支持修改"的前提下，代码量最小、常数最小的对数结构。它的思想（分层块、lowbit）也是线段树、可持久化结构的基础语言。

典型心智模型

01 · MOTIVATION

朴素做法的两难

本页回答：为什么前缀和不够用？
要"既快查又快改"怎么办。

朴素数组

查询 sum(l, r)：O(n) 逐个加
修改 a[x] += v：O(1)

查询太慢：10⁵ 次查询 × 10⁵ 长度 = 10¹⁰，TLE。

前缀和

sum(l, r) = S[r] − S[l−1]：O(1)
修改 a[x] += v：O(n)（要重建 S）

反过来，修改太慢。

要的性质

  • 修改只影响 O(log n) 个"预聚合值"
  • 查询也只需要拼 O(log n) 个预聚合值
  • 结构简单、常数小、不易写错

答案

把数组按 2 的幂分层：第 k 层每块长 2^k。查询时由粗到细拼装，修改时由细到粗更新 —— 这就是树状数组。

关键洞察：不必维护"任意区间"，只要维护 lowbit(i) 个后缀块就够了。
01 · IDEA

核心思想：每点管辖 lowbit(i) 个元素

本页回答：c[i] 到底存什么？
为什么这样分块够用。

定义

c[i] = a[i − lowbit(i) + 1 .. i] 的和
即长度为 lowbit(i) 的一段，右端点为 i

为什么够用

任取前缀 [1..x]，总能按 lowbit 把它切成 ≤ log n 段：例如 [1..13] = c[13] + c[12] + c[8]。

两个方向：查询往左/下跳（i −= lowbit(i)），修改往右/上跳（i += lowbit(i)）。
注意：c 的下标与 a 一致（1..n），没有 c[0]。
01 · LOWBIT

lowbit：x & -x 为什么是最低位

本页回答：这行位运算凭什么对？
用二进制一推就懂。

定义

lowbit(x) = x & -x = x 最低位 1 所代表的值
44 = 101100₂ → lowbit = 100₂ = 4

证明

设 x 的最低位 1 在第 k 位。则 x = A·2^(k+1) + 2^k，补码取负 -x = ~x + 1 后，第 0..k−1 位全变 1 再进位，恰好第 k 位为 1、高位为 A 取反。x & -x 只剩第 k 位。

致命细节：lowbit(0) = 0。若下标出现 0，while i > 0 之外的写法会死循环。所以树状数组一律 1-indexed。
顺手记：x & (x-1) 抹掉最低位 1（常用于数二进制中 1 的个数）；x | (x-1) 把最低位 1 变 0 之后全置 1。
01 · COVERAGE

1..16 的管辖范围长什么样

本页回答：哪些 c[i] 覆盖 1..8？
块的长度有什么规律。

规律

  • 块长 = lowbit(i)，永远是 2 的幂
  • 块长为 1 的块有 ⌈n/1⌉ 个，为 2 的有 ⌈n/2⌉ 个……共 n 个 c[i]
  • 块长 2^k 的块，右端点满足 i ≡ 0 (mod 2^k)

两个半边

查询走越来越短的块（13 → 12 → 8），修改走越来越长的块（5 → 6 → 8 → 16）。两条链的长度都 ≤ log₂ n。

01 · TREE

树形态：父亲 = i + lowbit(i)

本页回答：为什么叫"树状"数组？
父子关系怎么来的。

父子关系

父亲：i + lowbit(i)（管辖区间向右扩展）
子节点：j 满足 j + lowbit(j) = i

i 的管辖区间是父亲区间靠右的一段。

性质

  • 根是 lowbit = n 的位置（如 n = 2^k 时是 n 本身）
  • 深度 ≤ log₂ n，所以两条跳转链都是 O(log n)
  • 查询链 = 沿"被管辖"方向一路向左
命名由来：把每个 i 连到 i+lowbit(i)，得到一棵树 —— Fenwick Tree / Binary Indexed Tree。
记忆：编号越"整"（低比特越多），管得越宽；8 一统 1..8，1 只管自己。

02 · COMPARE

求逆序对：三种解法对比

本页回答：归并和 BIT 各有什么优势？

1归并排序

做法：合并时统计跨半逆序数。

优点：常数小、无需离散化；缺点：离线、只能一次统计。

2树状数组

做法：离散化后按值统计前缀计数。

优点：可支持在线/带修改；可顺带求"每个元素贡献"。

做法：插入时查询比它大的个数。

选择建议

  • 一次性统计、纯求逆序对 → 归并（快、短）
  • 要"每个元素的贡献"或后续有修改 → BIT
  • 值域小且稠密 → 直接开桶 + BIT，省去离散化

衍生问题

02 · LIS

最长上升子序列：BIT 维护最大值

本页回答：为什么这里 BIT 可以维护 max？
和 O(n log n) 的贪心解法比。

做法

  • 离散化值域；BIT 存"以值 r 结尾的 LIS 长度"
  • 对 a[i]：cur = query(rank − 1) + 1（严格上升）
  • update(rank, cur)（取 max）

为什么可用 max

每个排名的 dp 值只增不减（始终取 max），符合 BIT-max 的单调前提。否则必须上线段树。

与贪心对比：贪心 + 二分也是 O(n log n) 但只能求长度；BIT 版可以顺带统计方案数（改成求和 + 取模）。

02 · OFFLINE

离线查询：按右端点排序 + BIT

本页回答："区间不同数个数"怎么做？
为什么要记"上次出现"。

问题

题意：静态序列，多次询问 [l, r] 内不同数的个数（如洛谷 P1972）。

套路

  • 查询按 r 升序排，右端点单调右移
  • 每加入 a[p]：若它上次出现在 q，则 add(q, −1) 抵消
  • 再 add(p, +1)；答案 = range_sum(l, r)
关键：每个值只在最新出现位置上记 1，于是区间内"1 的个数" = 不同数个数。

差分：把"区间加"变成"单点加"

本页回答：差分数组是什么？
为什么区间加就变成两次单点加。

定义

d[i] = a[i] − a[i−1]，a[0] = 0
则 a[i] = d[1] + ... + d[i]（前缀和还原）

区间加的妙用

[l, r] 全部 + v：
d[l] += v，d[r+1] −= v
只动两个点！
于是：区间加 = 两次 BIT 单点加；单点查询 = BIT 前缀和。完美对接第 12 页的模板。
边界：r + 1 可能 = n+1，超出范围；BIT 的 while i ≤ n 会自然跳过，不必特判。

03 · TWO BIT

区间加 + 区间和：公式推导

本页回答：为什么要两个 BIT？
第二个 BIT 乘的是什么。

推导

S(x) = Σi=1..x a[i]
  = Σi=1..x Σj=1..i d[j]
  = Σj=1..x d[j]·(x − j + 1)
  = (x+1)·Σ d[j] − Σ j·d[j]

所以要同时维护 Σ d[j] 与 Σ j·d[j] —— 两个 BIT。

区间加怎么落到两个 BIT

[l, r] + v：
B1: add(l, v)，add(r+1, −v)
B2: add(l, l·v)，add(r+1, −(r+1)·v)

注意第二个加的是 l·v 与 −(r+1)·v，不是 −r·v。

验算：a = 1..5，[2,4] +2 后 a = 1,4,5,6,5；S(5) = 6·B1(5) − B2(5) = 6·5 − 9 = 21 = 1+4+5+6+5 ✓

04 · 2D RANGE

二维区间加：四个 BIT 的容斥

本页回答：二维也能"区间加区间和"吗？
需要维护什么。

思路

一维推导里的 (x+1)·Σd − Σ j·d[j]，在二维变成四个求和项，每个一项对应一个二维 BIT：

S(x,y) = (x+1)(y+1)·Σ d
  − (y+1)·Σ i·d − (x+1)·Σ j·d + Σ i·j·d

实话实说

考场上几乎用不到；真要写，按"四个 BIT + 容斥"机械展开即可。先保证一维版本滚瓜烂熟。

常考替代

  • 子矩阵加值、单点查询 → 二维差分（4 次单点 add）
  • 静态子矩阵和 → 二维前缀和 O(1)
  • 动态且只问单点 → 二维 BIT 即可

复杂度一览

操作复杂度
二维单点加O(log n · log m)
子矩阵和O(log n · log m)
二维区间加区间和O(log n · log m)（4 BIT）

本页回答：为什么 max 不能直接维护？
哪些信息可以。

判断准则

可结合 ⊕ 且 存在逆运算 ⊖ ⇒ 可用 BIT 做区间查询

为什么不能 max

去掉一个元素后无法"撤销"它的贡献；因此 sum(r) − sum(l−1) 这一步失效。

05 · BIT MAX

例外：单调更新下的最大值

本页回答：什么时候 BIT 能维护 max？
限制是什么。

成立条件

  • 更新只能是 a[i] = max(a[i], x)（只增不减）
  • 查询是前缀最大值，不是任意区间
  • 典型应用：LIS、"历史最大高度"

为什么可以

值只增不减时，c[i] 里的最大值只会变大，旧值永远不会"重新成为答案"；于是就地取 max 即可。

不能做：值变小、区间最大、任意区间查询 —— 这些一律线段树。

05 · DECISION

三步决策树

本页回答：拿到题怎么判断用哪一版？
建议打印贴在机位旁。

第一步：更新形式

  • 单点改 → 标准 BIT
  • 区间加 + 单点查 → 差分 BIT
  • 区间加 + 区间和 → 双 BIT
  • 区间赋值 → 线段树

第二步：查询形式

  • 区间和 / 异或 / 计数 → BIT
  • 区间最值 → 线段树 / ST 表
  • 第 k 小 → BIT 上二分（计数）

第三步：规模与维度

  • n ≤ 10⁶、q ≤ 10⁶ → BIT 稳过
  • 二维 → 二维 BIT（注意 n·m 内存）
  • 值域大 → 先离散化

06 · VERIFY

怎么验证答案是对的

本页回答：树状数组怎么对拍？
边界用例有哪些。

1暴力对拍

写一个 O(n) 朴素实现当参照；随机生成 n ≤ 200、操作 500 次的数据，对拍 1 万组。重点覆盖"区间加 + 区间和"。

3边界用例

  • n = 1（只有一个元素）
  • l = r（单点区间）
  • r = n（末端区间，r+1 = n+1）
  • 负数 / 零值（若题目允许）
  • k = 1 与 k = 总数（kth 两端）
  • 空区间、全相同值（离散化后 m = 1）

2不变量检查

  • sum(n) = 全体元素和（改完后仍成立）
  • 任意 l： range_sum(l, l) == a[l]
  • 对随机区间：BIT 结果 = 暴力累加
  • 双 BIT：prefix_sum(x) − prefix_sum(x−1) == a[x]
  • kth：sum(kth(k) − 1) < k ≤ sum(kth(k))

07 · SUMMARY

带走这 五句话

本页回答：如果只能记住一页，
就记这一页。
1
c[i] 管辖 lowbit(i) 个元素：这是全部理解的基石；lowbit = x & -x。
2
两条对偶跳转链：查询 i −= lowbit(i)，修改 i += lowbit(i)，都 ≤ log n。
3
