题 A

题意：区间全部加 v，多次询问区间和。

→ 懒标记（区间加）。

题 B

题意：单点改值，询问区间最大值。

题意：区间整体赋值为 v，询问区间和。

题 D

题意：求 n 个矩形的面积并。

→ 扫描线 + 线段树。

★统一模型

把区间递归二分，预聚合每个节点的信息；任何查询区间都能拆成 O(log n) 个节点， 把它们的答案合并就得到最终答案。区别只在于"合并什么、懒标记怎么下传"。

一句话：线段树是"递归 + 合并 + 懒标记"三件套；换题只换"合并规则"。

三个判断题

信息可结合吗 懒标记怎么合并 要不要标记下传

答对这三题，就能设计出新题的线段树。

01 · IDEA

核心思想：任意区间 = O(log n) 个节点

本页回答：查询区间怎么被"拼"出来？
为什么节点数这么少。

递归规则

  • 当前节点区间 [l,r] 被查询区间完全包含 → 整个收下
  • 否则劈成两半，只递归有交集的那一侧
  • 遇到叶子就收下

关键性质

每一层最多 2 个被完整收下的节点
树高 ⌈log₂ n⌉ ⇒ 总共 ≤ 2·log n 个
所以：查询 = 遍历 O(log n) 个节点 + 合并它们的答案。
对照：如果查询 [1,8]，根节点一个就够；查询 [2,3] 则要拆成 [2,2]+[3,3]。
01 · INDEX

堆式编号：u 的孩子是 2u 与 2u+1

本页回答：节点存哪个数组里？
空间为什么要开 4n。

规则

根 u = 1，覆盖 [1, n]
左子 2u 覆盖 [l, mid]　右子 2u+1 覆盖 [mid+1, r]
mid = (l + r) // 2

两种实现

  • 堆式编号 + 数组：简单、缓存友好、面试首选
  • 动态开点：区间很大（10⁹）时用，见第 34 页
另一套路：递归时传 u, l, r，也可以只传 l, r 而用字典存信息（Python 慢，了解即可）。

空间为什么要 4n

补齐到 2 的幂后，叶子可能到 2^⌈log₂n⌉ 个（< 2n），完全二叉树总节点 < 4n。

01 · UPDATE

单点修改：只改一条路径

本页回答：单点改怎么写？
为什么回溯时要 pushup。

三步

  • 定位到叶子，改 tree[u]
  • 回溯，每一层 pushup
  • 路径长度 = 树高 = O(log n)

与树状数组对比

线段树：u → u/2 往上回溯

01 · SPACE

空间、下标与容易翻车的细节

本页回答：数组开多大？
下标从 0 还是 1。

1数组大小

一律 4 * n + 5。懒标记、多个信息字段要同样大小（常见 bug：sum 开了 lazy 没开）。

2下标约定

推荐 1-indexed（l, r ∈ [1, n]），与堆式编号 2u / 2u+1 天然契合。

3递归深度

Python 默认 1000 层；n = 10⁶ 时树高 20，安全。但 n 大且多层嵌套时加 sys.setrecursionlimit。

4整数溢出

求和可能超 int；Python 无此问题，C++ 要用 long long；取模题别忘 sum[u] %= mod。

5零元与初值

求和 0、最值 -inf、乘法标记 1、加法标记 0、赋值标记 None。初值错了极难查。

6闭开区间

全篇统一 闭区间 [l, r]；若题目给开区间，先转闭区间再进函数。

记忆：三件套 4n + 5、1-indexed、mid = (l+r)//2，能挡掉一半的 bug。

02 · LAZY

懒标记：延迟兑现的承诺

本页回答：为什么要懒标记？
不做下传会怎样。

问题

区间加 v：朴素要改 O(n) 个叶子。但我们其实只需要知道"这段区间整体被加过 v"。

做法

  • 整段被覆盖 → 只更新 tree[u]，并在 u 上贴标签
  • 下次需要进入 u 的孩子时，先把标签下传（pushdown）
  • 标签清空，孩子"醒过来"
收益：区间修改降到 O(log n)；代价是每次递归前多一句 pushdown。
铁律：一旦要"看孩子"，就必须先 pushdown；漏掉就是经典的查询结果错。
02 · PUSHDOWN

pushdown 的三个必答问题

本页回答：下传要改哪些数组？
传完要做什么。

下传三问

  • 改孩子的 tree？要（+= val * 长度）
  • 改孩子的 lazy？要（+= val）
  • 清自己的 lazy？要（置 0 / None / 1）

何时下传

  • 查询/修改要递归进孩子之前
  • 叶子节点不需要（没有孩子）
  • 整段覆盖、直接返回时不下传

三种常见懒标记

标记初值清空值
加法 add00
乘法 mul11
赋值 assignNoneNone
覆盖计数 cnt0不清
扫描线特例：覆盖计数 永远不下传，因为查询永远是"整棵树的覆盖长度"（见第 31 页）。

节点区间动作
1[1,5]不全含 → pushdown → 劈

02 · MUL + ADD

区间加 + 区间乘：双标记的合成

本页回答：两个标记怎么共存？

合成公式

当前含义：v → v·mul + add
再来一个 (k, b)：
(v·mul + add)·k + b = v·(mul·k) + (add·k + b)
⇒ mul' = mul·k，add' = add·k + b

node 更新

tree[u] = tree[u]·k + b·(r-l+1)
取模题：三个量都要取模
顺序不能反：必须是 add·k + b，写成 add + b·k 就错了。

02 · ORDER

三种标记的先后次序

本页回答：加、乘、赋值一起出现怎么排？
给一张速查表。

固定次序

先 乘，再 加，最后 赋值

赋值会"抹掉"之前所有未兑现的加与乘。

速查表

新操作 \ 已有addmulassign
add(d)add += dadd += dassign += d
mul(k)add *= kmul *= kassign *= k
assign(v)add = 0mul = 1assign = v

为什么要"乘先加后"

因为我们的语义是 v → v·mul + add：乘作用在原值上，加是最后加上去的常数。新乘操作要把旧加也乘进去。

陷阱：负数乘

若维护区间最值，×(-1) 会让 最大值与最小值互换；要同时维护 max 与 min，乘负数时交换两者。

练习建议：自己推一遍 (v·mul + add)·k + b，比死记公式稳。

问题在哪

整段加 v 后，长度为 k 的子段增加 k·v。而 pre / suf / ans 是不同长度的最优值，无法用一个加法统一平移。

换句话说：ans 不再是"整体平移"，旧答案会失效。

所以模板这样定位

  • 单点修改 + 区间最大子段和（P4513）→ 四字段 + 单点改
  • 区间最值 + 区间加 → 可以（第 25 页）
  • 区间最大子段和 + 区间加 → 超出普及/提高范围

真要做的思路

  • 把"最大子段和"看成 线段族的上凸包（每段对应一条直线）
  • 用 李超线段树 / 凸壳 维护区间最优
  • 或改成"区间加 + 区间最大子段和"的整体二分

同族问题

"最大连续 1 的个数""最长不下降子段""最大子矩阵"都是四字段的变体：只要 pushup 是局部合并，就能上线段树。

教训：不是所有"区间信息 + 区间修改"都能做；先问一句"修改能否局部合并"。
03 · HISTORICAL

历史最值：标记里再存一份"曾经的最大"

本页回答：怎么求"历史最大值"？
标记要多存什么。

问题

题意：区间加 / 区间赋值后，询问"这段时间里每个位置曾经的最大值"（如洛谷 P4314 CPU 监控）。

做法

  • 每个节点存 mx（当前最大）与 hmx（历史最大）
  • 每个标记也存 tag 与 htag（历史最大的标记）
  • pushdown 时先更新孩子的 hmx，再更新 mx

三个易错点

  • 顺序反了（先 mx 后 hmx）→ 历史值被覆盖
  • 只存当前标记，没存"历史最大标记"
  • 赋值与加法混用时，htag 的合成漏了赋值分支

难度定位

这是线段树的高阶内容（省选/NOI 级）。基础阶段只需知道"可以做"，等熟练后再啃。

学习路径：区间加区间和 → 加乘双标记 → 区间赋值 → 历史最值。每一步都在练"标记合成"。
03 · SWEEP LINE

扫描线：矩形面积并

本页回答：面积并怎么转化成线段树问题？
关键的 pushup 有什么不同。

思路

  • 把矩形拆成"进入/离开"两个事件，按 x 排序
  • y 轴离散化后建线段树，维护被覆盖的长度
  • 相邻两个事件之间：面积 += 覆盖长度 × Δx

关键 pushup

if cnt[u] > 0: len = ys[r] − ys[l−1]
elif 叶子: len = 0
else: len = 左.len + 右.len

注意 cnt > 0 就整段覆盖，不看孩子。

不下传：cnt 永远不下传，因为我们只关心"整棵树的覆盖长度"。
下标坑：节点 [l, r]（离散化后的 1-based 段号）对应 [ys[l−1], ys[r])，长度写 ys[r] − ys[l−1]。

03 · SWEEP TRACE

手算：两个矩形的面积并

本页回答：每一步覆盖长度是多少？
总面积对不对。

事件表

x动作覆盖长度Δ面积
0+R1 (y:0→2)2—
1+R2 (y:1→3)32×1 = 2
2−R1 (y:0→2)23×1 = 3
3−R2 (y:1→3)02×1 = 2

总计

2 + 3 + 2 = 7　= |R1| + |R2| − |交集| = 4 + 4 − 1 = 7 ✓

离散化

y 值：{0,1,2,3} ⇒ ys = [0,1,2,3]，段数 m = 3。

段 1 = [0,1)，段 2 = [1,2)，段 3 = [2,3)。

逐段核对

  • x ∈ [0,1)：只有 R1，覆盖 [0,2) ⇒ 2 ✓
  • x ∈ [1,2)：R1 ∪ R2 = [0,3) ⇒ 3 ✓
  • x ∈ [2,3)：只有 R2，覆盖 [1,3) ⇒ 2 ✓
提示：先用小数据手算再写代码，能省一小时调试。

04 · DYNAMIC

动态开点：用多少开多少

本页回答：n 很大时怎么办？
节点数怎么估。

场景

坐标/值域到 10⁹，但只有 10⁵ 次操作。开 4n 数组会爆内存。

做法

  • 节点动态新建（数组 / 字典），0 表示空
  • pushdown 时才给孩子开节点
  • 节点数 ≈ O(q · log n)

04 · PERSISTENT

可持久化：保留每一个历史版本

本页回答：主席树怎么做到的？
空间怎么估。

核心

  • 修改时不改动旧节点，新建一条路径
  • 未变的孩子共享旧版本的节点
  • 每个版本一个根，root[i] = 前 i 个元素

用途

区间第 k 小 = 用 root[r] 与 root[l−1] 同时往下走，比较左子计数差。

空间：每次修改新增 O(log n) 节点，总量 O((n+q) log n)。

04 · ORDER STATISTIC

权值线段树：在值域上建树

本页回答：区间第 k 小还有哪些做法？
各自复杂度。

1主席树

静态区间第 k 小，O((n+q) log n)。最经典。

见第 35 页。

2整体二分

把"值"二分 + BIT/线段树统计，带修改也能做。

O((n+q) log n · log V)。

3树状数组上二分

计数非负时 O(log n) 一问；但一般只支持全局第 k 小。

见上一份讲义。

权值线段树是什么

把"值域"当区间建树，每个节点存"值落在该区间的元素个数"。于是"第 k 小"变成"在树上二分"。

选型

静态区间第 k 小 → 主席树；带修第 k 小 → 树套树 / 整体二分；全局第 k 小 → BIT 二分最省事。

提醒：第 k 小题必先离散化；值域小可以直接当索引，省去离散化。
04 · ZKW

zkw 迭代线段树：去掉递归

本页回答：迭代版怎么写？
什么场景值得换。

思路

  • 把 n 补到 2 的幂，叶子在 [m, 2m)
  • 自底向上建树，i >>= 1 往上

05 · DECISION

三步决策树

本页回答：拿到题怎么判断？
建议打印贴在机位旁。

第一步：修改形式

  • 单点改 → BIT / 线段树（无标记）
  • 区间加 → 懒标记 add
  • 区间加 + 乘 → 双标记 mul/add
  • 区间赋值 → assign 标记
  • 区间覆盖（矩形）→ cnt，不下传

第二步：查询信息

  • 和 / 异或 → BIT 或线段树
  • 最值 → 线段树 / ST 表
  • 子段和 / 连续段统计 → 四字段
  • 第 k 小 → 主席树 / 权值树

第三步：规模

  • n ≤ 10⁵，q ≤ 10⁵ → 标准线段树
  • 值域 10⁹、操作少 → 动态开点
  • 要历史版本 → 可持久化
  • 常数敏感、只求和 → 换树状数组

05 · TUNING

常数与空间优化清单

本页回答：能再快一点吗？
按性价比排序。

1换数据结构

只求和/计数 → 换树状数组，最省事的 2 倍提速。

2标记永久化

区间加 + 和/最值：去掉 pushdown，实测快 20~40%。

3去递归

zkw / 栈模拟递归，省去函数调用开销。

4离散化 / 动态开点

压缩 n 或值域，减少内存与缓存失效。

5减少分支

把 ql <= mid / qr > mid 合并写法；信息定长时用 tuple。

6输入输出

sys.stdin.buffer.read().split() + 一次性 join 输出。

Python 特有

  • 热路径数组取到局部变量（t = self.t）
  • 用 __slots__、array 或 list 而非 dict
  • 避免在递归里构造 tuple / dict

C++ 特有

  • 结构体数组 vs 多个数组（缓存局部性）
  • register 无用，别纠结
  • 递归改迭代 / -O2 开启

06 · PITFALLS

易错清单 Checklist

本页回答：提交前自检什么？
（每条都对应本讲义的坑）

下传与合并

  • 递归进孩子前忘了 pushdown
  • 叶子节点也调用 pushdown（越界）
  • 回溯忘了 pushup
  • 整段覆盖时先 pushdown 再返回（多余且易错）
  • pushdown 里忘了清自己的 lazy
  • pushup 写漏某个字段

零元与初值

  • 最大值零元写成 0（应为 -∞）
  • 乘法标记初值写成 0（应为 1）
  • 赋值标记用 0 表示"无"（应为 None）
  • 空子段/非空子段语义混淆
  • 数组只开 2n（应为 4n+5）
  • sum 开了、lazy 忘了开

标记合成

  • 加乘顺序写反（应为 add·k + b）
  • 赋值来了没清 add / mul
  • 乘负数忘了交换 max/min
  • 扫描线长度写成 ys[r+1]−ys[l]（对齐约定易错）
  • 扫描线 y 区间没写右开
  • zkw 里 l & 1 == 0 的优先级

06 · VERIFY

怎么验证答案是对的

本页回答：线段树怎么对拍？
边界用例有哪些。

1暴力对拍

写一个 O(n) 朴素数组当参照；随机 n ≤ 100、操作 500 次，对拍 1 万组。重点覆盖"区间加 + 区间查询 + 混合操作"。

3边界用例

  • n = 1（只有一个叶子）
  • l = r（单点区间）
  • 全负数（测最大值零元）
  • 查询区间 = 全区间 / 只有一个元素
  • 赋值与加法交替（测优先级）
  • 乘 0 / 乘负数（测双标记）

2不变量检查

  • 无操作时 query(1,n) == sum(a)
  • 单点：query(i,i) == a[i]
  • 区间加后 query(l,r) == 暴力
  • 四字段：ans ≤ s 且 ans ≥ max(a)
  • 扫描线：面积 ≤ 外接矩形 且 ≥ 最大单矩形
小技巧：调试时打印整棵 tree 与 lazy，对照"理论值"逐节点核对；下传 bug 一眼可见。

07 · SUMMARY

带走这 五句话

本页回答：如果只能记住一页，
就记这一页。
1
任意区间 = O(log n) 个节点：每层最多 2 个，这是全部复杂度的来源。
2
三件套：pushup（合并孩子）、apply（整段处理）、pushdown（兑现标签）。
3

4

5

升华：线段树最值得学的不是模板，而是"把操作拆成可合成的标记、把信息拆成可合并的字段"这套思考方式。
