02 · CORE

松弛：唯一的原子操作

本页回答：最短路到底在反复做什么？
全篇所有算法都只是这一行的重复。
if dist[u] + w(u,v) < dist[v]:
    dist[v] = dist[u] + w(u,v)  # 松弛成功

直觉：原本以为到 v 至少要花 dist[v]；现在发现"先到 u 再走一条边"更便宜，于是把估计值拉低。像拧松一根绷紧的橡皮筋。

不变量：dist[v] 是"当前已知的最好上界"，只会变小，不会变大。
关键：松弛只在"dist[u] 已是最终答案"时才干净。各算法的区别，就在于用什么办法保证这一点。

松弛 = 检验三角不等式是否被破坏，破坏了就修好它。

02 · MAP

五种算法 = 五种调度方案

本页回答：各算法在"顺序/次数"上分别做了什么选择？
算法松弛顺序松弛次数正确性靠什么保证
BFS按层（队列）每点 1 次层号 = 距离，第一次到达即最优
0-1 BFS双端队列（0 边优先）每点 ≤ 2 次队列始终保持 dist 非降
Dijkstra每次取 dist 最小者每点 1 次（确定）非负权 ⇒ 最小值不可能再被改进
Bellman-Ford轮次：每轮扫全部边共 n−1 轮最短路径 ≤ n−1 条边
SPFA队列：谁变优谁入队不限次，判负环同 BF，均摊常数更小
Floyd按"允许的中转点集合"分阶段每阶段 n² 次k 阶段递推定义

为什么"顺序"重要

如果轮到 u 时 dist[u] 还不是最终答案，用它去松弛就会给出错误结果 —— 这正是负权破坏 Dijkstra 的原因。

为什么"次数"重要

次数决定复杂度。每点只确定一次 ⇒ O(m log n)；不限次数 ⇒ 最坏 O(nm)。复杂度是结论，不是玄学。

02 · PROOF

贪心为何安全？一次反证

本页回答：为什么"取最小"一定对、
为什么负权会让它崩掉？

证关键引理

设 u 是未确定点中 dist 最小者。断言：dist[u] 就是 u 的最终答案。

反证：若不然，真正的最短路 s⇝…→x→u 必经过某个未确定点 x（否则早已松弛到 u），于是

dist[x] ≤ dist_true(x) < dist_true(u) < dist[u]

与"u 是最小者"矛盾。∎

推论 1（最优子结构）：最短路的任意子段仍是最短路，所以可以"从前往后"递推。
推论 2（负权为何失效）：负边可能让"绕路再回头"更便宜，"dist[x] ≥ dist[u]"这一步不再成立，贪心顺序失去依据。

三段式理解 Dijkstra

  • 不变式：已确定集合 S 内 dist 全是最终答案
  • 扩展：从 S 外取 dist 最小的 u 加入 S
  • 松弛：用 u 更新它的所有邻居

由此得到的三个结论

① 每点只需确定一次；
② 瓶颈只在"快速取最小" ⇒ 用堆；
③ 前提必须非负权。

答主观题的模板：先说不变式，再说"最小 dist 不可能被改进"，最后点明非负权前提。

SPFA 的两面

04 · NEGCYCLE

负环：什么时候有、意味着什么

本页回答：负环如何影响答案？
三种典型题型如何应对？

1题面要求判负环

做法：SPFA + 入队计数；或 BF 第 n 轮检查。

典型：P3385 负环

2求最短路但含负环

若负环在 s→t 的路径上，最短路为 −∞（可无限绕圈），常要求输出 -1 或特殊标记。

做法：先判负环，再判断负环是否在关键路径上。

3题面隐式含负边

如"退款""补偿""差价"等语义，往往转化为负权边；此时必须放弃 Dijkstra。

先问：负边会形成环吗？环的总权是负的吗？

判断口诀

① 有负边不等于有负环；② 有负环才导致无解；③ 负环若不可达目标，可忽略。

实现提醒

SPFA 判负环时，cnt 记录入队次数并在入队时递增（如模板所示），不要在出队时累加。

05 · FLOYD

Floyd：f[k][i][j] 的三层含义

本页回答：k 为什么必须在最外层？
可以省掉一维吗？
f[k][i][j] = min( f[k−1][i][j], f[k−1][i][k] + f[k−1][k][j] )
# 含义：从 i 到 j、只允许用 1..k 号点做中转的最短路

k 为什么最外层

k 是阶段：第 k 阶段才允许用 k 做中转。若把 k 放内层，会在阶段未完成时就用 k 更新，破坏递推前提。

空间优化：k 维可去掉，直接原地 d[i][j] = min(d[i][j], d[i][k] + d[k][j])（只会变小）。
阈值：n ≤ 400 可跑；n ~ 1000 用 bitset 传递闭包或 n 次 Dijkstra。

换运算不换套路：概率、瓶颈、期望

本页回答：目标不是"和"怎么办？
怎么判断贪心仍成立？

最大概率

题意：每条边有通过概率，求成功概率最大的路径。

dist[v] = max( dist[v], dist[u]×p )

"+"换"×"、min 换 max。概率 ≤ 1 ⇒ 乘积单调不增 ⇒ 贪心成立。

LC 1514

最小化最大边

题意：路径代价 = 路径上最大单边权，求最小化。

dist[v] = min( dist[v], max(dist[u], w) )

变形 Dijkstra：把 "+"换成 max，单调性依旧。

LC 1631

期望 / 乘积

乘积可取对数转加法；期望常转 DP + 高斯消元。

判断标准：合并运算与比较关系能否构成满足三角不等式的结构。

反例：什么时候不行

"最大化最小边"（瓶颈最大化）单调方向相反，贪心不再成立，应改用最大生成树（Kruskal）。

要领

先写松弛式，再问：会不会存在"当前确定的值以后变差"？会 ⇒ 贪心不成立，改用多轮或二分。

AK 短路（A* + 反图）

  • 先在反图上求 distT[v] 作估价
  • 堆中放 (当前花费 + distT, 当前花费, 点)
  • t 第 K 次出堆即答案

第 2 短路：P2865 Roadblocks（可用"次短路"DP 做）

BA* 的思想

用 f = g + h 排序：g 已花费，h 是乐观估计。只要 h 不高估，结果正确且更快。

h(v) ≤ dist_true(v, t)  # 可采纳性

网格常用曼哈顿距离；图上常用反向最短路。

两个概念别混

"最多走 k 条边 / 最多用 k 次机会"是分层图问题（LC 787）；"第 k 短的路径"才是第 K 短路问题。

07 · PITFALLS

易错清单 Checklist

本页回答：提交前自检什么？
（本页内容均来自模板代码的易错点）

正确性

  • 有负权却用了 Dijkstra
  • 0 边用普通 BFS（层序错乱）
  • Floyd 把 k 放到了内层
  • 无向图只建了一条边
  • 重边 / 自环未处理
  • 起点到自身答案未置 0
  • BF 中未跳过 dist[u] = INF 的点

实现

  • INF 太小，加法溢出
  • 堆里放 (点, 距离) 导致排序错
  • 懒惰删除写成 ≤
  • 计数取模位置不对，重复累加
  • Python 读入太慢
  • 路径回溯时 pre 被覆盖
  • 数组开小 / 下标 0、1 混用

建图

  • 拆点后规模估算错误
  • 漏加超级源点，判负环失效
  • 二分答案没证明单调性
  • "限 K 次"误写成"第 K 短"
  • 该反向建图却硬跑多源
  • 把"最大边最小化"当"和最小"
  • 漏掉"不可达"的输出约定
提交前 30 秒五连问：① 有负权吗 ② 权值有特殊吗 ③ 单源还是全源 ④ 有隐藏维度吗 ⑤ 复杂度与规模匹配吗。

怎么验证你的答案是对的

本页回答：写完怎么自查？
暴力对拍、不变量、边界用例。

1暴力对拍

写一个"笨版本"（Bellman-Ford / 朴素），在 n ≤ 8 的随机数据上与优化版对拍 1 万组。

random_gen.pyPYTHON

3边界用例

  • 不连通（应输出 INF / −1）
  • 重边、自环
  • s == t
  • 全 0 边 / 全 1 边
  • 含负环
  • k = 0 与 k 取最大
  • n = 1

2不变量检查（断言）

  • dist[s] == 0
  • 无负环时：所有边满足 dist[v] ≤ dist[u] + w
  • 结果不超过任何一条可行路径的长度
  • 松弛次数 / 入队次数在合理范围
  • 计数与暴力枚举一致（小数据）
好习惯：代码顶部注释写清"输入规模 + 复杂度估算"。写完立刻算一次：10⁵ 规模下 O(m log n) 可行，O(nm) 必炸。

08 · SUMMARY

带走这 五句话

本页回答：如果只能记住一页，
就记这一页。
1
最短路 = 松弛的重复。堆、队列、轮次都只是"松弛顺序"的选择。
2
非负权 ⇒ 贪心安全；负权 ⇒ 必须多轮，且要会判负环。
3
难点是建图。状态即点、拆点分层、反向、超级源点，是四把手术刀。
4
换运算不换套路。概率、瓶颈、期望…… 满足单调性即可。
5
最小化最大值 ⇒ 二分。把最优化变判定，是最高频的思维转换。
升华：最短路教给我们的，是"用更优解不断覆盖旧解"的思维方式 —— 这也是动态规划、优化算法、工程迭代的共同底色。
