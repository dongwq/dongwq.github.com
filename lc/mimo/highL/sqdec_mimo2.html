01 · HOOK

四道"线段树写不动"的题，一个套路

本页回答：分块能干什么？
它擅长哪一类题。

题 A

题意：区间加值，询问区间内 ≥ x 的元素个数。

→ 散块暴力 + 整块懒标记。

题 B

题意：区间整体开平方（向下取整），询问区间和。

→ 均摊：一个数最多开方 6 次。

题 C

题意：静态区间众数。

→ 块间预处理 + 散块候选。

题 D

题意：离线多次询问区间不同数的个数。

→ 莫队：分块排序 + 双指针。

★统一模型

把序列切成 √n 块：区间操作时整块打标记、散块暴力改； 查询时整块用预聚合值、散块逐个算。于是"难合并的信息"也能 O(√n) 处理。

一句话：分块是"放弃精细的 log，换取对信息的宽容"——只要能 O(B) 暴力，就能上。

三个判断题

信息能 O(B) 暴力吗 整块能 O(1) 标记吗 要不要离线

答对这三题，就知道该不该上分块。

01 · IDEA

核心思想：块数 × 块大小 = n

本页回答：√n 是怎么算出来的？
为什么不是 ³√n。

两个代价

散块（逐个改）：O(B)
整块（逐块改标记）：O(n / B)
总计：O(B + n/B) ≥ 2√n

最优点

由均值不等式 B + n/B ≥ 2√n，等号当且仅当 B = √n。

所以块大小取 √n，块数也约 √n。

直观理解：块太少 → 每块太大（散块贵）；块太多 → 整块太多（标记贵）。
常数提醒：实际常数比线段树大，B 会略微调大（见第 13 页）。

四个必备数组

数组含义

公式

B = max(1, isqrt(n))　块数 m = ⌈n / B⌉

命名习惯：下标 1-based、块号 1-based，与线段树/树状数组保持一致。
01 · POSITIONS

分类讨论

情形处理
bel[l] == bel[r]整段暴力，只动一个块

中间整块只改标记 bl+1 .. br-1

为什么"单块"要特判

规律：区间越"整"，越省事；最坏就是被劈成两个散块 + 0 个整块。

01 · LAZY

push 与 lazy 的分工

本页回答：什么时候必须 push？
什么时候可以只读标记。

必须 push 的时机

  • 要逐元素修改散块之前
  • 要逐元素重算块聚合值之前
  • 要导出真实值（比如排序、取具体元素）

可以只读标记的时机

  • 查询整块的 s[b] / mx[b]
  • 查询散块的单个值（a[i] + add[bel[i]]）
二选一：要么"查询也 push"（代码简单、略慢），要么"读时加标记"（快、易错）。全篇必须统一。
与线段树对比：线段树 pushdown 是"进孩子前"；分块 push 是"动元素前"。都是"延迟兑现"。

01 · BLOCK SIZE

块大小 B 到底取多少

本页回答：理论值 √n，实际取多少？
不同题型有没有特例。

经验表

场景建议 B
通用（在线）isqrt(n) ~ 2·isqrt(n)
莫队（q 次询问）n / √q
带修莫队n^(2/3)
块状链表isqrt(n)，块维持 [B/2, 2B]

常数修正

分块常数比线段树大，实践中 B 取 500~1000（n = 10⁵）往往比严格 √n 快。压不过就调参。

代码

import math
B = max(1, math.isqrt(n))
# 不要 int(n ** 0.5)，浮点误差可能差 1

为什么莫队是 n/√q

指针总移动量 ≈ q·B + n²/B，对 B 求最小得 B = n/√q，总代价 O(n√q)。

注意：B 太小会让块数暴涨，bel / L / R 的缓存命中变差；B 太大则散块变慢。
01 · COMPLEXITY

复杂度：一条 O(√n) 的直线

本页回答：分块到底多快？
和线段树比谁赢。

各项开销

操作复杂度
建块（划分 + 聚合）O(n)
区间修改O(B + n/B)
区间查询O(B + n/B)
单点修改O(1) 均摊
空间O(n)

对比线段树

n = 10⁵ 时：线段树 ≈ 17 步；分块 ≈ 632 步。但分块常数小、无递归、代码好写，而且能做线段树做不了的事。

莫队的复杂度

排序后指针总移动 O(n·√q)
每次移动增删 O(1)
总计 O((n + q)·√n)

均摊的操作

  • 区间开方：每个数最多 6 次
  • 块状链表：分裂/合并维持块大小
  • 区间取 min / mod：同理
结论：分块不是"更慢的线段树"，而是"能吃更多操作的 O(√n)"。
01 · AMORTIZED

均摊思维：什么时候能"骗过"复杂度

本页回答：为什么区间开方能 O(√n)？
均摊怎么想。

区间开方

64 → 8 → 2 → 1 → 1：一个 long long 最多被开方 6 次就稳定在 1。

维护"块内是否全 ≤ 1"，是则整块跳过 ⇒ 总复杂度 O((n + q)·√n) 的常数倍。

块状链表

插入后块过大就分裂，过小就与邻块合并；块大小维持 [B/2, 2B] ⇒ 每次均摊 O(√n)。

共同套路：找一个单调且有界的量，证明"每次要么便宜、要么消耗了这个量"。

不是均摊的场景

  • 区间加、区间赋值：每次都是 O(√n)
  • 莫队：总移动量有界，属于整体均摊

均摊的坑

均摊 ≠ 单次上界。若题面要求单次操作上限（如实时系统），分块的"均摊 O(1)"写法不达标。

怎么验证

写个计数器统计实际执行的循环次数，跑随机数据看总次数 / 操作数是否稳定在常数附近。

01 · SPACE

空间、下标与容易翻车的细节

本页回答：数组开多大？
下标从 0 还是 1。

1数组清单

a[n+1]、bel[n+1]、L[m+1]、R[m+1]、s[m+1]、add[m+1]、assign[m+1]。共 O(n)。

2下标约定

统一 1-indexed；块号也从 1 开始。bel[i] = (i-1)//B + 1。

3最后一块

R[m] = min(m*B, n)，最后一块可能不满；越界写 L[m], R[m] 是高频 bug。

4标记初值

add = 0、assign = None、mx = -inf。初值写错极难查。

5聚合值更新

整块加时 s[b] += v*len、mx[b] += v；改散块后必须 _recalc(b)。

6递归深度

分块基本不递归，没有爆栈问题；这是它比线段树更稳的一面。

记忆：四件套 1-indexed、R[m] = min(m*B, n)、bl == br 特判、改散块后 _recalc。

要点

  • 整块：assign[b] = v、add[b] = 0

语义：先赋值，再加

assign 会清掉 add；反过来 add 累加

02 · MUL + ADD

加乘双标记：合成顺序不能错

本页回答：两个标记怎么共存？
合成公式是什么。

合成公式

当前：v → v·mul + add
再来 (k, b)：
(v·mul + add)·k + b = v·(mul·k) + (add·k + b)
⇒ mul' = mul·k，add' = add·k + b

块聚合

s[b] = s[b]·k + b·len
mx[b] = mx[b]·k + b（k > 0）
k < 0 时 max / min 互换
顺序不能反：必须是 add·k + b，写成 add + b·k 就错。

与赋值合并

新操作 \ 已有addmulassign
add(d)add += dadd += dassign += d
mul(k)add *= kmul *= kassign *= k
assign(v)add = 0mul = 1assign = v

固定次序

先 乘，再 加，最后 赋值。赋值抹掉之前一切未兑现标记。

自检：推一遍 (v·mul + add)·k + b，比背公式稳。

02 · MODE

区间众数：块间查表 + 散块候选

本页回答：众数怎么预处理？
查询为什么是 O(√n log n)。

预处理

  • f[i][j] = 块 i..j 的众数（并列取较小）
  • c[i][j] = 该众数的出现次数
  • 转移：f[i][j] = f[i][j-1] 与块 j 合并
  • 空间 m² = O(n)，时间 O(n√n)

查询

  • 候选 = 整块众数 + 两个散块里的值（≤ 2B 个）
  • 每个候选用 pos[x] 二分求区间内次数
  • 复杂度 O(B log n)
替代：离线用莫队 + 值域分块，也能 O(n√n)。

  • 块内改成值域计数，check 变 O(√n)
  • 值域离散化，二分只到 log n 层
  • 整体二分（离线）可降到 O(n log² n)
心法：只要 check 能写成"整块查表 + 散块暴力"，就可以套这个套路。
03 · MO'S

莫队：把排序变成武器

本页回答：莫队怎么工作？
为什么是 O(n√q)。

三步

  • 询问按 (bel[l], r) 排序
  • 维护当前区间 [cur_l, cur_r]，用 add / remove 移动指针
  • 指针总移动 O(n√q) ⇒ 每次 add/remove 必须 O(1)

能做 / 不能做

能：不同数个数、区间众数、区间 mex、区间第 k 小（值域分块）。
不能：需要在线、需要修改（带修莫队另算）、add/remove 不 O(1)。

前提：离线！所有询问一次性给出。

03 · MO TUNING

莫队的四种进阶

本页回答：还能更快吗？
带修改怎么做。

1奇偶优化

奇数块 r 降序，减少回跳。常数几乎砍半。

代码见第 26 页的 sort key。

2块大小

B = n / √q；若 q ≈ n 则 B = √n。

实测可微调 2 倍。

3带修莫队

三关键字 (bel[l], bel[r], t)；块大小 n^(2/3)，总复杂度 O(n^(5/3))。

要维护"撤销修改"。

4回滚莫队

只支持 add 不支持 remove 时（如区间 mex），用"只加不删 + 回滚"。

常数更小，技巧性强。

带修莫队的骨架

排序键：(bel[l], bel[r], t)
移动：先调时间轴 t，再调左右指针
时间轴只能在"整块区间"时移动，代价靠块大小平衡

何时选哪个

  • 无修改、add/remove 好写 → 普通莫队
  • 有修改 → 带修莫队 或改成在线结构
  • 只能 add → 回滚莫队
03 · TREE MO

树上莫队：欧拉序 + 奇偶 toggle

本页回答：路径询问怎么变成区间？
LCA 怎么补。

三步

  • 求 欧拉序（进入/离开各记一次，长 2n）
  • 路径 (u,v) 映射成区间：
    LCA == u → [tin[u], tin[v]]
    否则 → [tout[u], tin[v]] + LCA
  • toggle(x)：出现奇数次 = 在路径上

关键

一个点在欧拉序里出现两次，toggle 两次等于取消；这正好实现了"在不在路径上"的开关语义。

易错：LCA 不在区间里，必须单独计入再还原，否则答案少 1。

03 · VALUE BLOCK

莫队 + 值域分块：O(1) 增删、O(√V) 查询

本页回答：区间第 k 小 / 众数怎么做？
值域分块是什么。

值域分块

  • 把值域切成 √V 块，维护每块的计数和
  • add(x) / remove(x)：O(1) 更新 cnt[x] 与所在值块
  • 求第 k 小：先扫值块找块（O(√V)），再在块内枚举值（O(√V)）
  • 求众数：扫所有值块取最大（O(√V)）

组合复杂度

莫队 O(n√q) × 增删 O(1)
+ 查询 O(q·√V)
V = 值域大小（离散化后 ≈ n）

三种方案对比

问题方案复杂度
区间众数（在线）块间 f[i][j]O(√n log n)
区间众数（离线）莫队+值域分块O(n√n)
区间第 k 小（静态）主席树O(log n)
区间第 k 小（离线）莫队+值域分块O(n√n)

心法

"值域也分块"是分块的第二层玩法：把"数值"当成第二根轴，同样用 √ 平衡。

连招：分块（下标） + 值域分块（数值） = 能处理"区间 + 数值"二维的信息。

04 · BLOCK LIST

块状链表：序列的插入与删除

本页回答：要插入/删除怎么办？
块大小怎么保持。

思路

  • 把序列存成块的链表，每块 √n 个元素

块内放什么解决什么

04 · PATTERNS

六个常见套路清单

本页回答：拿到题怎么套？
建议贴在机位旁。

1整块标记 + 散块暴力

最经典。区间加/赋值/乘。关键是"整块 O(1) 打标记"。

2块内排序副本

需要"区间 < x 的个数/前驱"时，每块维护排序数组 + 二分。

3块间预处理表

f[i][j] 类：块 i..j 的答案预处理，查询 O(1) + 散块修正。如众数、区间最值。

4均摊跳过

维护"块内是否已稳定"（如全 ≤ 1、全相等），是则整块跳过。开方、取 min、mod。

5值域分块

把数值当第二根轴，O(1) 增删 + O(√V) 查询第 k 小/众数。

6分块排序 + 双指针

莫队：离线询问按 (bel[l], r) 排序，指针移动总量有界。

选型口诀：能标记 → ①；要统计 → ②；要查表 → ③；操作不线性 → ④；值域维度 → ⑤；离线 → ⑥。

05 · DECISION

三步决策树

本页回答：拿到题怎么判断？
建议打印贴在机位旁。

第一步：信息能不能合并

  • 能 O(1) 合并（和/最值/xor）→ 线段树/BIT
  • 不好合并（众数、< x 个数）→ 分块
  • 不可合并但可暴力（开方、mod）→ 分块均摊

第二步：在线还是离线

  • 在线 → 分块 / 线段树
  • 离线 + 询问多 → 莫队
  • 离线 + 有修改 → 带修莫队

第三步：规模与常数

  • n ≤ 10⁵、时限 1s → 严格 √n 或线段树
  • 常数敏感 / 卡 log → 分块 + 调 B
  • 要插入删除 → 块状链表
  • 值域维度 → 值域分块

06 · ADAPT

改一改就能用：四个改点

本页回答：换一道题要改哪里？
只有四处。

1聚合函数

_recalc 里的 s[b] / mx[b] 换成你要的信息（gcd、or、计数……）。

2标记语义

add / assign / mul 换成你的操作；记住"赋值 > 加 > 乘"的次序。

3查询函数

散块逐个怎么算、整块怎么用聚合值。若要二分，就加块内排序副本。

4块大小

通用 isqrt(n)；莫队 n/√q；带修莫队 n^(2/3)。

换题检查表

  • 这个操作能整块 O(1) 打标记吗？
  • 散块能不能 O(B) 暴力？
  • 查询需要预处理表吗（f[i][j]）？
  • 是否离线（可以上莫队）？

什么时候该放弃分块

信息能 O(1) 合并且要严格 log → 用线段树；空间紧张 → 用 BIT；数据随机且 q 小 → 直接暴力。

别硬上：分块常数大，"能做"不等于"该做"。
06 · VERIFY

怎么验证答案是对的

本页回答：分块怎么对拍？
边界用例有哪些。

1暴力对拍

写一个 O(n) 朴素数组当参照；随机 n ≤ 100、操作 500 次，对拍 1 万组。重点覆盖"散块 + 整块 + 单块"三种分支。

3边界用例

  • n = 1（只有一个块、一块一元素）
  • l = r（单点）
  • 查询 = 全区间 / 只跨一个块
  • 恰好跨块边界（l = R[bl] 或 r = L[br]）
  • 赋值与加法交替
  • 全 1 / 全 0（测均摊跳过）

2不变量检查

  • 无操作时 query(1,n) == sum(a)
  • 单点：query(i,i) == a[i] + add[bel[i]]
  • 每个块：s[b] == Σ(a[i] + add[b])
  • 众数：并列时返回较小值
  • 块状链表：len(to_list()) 与实际元素数一致
