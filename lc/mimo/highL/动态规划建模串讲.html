01 · HOOK

三道"长得像"的题，三种状态

本页回答：为什么不能背模板？
状态选错 = 复杂度爆炸或答案错。

A序列

题意：给 n 个数，求最长递增子序列长度。

→ 状态 f[i] = 以 i 结尾的 LIS 长度。
朴素 O(n²)，贪心+二分 O(n log n)。

B结构

题意：n 堆石子排成一排，每次合并相邻两堆，代价为重量和，求最小总代价。

→ 状态 f[l][r] = 合并 a[l..r] 的最小代价。
区间 DP O(n³)，四边形不等式 O(n²)。

C组合

题意：n 个城市，求访问每个城市恰好一次并回到起点的最短回路（TSP）。

→ 状态 f[S][i] = 已访问集合 S、当前在 i。
状压 DP O(2ⁿ·n²)。

★共同点与差异

三者都在做同一件事：把指数级搜索空间压缩成多项式状态空间。区别在状态的形状——序列、区间、集合。选错形状不是"略慢"，而是根本跑不完。

一句话：DP 的第一问不是"转移是什么"，而是"状态怎么定义"。

三个判断题

状态是一维位置吗 状态是区间 / 子树吗 状态是集合吗

答对这三题，状态形状就定了。

问题问的是答案指向典型陷阱

01 · THREE QUESTIONS

三问逐条展开

本页回答：每一问具体怎么答？
答错了会怎样。

1状态怎么定

  • 下标要能完整刻画局面
  • 两个局面状态相同 ⇔ 后续最优决策相同
  • 维度尽量少，但不能漏

⇒ 五种形状：序列 / 区间 / 集合 / 值域 / 图。

2转移怎么找

  • 问"最后一步是什么"
  • 枚举所有可能的最后决策
  • 取 min / max / sum

⇒ 复杂度 = 状态数 × 决策数。

3优化怎么上

  • 转移形如 a[j]·x[i]+b[j] → 斜率
  • opt[i] 单调 → 决策单调 / 分治
  • 转移是线性的 → 矩阵快速幂

⇒ 先证单调 / 凸性，再写优化。

三问的"叠加性"

一道题可以同时要好状态、好转移、好优化。这时按顺序叠加，而不是三选一。最常见的顺序是：先定状态 → 写朴素转移 → 验证 → 再优化。

常见组合

  • 序列状态 + 枚举前驱 + 斜率优化（玩具装箱）
  • 区间状态 + 分割枚举 + 四边形不等式（石子合并）
  • 集合状态 + 子集转移 + 高维前缀和（覆盖 / 分组）
心法：DP 是可叠加的积木——状态、转移、优化三层各自独立，别一次写到底。

02 · LINEAR DP

线性 DP：状态是"到 i 为止的最优"

本页回答：线性 DP 的骨架是什么？
为什么"最后一步"是关键。

核心骨架

f[i] = min/max { f[j] + cost(j,i) } j < i

问 "最后一步是什么"：
  · LIS：最后一个取谁
  · 编辑距离：最后一步是插入/删除/替换
  · 最大子段和：以 a[i] 结尾还是一刀两断

滚动数组

  • f[i][j] 只依赖 f[i-1][*] → 只留两行
  • 0/1 背包必须倒序遍历容量（防止重复用）
  • 完全背包必须正序遍历容量
复杂度：状态数 × 决策数 = O(n × k)；决策数可优化到 O(1) 就是斜率优化的入口。

三个易错

  • 滚动数组方向写反 → 0/1 背包变完全背包
  • 初值用 0 而非 -INF，"取不到"被当 0
  • 状态漏掉"上一个取了什么" → 后续决策不一致
02 · TEMPLATE

模板一：LIS（朴素 + 贪心二分）

本页回答：O(n²) 与 O(n log n) 怎么写？
差别在哪。

四个关键点

  • 朴素：f[i] = 以 a[i] 结尾的 LIS 长度
  • 优化：tails[k] = 长度 k+1 的 LIS 最小结尾值
  • 严格递增用 bisect_left；非降用 bisect_right

朴素 f = [1,1,1,2,2,3,4,4] → 4

02 · TEMPLATE

模板二：编辑距离（2D + 滚动数组）

本页回答：二维 DP 怎么降维？
降维时踩什么坑。

四个关键点

  • 状态 f[i][j] = s[:i] 变到 t[:j] 的最小操作数
  • 转移三选一：替换 / 删除 / 插入
  • 降维要存 prev（f[i-1][j-1]）
  • 空间优化后是 O(min(n,m))

验证样例

s="horse", t="ros" → 3
horse → rorse (替换 h→r) → rose (删 r) → ros (删 e)
易错：降维时 prev 必须在覆盖 f[j] 之前保存，否则 f[i-1][j-1] 就丢了。

模板三：最大子段和（三解对照）

本页回答：同一题的三种建模。
顺便当对拍用。

三种建模

  • 暴力 O(n²)：枚举所有子段
  • 前缀 DP O(n)：f[i] = max(a[i], f[i-1]+a[i])

分治的四元组

(sum, pref, suff, best)
合并：
 sum = ls + rs
 pref = max(lp, ls + rp)
 suff = max(rq, rs + lq)
 best = max(lb, rb, lq + rp)

02 · CASES

线性 DP建模案例

本页回答：哪类题想到线性 DP？
四个典型。

A最长递增子序列

题意：求最长递增子序列长度。

建模：f[i] = 以 i 结尾的 LIS。
答案：O(n log n)。

B编辑距离

题意：字符串 s 变到 t 最少几步。

建模：f[i][j] = 前缀对齐。
答案：O(nm) + 滚动。

C最大子段和

题意：求最大连续子段和。

建模：f[i] = 以 i 结尾的最大和。
答案：O(n)。

D打家劫舍 / 选或不选

题意：相邻不能都选，求最大价值。

建模：f[i][0/1] = 选 / 不选。
答案：O(n)。

共同结构

都是"到 i 为止的最优"。识别信号：子序列、前缀、连续一段、选或不选。

什么时候不够用

  • 要区间合并 → 区间 DP
  • 要集合（哪些已用）→ 状压 DP
  • 转移是非线性的且决策数大 → 优化层
心法：看到"到 i 为止"或"以 i 结尾"，第一反应是线性 DP。

关键：线性 DP 的通用套路是"问最后一步，枚举上一个决策点"。

03 · INTERVAL DP

区间 DP：状态是"区间 [l, r]"

本页回答：区间 DP 的骨架是什么？
为什么按长度枚举。

核心骨架

f[l][r] = min/max { f[l][k] + f[k+1][r] + w(l,r) }
k ∈ [l, r-1]（枚举最后一次分割 / 合并点）

问 "最后一次合并发生在哪"

遍历顺序

  • 按长度枚举：先短区间，后长区间
  • 或记忆化搜索（自动正确）
  • 环形问题：断环成链，复制一份拼接

03 · TREE DP

树形 DP 与换根

本页回答：树上怎么 DP？
换根在解什么。

树形 DP（一次 DFS）

  • 状态 f[u][*] = 子树 u 的最优
  • 后序遍历：先算子，再算父
  • 典型：最大独立集、树上背包、染色
复杂度：O(n × 状态数 × 决策数)。

换根 DP（两次 DFS）

  • 第一次：求子树内贡献 f[u]
  • 第二次：把子树外贡献 h[u] 传给子
  • 典型：每个点到所有点的距离和、树的重心
关键：换根公式要减去子的贡献再加父侧，别重复算。

典型状态

问题状态转移
最大独立集f[u][0/1]选 u 则子必不选
最小点覆盖f[u][0/1]边的两端至少选一
树上背包f[u][j]子树合并背包
染色 / 社交距离f[u][c]枚举 u 颜色
换根距离和dp[u] + sz[u]两次 DFS

三个易错

  • DFS 递归太深 → 用迭代栈或加递归限制
  • 换根时忘了减去子的贡献
  • 树形背包复杂度写成 O(nV²)，实际是 O(nV)（按子树大小枚举）
心法：树形 DP 的遍历顺序由父子依赖决定；换根则需要两次。

04 · STATE COMPRESSION

状压 DP：状态是集合 S

本页回答：状压的核心是什么？
子集枚举怎么优化。

核心骨架

f[S][i] = 已选集合 S、当前在 i 的最优

f[S ∪ {v}][v] = min/max { f[S][u] + w(u,v) }
S 用二进制位表示；遍历按 |S| 递增

子集枚举技巧

枚举 S 的子集：T = (T-1) & S
总复杂度 O(3ⁿ) 而非 O(4ⁿ)
高维前缀和（SOS DP）：O(n·2ⁿ)
规模：n ≤ 20 → 2²⁰ ≈ 10⁶ 可行；n ≥ 22 直接爆。

典型问题

  • TSP：f[S][i] 访问集合 S、当前在 i
  • 互不侵犯：f[i][S][k] 前 i 行、当前行状态 S、放 k 个
  • 炮兵阵地：两行状态兼容性
  • 覆盖 / 染色：格子被哪些骨牌盖住
  • 最大独立集（一般图）：f[S]

三个易错

  • 状态数算错 → 2²² 直接爆内存
  • 遍历顺序不是按 |S| 递增 → 依赖没算
  • 兼容性判据写漏（如"相邻行不能攻击"）

与其它主线的关系

状压是枚举与 DP 的结合。当 n 大但值域小时，换成值域 DP（背包族）；当集合有结构时，考虑折半搜索。

04 · DIGIT DP

数位 DP：状态是数字结构

本页回答：数位 DP 在解什么？
三个状态维度是什么。

核心骨架

f[pos][sum][tight]
 pos = 填到第几位
 sum = 已填位的某种量（和 / 乘积 / 余数）
 tight = 是否贴着上界

记忆化搜索写法最自然

三个关键

  • tight 决定本位上界是 9 还是 digits[pos]
  • 记忆化时 不能把 tight 存进去（否则状态数翻倍）
  • 统计 [L,R] = calc(R) - calc(L-1)
典型：windy 数、数字游戏、度的数量、数字计数。

典型问题

问题状态额外维度
数位和 ≤ ksum
相邻位差 ≥ 2（windy）lead / last
不含 49pre4 / found
某数字出现次数cnt / found
模 k 余 0rem

三个易错

  • 把 tight 缓存进 lru_cache → 状态爆炸
  • 前导 0 没处理（如"数位和"要排除前导 0）
  • 统计 [L,R] 忘了减 calc(L-1)

与其它主线的关系

数位 DP 是值域 DP 的特例：把"数字"按位拆成"填了什么 + 是否贴界"。当问题变成"子集"时，切换到状压。

本页回答：分治怎么写？
边界怎么处理。

四个关键点

  • opt[i]（最优分割）随 i 单调不降
  • solve(l, r, kl, kr)：求 dp[l..r]，决策在 [kl, kr]
  • 先算中点 m，得到 bestk，再左右递归
  • 上界 kr = min(kr, m-1)（k < m）

适用形态

dp[i][k] = min_{j<i} { dp[j][k-1] + cost(j+1, i) }
分层 DP，逐层调用
O(K·n²) → O(K·n log n)
易错：必须先证 opt[i] 单调，否则分治会漏掉最优分割点。

模板十二：矩阵快速幂

本页回答：线性递推怎么加速？
fib 的索引别取错。

四个关键点

  • 转移必须是线性的（常系数递推）
  • 状态向量 [f[n], f[n-1], ...]
  • A^n = [[F(n+1), F(n)], [F(n), F(n-1)]]
  • fib(n) 返回 R[0][1]，不是 R[0][0]

验证样例

fib(1) = 1, fib(2) = 1, fib(3) = 2
fib(10) = 55
复杂度 O(k³ log n)，k = 状态维度
用途：斐波那契、爬楼梯、铺砖、线性递推计数、图上路径计数（邻接矩阵幂）。

05 · CASES

优化建模案例

本页回答：哪类题想到斜率 / 分治 / 矩阵？
四个典型。

A玩具装箱

题意：把 n 个玩具分成若干段，代价 (Σ+段数-1-L)²，求最小。

建模：转移线性化 → 斜率优化。
答案：O(n log n) → O(n)。

B仓库建设

题意：在 n 个位置选点建仓库，代价含距离与建造。

建模：f[i] = min_j{...} 斜率优化。
答案：O(n)。

C石子合并优化

题意：合并相邻堆，最小总代价。

建模：四边形不等式 → 收窄 opt。
答案：O(n³) → O(n²)。

D铺砖 / 线性递推

题意：2×n 铺砖方案数（n 可达 10⁹）。

建模：转移是线性递推 → 矩阵快速幂。
答案：O(k³ log n)。

共同结构

都是"状态不变，只换转移实现"。识别信号：朴素 DP 能写但超时、转移可线性化。

什么时候不够用

  • 斜率不单调 → 李超线段树
  • 转移非线性 → 矩阵失效
  • 带限制（如恰好 k 段）→ WQS 二分
心法：优化层的通用套路是"先写朴素，再证单调，最后换实现"。

06 · CROSS B

同题三解 B：0/1 背包

本页回答：同一道背包，状态怎么选？
三种维度的甜点。

Q1容量 DP

题意：容量 V，物品有重量和价值，求最大价值。

  • 状态 f[j] = 容量 j 最大价值
  • 倒序遍历 j
  • O(nV) ✅ V ≤ 10⁵

失效：V = 10⁹ 时爆。

Q2价值 DP

题意：同上，但 V 很大、Σv 不大。

  • 状态 f[v] = 价值 v 最小重量
  • 再找最大 v 使重量 ≤ V
  • O(n·Σv) ✅ Σv ≤ 10⁵

失效：Σv 大时爆。

Q3折半搜索

题意：n ≤ 40、V 与 Σv 都大。

  • 对半枚举 2^(n/2)
  • 右侧按重量排序 + 前缀最优
  • O(2^(n/2)) ✅ n ≤ 40

失效：n > 45 时爆。

一句话对照

"状态维度怎么选"取决于哪个维度小。V 小用容量、Σv 小用价值、n 小用折半。三个都大就换模型。

一致性

三种建模答案必须一致——这是最强的正确性检查。cross_check 会把三者对拍。

提醒：换维度时容易漏"恰好装满"的初值语义，务必检查 f[0]=0 还是 -INF。
心法：背包的本质是"选或不放"，维度选择是实现细节——但选错维度就是 TLE。
06 · CROSS C

同题三解 C：石子合并

本页回答："结构型状态 + 优化"怎么走？
三个层次。

Q1暴力递归

题意：合并相邻堆，代价为重量和，最小总代价。

  • 枚举所有合并顺序
  • O(2ⁿ) ✅ n ≤ 15
  • 正确性基准

失效：n > 20 就跑不完。

Q2区间 DP

题意：同上。

  • 状态 f[l][r]，枚举分割点
  • O(n³) ✅ n ≤ 300
  • 环形需断环成链

失效：n = 2000 时 TLE。

Q3四边形不等式

题意：同上，n 更大。

  • opt[l][r] 单调
  • O(n²) ✅ n ≤ 2000
  • 须先证四边形不等式

失效：代价不满足四边形时不适用。

一句话对照

"结构型状态 + 优化"是分层推进的典范：暴力 → 区间 DP → 四边形不等式，每层都保留作对拍。

规约关系

Q3 依赖 Q2 的状态定义（f[l][r]）——优化不改状态，只改转移的搜索范围。这是优化层的本质。

提醒：若代价 w(l,r) 不满足四边形不等式，opt 范围收窄会漏解——先证再写。
心法：看到"合并相邻"，第一反应是区间 DP；看到"n=2000 还要合并"，再想四边形不等式。
06 · REDUCTION

归约关系：谁是谁的特例

本页回答：四条主线能互相转化吗？
哪些不能。
归约方向说明
线性 DP → 背包✅ 成立背包是线性 DP 在值域维度的特例
区间 DP → 矩阵链✅ 成立矩阵链是区间 DP 的原型
区间 DP + 四边形不等式 → O(n²)✅ 前提必须先证 w 满足四边形不等式
斜率优化 → 线性 DP✅ 前提转移须能写成 a[j]·x[i]+b[j]
决策单调 → 分治✅ 成立opt[i] 单调即可
矩阵快速幂 → 线性递推✅ 前提转移须是常系数线性的
数位 DP → 值域 DP✅ 成立数位是值域的按位拆解
状压 DP → 折半搜索⚠️ 部分n 大时可换成折半，但语义不同
树形背包 → 线性背包⚠️ 部分链状树退化成线性背包
贪心 → DP✅ 成立贪心是 DP 的退化（决策唯一）
最短路 → DAG DP✅ 成立DAG 上的 DP 就是最短路
DP → NP-hard 问题❌ 不成立一般 TSP / 装箱无法 DP 化
斜率优化 → 非线性转移❌ 不成立转移不是 a[j]·x[i]+b[j] 就用不了
四边形不等式 → 任意代价❌ 不成立代价不满足时优化会漏解
状压 DP → n > 22❌ 不成立状态数爆内存
有环期望 DP → 递推❌ 不成立需高斯消元，不是 DP

重要结论

  • 背包 ⊂ 线性 DP（值域特例）
  • 矩阵链 ⊂ 区间 DP（原型）
  • 优化层不改状态，只改转移实现

为什么归约有用

把新问题归约到已知主线，就能直接复用状态定义与复杂度结论。
但要先确认归约条件成立（单调、凸性、线性……）。

心法：归约前先问"这个转化保不保最优解"。

06 · IRREPLACEABLE

什么时候必须用哪个

本页回答：四个"不换不行"的场景。
以及换掉会怎样。

线性 DP

  • 序列 / 前缀问题的默认答案
  • 滚动数组可降到 O(1) 空间
  • 最易被斜率优化加速

换掉会：结构问题被硬套线性 → 状态漏信息。

结构 DP

  • 合并 / 分割 / 父子类的唯一自然解
  • 四边形不等式 / Knuth 的入口
  • 树形 + 换根的唯一形式

换掉会：区间问题被硬套线性 → 根本表达不了。

组合 DP

  • n ≤ 20 的集合最优唯一解
  • 数位 / 容量问题的值域表示
  • 折半搜索的入口

换掉会：组合问题被硬套线性 → 状态数指数爆炸。

优化层

  • 朴素能写但超时时的救命稻草
  • 不改状态语义，可独立验证
  • 斜率 / 分治 / 矩阵三件套

换掉会：没有替代品——只能 TLE。

三种"选错"的后果

  • 把区间合并当线性 DP → 状态根本表达不了
  • 把n ≤ 20 集合当线性 DP → 状态数指数爆炸
  • 没证单调就上斜率优化 → 漏解

决策口诀

先问状态形状，再问最后一步，最后问能不能更快。三问定主线。

升华：DP 建模能力 = "把搜索空间压缩成状态空间"，而不是背转移方程。

07 · CORRECTNESS

DP 的"为什么对"：状态与证明

本页回答：DP 成立的三个条件？
怎么证，怎么验。

DP 成立的三个条件

  • 最优子结构：最优解包含子问题的最优解
  • 重叠子问题：子问题被重复计算（否则不必 DP）
  • 无后效性：当前状态只依赖已确定的状态

状态"充分"的判据

两个局面状态相同 ⇔
它们后续的最优决策完全一致
反之，状态就漏信息了

常见漏信息

  • 没把"上一个取了什么"放进状态
  • 没把"是否贴界"放进状态（数位 DP）
  • 没把"剩余容量"放进状态（背包）

证明手法

  • 反证法：若最优解不走最优子解，可替换得更优 → 矛盾
  • 交换论证：任意解可重排成"标准形"且不劣
  • 归纳法：对状态规模归纳
  • 对拍：小数据与暴力一致（最实用）

验证三层

  • 边界：空集、单元素、全相等
  • 不变量：答案与暴力一致
  • 边界用例：n=0/1、全负、全相等、极值

优化前后的对拍

朴素版与优化版必须对拍——优化只改实现，不改语义。任何优化上线前都应通过 stress_dp()。

心法：DP 的正确性是设计出来的——状态定义充分，转移才对；优化上线前必须对拍。
07 · PITFALLS

易错清单 Checklist

本页回答：提交前自检什么？
（每条都对应本讲义的坑）

状态与初值

  • 状态漏关键信息（上一个 / 剩余容量 / 贴界）
  • 初值用 0 而非 ±INF
  • 恰好装满的初值语义写错
  • 状态维度算错 → 2²² 爆内存
  • 数组下标差一（f[i][j] vs f[i-1][j]）

转移与顺序

  • 遍历顺序错（i 依赖 i+1）

  • 区间 DP 没按长度枚举
  • 树形 DP 没按后序遍历
  • 状压没按 |S| 递增遍历
  • 环形没断环

优化与降维

  • 滚动数组方向写反
  • 降维忘了保存 prev
  • 斜率优化没证单调就上
  • 四边形不等式没证就收窄 opt

  • 数位 DP 把 tight 缓存进键

07 · VERIFY

怎么验证建模选对了

本页回答：四种建模怎么互相对拍？
边界用例有哪些。

1跨建模对拍

能用两种建模解的题，必须对拍。brute / dp / 优化 三者一致——这是最强的正确性检查。

3边界用例

  • n = 0 / 1 / 2
  • 全负 / 全正 / 全相等
  • 单元素区间（l == r）
  • 空集（S = 0）
  • 容量 0 / 重量超过容量
  • 数位 DP 的 x = 0
  • 树形 DP 的链 / 星 / 单点

2不变量检查

  • LIS：朴素 ≡ 贪心二分
  • 编辑距离：2D ≡ 1D 滚动
  • 最大子段和：暴力 ≡ DP ≡ 分治
  • 背包：容量 ≡ 价值 ≡ 折半
  • 矩阵链：暴力 ≡ 区间 DP ≡ 四边形
  • 树形 DP：换根 ≡ 暴力（每个点为根）
  • TSP：状压 ≡ 暴力（n ≤ 8）
  • 斜率优化：优化 ≡ 朴素
小技巧：随机打乱输入顺序重跑，答案应不变（除非问题本身有序）。
最强自检：能用两种建模的题，一定对拍；不能的题，用暴力小数据对拍。
