01 · HOOK

四道"互相配对"的题，一个套路

本页回答：网络流能干什么？
它把哪类问题统一了。

题 A

题意：管道有容量，从源到汇最多能送多少水？

→ 最大流。

题 B

题意：最少切断多少容量的管道，才能完全断流？

→ 最小割 = 最大流。

题 C

题意：每条管道有单价，送完指定流量的最小成本？

→ 最小费用流。

题 D

题意：选项目有收益/花费，选了 A 就必须选 B，最大收益？

→ 最大权闭合子图。

★共同点

都是"在带容量的图上做最优的流量分配"。一旦识别出这个结构， 就能套现成算法，不用重新推导。

一句话：网络流把"最优分配类问题"从指数枚举降到 O(V²E)，并附赠对偶量（最小割）。

三个判断题

有"源"和"汇"吗 边有容量限制吗 要不要考虑费用

答对这三题，就知道该用哪个算法。

01 · PROBLEM

先把概念说清楚

本页回答：流网络、可行流、最大流、最小割各是什么？
求的是什么量。
概念定义复杂度说明
流网络有向图 G=(V,E)，边有容量 c(u,v) ≥ 0，指定 s, t—不含反向容量
可行流 f容量约束 + 流量守恒—0 ≤ f ≤ c
流量 |f|源的净流出 = 汇的净流入—目标函数
残量网络c_f(u,v) = c(u,v) − f(u,v)；反向边容量 = f(u,v)—撤销能力
增广路残量网络上 s→t 的路径O(E)沿路加 Δ 流量
最大流流量最大的可行流O(V²E)核心问题
割 (S,T)S ∋ s, T ∋ t；容量 = Σ c(u,v), u∈S, v∈T= 最大流对偶量
最小割容量最小的割= 最大流方案输出
费用流边再带费用 w；求最小总费用O(E log V·f)MCMF
闭合子图u ∈ C 且 u→v ⇒ v ∈ C；最大权= 最小割建模利器
上下界流每条边有流量下限 l(u,v)O(V²E)超级源汇

核心观察

最大流、最小割、闭合子图、上下界流都归约到同一个 Dinic，只是建图不同。

不适用

求所有最大流、非线性费用、一般图匹配（改用带花树）、NP-hard 类（如装箱）。

01 · DEFINITION

流网络与可行流

本页回答：什么叫"合法的流"？
两个约束条件。

两个约束

容量约束 0 ≤ f(u,v) ≤ c(u,v)
流量守恒 ∀v≠s,t: Σ_in f = Σ_out f

流量 |f|

|f| = Σ_v f(s,v) − Σ_v f(v,s)
= 源的净流出 = 汇的净流入
约定：源没有入边、汇没有出边（不影响一般性）。

注意

  • 流可以有反向值（等价于撤销）
  • 容量必须 非负
  • 多条平行边可以合并容量
01 · RESIDUAL

残量网络：反向边是"撤销"

本页回答：为什么必须有反向边？
没有它会错在哪。

定义

正向残量 c_f(u,v) = c(u,v) − f(u,v)
反向残量 c_f(v,u) = f(u,v)
即：已送的流量可以"退回"

反向边的作用

  • 让算法能撤销错误的早期决策
  • 等价于翻转增广路（匹配里的"让位"）
  • 保证 Ford-Fulkerson 正确性
没有反向边的后果：贪心增广后无法回退，最大流会偏小——这是网络流最大的坑。

三条铁律

  • 加边 必须同时加反向边，容量 0
  • 增广时正减反加，同一个 Δ
  • 反向边的反向边指回正向边（rev 索引）
01 · AUGMENT

增广路与 Ford-Fulkerson

本页回答：增广怎么做？
为什么停止就是最大流。

三个定义

  • 增广路：残量网络上 s→t 的路径
  • 瓶颈 Δ = 路径上最小残量
  • 增广：沿路正向减 Δ、反向加 Δ

Ford-Fulkerson 定理

f 是最大流
⇔ 残量网络中不存在 s→t 的路径
类比：和二分图的 Berge 定理完全同构——最大 ⇔ 无增广路。

通用骨架

while 存在 s→t 路径 P:
  Δ = min 残量(P)
  沿 P 增广 Δ　# 正减反加
return |f|

不同算法的差异

  • FF：随便找一条（DFS），可能极慢
  • EK：找最短增广路（BFS）
  • Dinic：一次找一组最短增广路（阻塞流）
  • MCMF：找费用最小的增广路
心法：学算法时永远问一句："它在找哪一种增广路？"
01 · DUALITY

最大流 = 最小割

本页回答：割是什么？
为什么两者相等。

割的定义

划分 (S,T)：s ∈ S，t ∈ T
c(S,T) = Σ c(u,v)，u∈S, v∈T
只算从 S 指向 T 的边

定理

最大流 = 最小割
Ford-Fulkerson 对偶定理
推论：求出最大流就能立刻拿到最小割方案——不用另写算法。

直觉

流"满"了 ⇒ 残量网络断开 ⇒ S = 从 s 还能到达的点集。任何 s→t 的路都必须穿过 S 到 T，所以割容量至少等于流量；又存在割恰好等于流量。

三个应用

  • 方案输出：哪些边被"切断"
  • 最小割计数 / 字典序最小割
  • 闭合子图 / 选与不选建模
注意：割只算 S→T 方向的边；T→S 的边不算。

01 · TRACE

手算：三次增广到最大流

本页回答：增广路怎么选？
逐轮对照残量。

图

点 s, a, b, t
边：s→a(2), s→b(1), a→b(1), a→t(1), b→t(2)

轮次增广路瓶颈 Δ|f|
1s→a→t11
2s→a→b→t12
3s→b→t13
4无增广路—3

对偶验证

割 ({s,a,b}, {t}) 容量 = 1 + 2 = 3
割 ({s}, {a,b,t}) 容量 = 2 + 1 = 3
最大流 = 最小割 = 3 ✓

观察

  • 每轮恰好一条增广路，Δ = 1
  • 第 2 轮走了 a→b，说明不用反向边也可能对
  • 但更复杂的图必须靠反向边才能得到最大流
01 · COMPLEXITY

EK 复杂度：O(V·E²)

本页回答：为什么最短增广路能保证多项式？
单调性的价值。

关键引理

残量网络中，最短增广路长度单调不减
每条边最多成为关键边 O(V) 次
总关键边次数 O(V·E) ⇒ O(V·E²)

对比 DFS 版 FF

  • FF (DFS)：O(E·f*)，与流量值有关
  • 若 f* 极大（如 2⁶⁰），FF 直接挂掉
  • EK 与流量值无关，只与图结构有关

FF 的坏例子

s→a (10⁶), s→b (10⁶), a→t (1), b→t (1), a→b (1)
DFS 可能交替选 s→a→b→t / s→b→a→t
每次只 +1，要 2×10⁶ 轮

什么时候还用 EK

  • n ≤ 500，代码量小、好调试
  • 教学演示"最短增广路"思想
  • 比赛里 Dinic 忘了时的备胎
记忆：EK = "每轮找一条最短路"；Dinic = "每轮把所有最短路一起找完"。

02 · LEVEL

Dinic：分层图 + 阻塞流

本页回答：分层图为什么能加速？
BFS 与 DFS 各干什么。

BFS：建分层

  • level[v] = 残量网络上 s→v 的最短距离
  • 只沿 cap > 0 的边扩展
  • 若 level[t] < 0 ⇒ 无法增广，结束

DFS：阻塞流

  • 只沿 level[v] == level[u] + 1 的边走
  • 一次 DFS 找到一条增广路
  • 反复 DFS 直到无路可走（阻塞流）
  • 再 BFS 重新分层
收益：分层保证只走最短路，DFS 复用层次 ⇒ 一轮找一组增广路。

为什么有效

分层后增广路长度单调不减，一轮内穷尽当前长度的所有增广路 ⇒ 总轮数 ≤ √V 级别（单位容量网络）。

02 · CURRENT ARC

当前弧优化 + 多路增广

本页回答：it 数组是干什么的？
没有它会慢在哪。

当前弧 it[u]

  • 记录 u 的边从哪条开始继续
  • 一条边用尽（残量 0）后不再回头
  • 每轮 BFS 后 it 全部复位

没有它会怎样

DFS 每次从 g[u][0] 开始
反复扫描已经用尽的边
退化到 O(V²E) 甚至更差
收益：把每条边的扫描次数从 O(V) 降到 O(1) 摊还。

多路增广

  • 一次 BFS 后，反复调用 dfs(s, t, INF)
  • 每次返回一条增广路的 Δ
  • 返回 0 ⇒ 本轮阻塞，重新 BFS

易错

  • it 只在 max_flow 里初始化一次 → 错
  • 必须每轮 BFS 后复位
  • INF 要足够大（建议 10**18）
  • 递归深度过大 → 改迭代或提栈
验证：对照第 42 页的 stress()，Dinic 与 EK 必须一致。

03 · MIN-CUT

最小割构造：残量可达集

本页回答：怎么从最大流拿最小割？
为什么这样是对的。

三步

  • 跑完 max_flow（残量留在 g）
  • 在残量网络上从 s BFS，得可达集 S
  • 割 = (S, V\S)；割边 = S 到 V\S 的原图边

原容量怎么恢复

跑完后 g[u][i][1] = 正向残量
g[v][rev][1] = 反向残量 = 已用流量
原容量 = 两者之和
正确性：残量上 s 到不了 t ⇒ S 与 T 被"断开"，这就是最小割。

03 · CLOSURE

最大权闭合子图

本页回答：什么是闭合子图？
为什么转成最小割。

定义

闭合子图 C：u ∈ C 且 u→v ⇒ v ∈ C
"选 u 就必须选 v"的传递闭包
目标：最大化 Σ w(i), i ∈ C

建图

  • 正权点：s → i，容量 w[i]
  • 负权点：i → t，容量 -w[i]
  • 依赖边 u → v：容量 INF（不能被割）
  • 最大权 = 正权总和 − 最小割

直觉

最小割把点分成"选（s 侧）"和"不选（t 侧）"。割掉 s→i 等于"放弃正权 i"；割掉 i→t 等于"接受负权 i 的代价"。INF 依赖边保证不违反依赖。

典型题

  • 太空飞行计划：实验（正权）依赖仪器（负权）
  • 项目选择：收益/成本 + 前置条件
  • 最大密度子图（二分 + 割）
易错：依赖边容量必须是真正够大的 INF（≥ 所有权绝对值之和），否则会被误割。
03 · TEMPLATE

模板三：最大权闭合子图

本页回答：闭合子图怎么写？
方案怎么取。

关键点

  • 正权点接 s，负权点接 t
  • 依赖边容量 = INF
  • 答案 = 正权总和 − 最小割

03 · MEANING

割的含义与方案输出

本页回答：割代表什么决策？
怎么把割转成答案。

1选 / 不选

S 侧 = 选，T 侧 = 不选。割容量 = 付出的总代价。

→ 闭合子图、项目选择

2切 / 不切

割边 = 被切断的管道；最小割 = 最小断流代价。

→ 网络可靠性、防御

3方案输出

把 min_cut 返回的 S 直接翻译成"选中的对象"。

→ 输出具体方案而非数值

进阶：最小割计数

  • 最小割边数：求 1 条最小割，删掉后再求，直到流量变化
  • 字典序最小割：按顺序尝试"把点推到 T 侧"
  • 必须割 / 可选割：改动容量再判

易错

  • 割只算 S→T 方向的边，T→S 不算
  • 必须在 max_flow 之后再 BFS
  • INF 边割不动 ⇒ 依赖不被违反
  • 权可能为负 ⇒ 先判全负/全正情况
心法：凡是"选一组对象、有依赖或冲突、求最优"，先想能不能用割表示代价。

04 · MCMF

费用网络与最小费用流

本页回答：费用流在求什么？
两个目标怎么排优先级。

定义

边 (u,v) 带容量 c(u,v) 与费用 w(u,v)
总费用 cost(f) = Σ w(u,v)·f(u,v)
目标：先流量最大，再费用最小

两种问法

  • 最小费用最大流（MCMF）：流量必须最大
  • 固定流量 k 的最小费用：只增广 k 单位
  • 最大费用流：费用取负，转最小
核心：每次沿费用最短的增广路增广，直到无法增广。

反向边的费用

正向边 (u,v,c,w)
反向边 (v,u,0,-w)
费用取负 ⇒ "退回"要退钱

负权边怎么办

  • SPFA 版：允许负权，但不能有负环
  • Dijkstra 版：用势函数把边权抬成非负
  • 初始有负费用 ⇒ 先用势或 SPFA 初始化
注意：求"最大收益"时把费用设为 -收益，最后取负。

模板四：MCMF（SPFA 版）

本页回答：最朴素的费用流写法。
容易理解、易写错。

流程

  • SPFA 求 s→t 费用最短路
  • 沿路增广 Δ（最小残量）
  • 费用累加 Δ · dist[t]
  • 直到 dist[t] == INF

复杂度

O(V·E·flow)，最坏很慢
实际随机数据通常够用
何时用：n ≤ 500、边少、好调试；或需要支持负权时。

04 · POTENTIAL

势函数：Johnson 抬权

本页回答：为什么 Dijkstra 能用于负权？
势怎么更新。

核心等式

修正边权 w' = w + h[u] − h[v]
可行势：w' ≥ 0
最短路不变（只是整体平移）

势怎么更新

  • 初始 h = 0（或 SPFA 预处理）
  • 每轮 Dijkstra 后 h[i] += dist[i]
  • 只对可达点更新
  • h[s] 恒为 0 ⇒ h[t] = 原图最短路长

为什么对

若 h 是可行势（对残量所有边 w + h[u] − h[v] ≥ 0），Dijkstra 就合法。增广后残量变化，但更新后的 h 仍保持可行性（Bellman-Ford 不等式）。

复杂度

O(E log V · flow)
比 SPFA 稳定得多
  • 比赛默认写法
  • 需要支持负费用时也能用
易错：h[i] += dist[i] 必须在 cost += d * h[t] 之前执行。
04 · TEMPLATE

模板五：MCMF（Dijkstra + 势）

本页回答：费用流标准实现。
建议闭卷默写。

关键点

  • 边存 [v, cap, cost, rev]
  • 反向边 cost = -w
  • 每次 heappush 用 w + h[u] - h[v]
  • cost += d * h[t]（不是 dist[t]）

变体

  • 最大费用：cost 取负
  • 只送 k 单位：if flow == k: break
  • 无费用最大流：cost 全 0（退化为 Dinic 的 EK 版）
自检：对照 SPFA 版，flow 与 cost 必须一致。

费用流对比与负环

本页回答：SPFA 与 Dijkstra 怎么选？
负环怎么处理。
方案时间负权负环推荐
MCMF (SPFA)O(V·E·flow)✓会挂n 小 / 好调试
MCMF (Dijkstra+势)O(E log V·flow)✓（初值可行）会挂默认
消圈算法O(V·E·flow)✓✓一般费用流
上下界费用流O(E log V·flow)✓需预处理有流量下限

负环的三种情况

  • 题目保证无负环 ⇒ 直接跑
  • 有负环 ⇒ 用消圈或先消去负环
  • 负环在残量里出现 ⇒ 说明初始可行流不对

易错清单

  • 反向边费用写成 +w → 全错
  • cost += d*dist[t] 而非 d*h[t] → 费用错
  • 势未对可达点更新 → 权重变负，Dijkstra 挂
  • 求最大收益忘了取负 → 结果反号
记忆：费用流 = "Dinic 的思想 + 最短路的骨架"。

05 · PATTERN A

套路 A：最大权闭合子图

本页回答：闭合子图怎么认？
用太空飞行计划走一遍。

题意（太空飞行计划）

有 m 个实验，做实验 i 获利 p_i；每个实验需要若干仪器，购买仪器 j 花费 c_j。每种仪器可重复用于多个实验。求最大利润。

建模

  • 实验 = 正权点（p_i）
  • 仪器 = 负权点（-c_j）
  • 实验 → 所需仪器 = 依赖边 INF
  • 最大利润 = Σp − 最小割
方案：残量上 s 可达的实验 = 要做的；可达的仪器 = 要买的。

验证样例

实验：A(+10)、B(+8)；仪器：X(−5)、Y(−3)
A 需 X；B 需 X、Y
都做：10+8−5−3 = 10；只做 A：10−5 = 5
答案 10，选 {A, B, X, Y}

易错

  • 依赖边容量不够大 → 依赖被"割断"
  • 把仪器也当正权点 → 公式错
  • 忘了减 Σp → 结果是割不是收益
  • 仪器可复用 ⇒ 依赖边方向别搞反
举一反三：项目选择、最大密度子图（二分密度后转割）都是同一骨架。

套路 B：拆点

本页回答：点有容量/费用怎么办？
下标怎么定。

核心

  • 点 u 拆成 u_in = 2u，u_out = 2u+1
  • u_in → u_out：容量 = 点容量，费用 = 点费用
  • 进 u 的边改连 u_in；出 u 的边改从 u_out 出

三种用途

  • 每人只能做 1 个任务 → 点容量 1
  • 点最多经过 k 次 → 点容量 k
  • 经过点要交税 → 点费用 > 0
典型：最长递增子序列（不相交计数）、深海机器人、火星探险。

套路 E：上下界可行流

本页回答：流量有下限怎么办？
符号约定最易写反。

符号约定（关键）

边 (u,v,l,r)：拆成 u→v 容量 r−l
b[u] -= l，b[v] += l
b[i] > 0 ⇒ SS → i（要净流出）
b[i] < 0 ⇒ i → TT（要净流入）

06 · ADAPT

改一改就能用：四个改点

本页回答：换一道题要改哪里？
只有四处。

1建图

谁是源、谁是汇；边的含义是什么（可连接 / 可使用 / 可传输）。

2求解量

最大流 → max_flow；最小割 → min_cut；最优代价 → MCMF。

3输出

数值、方案、割边、选中点集——都是同一份残量网络的不同视角。

4规模

看 V, E 决定用 Dinic、ISAP 还是 MCMF；有费用用势函数版。

换题检查表

  • 源 / 汇的语义搞对了吗？
  • 容量的语义是"限制"还是"代价"？
  • 要的是数值还是具体方案？
  • 有没有费用 / 下界 / 顺序约束？

什么时候该换框架

有费用 → MCMF；有下界 → 上下界流；有奇环匹配 → 带花树；NP-hard → 回溯/DP/启发式。

别硬上：把 NP-hard 问题硬套网络流，结果是"错"而不是"略差"。
06 · VERIFY

怎么验证答案是对的

本页回答：三种算法怎么互相对拍？
边界用例有哪些。

1三算法对拍

暴力 FF 作基准，与 EK / Dinic 比对。随机小图 1000 组，三个数必须完全相等。

3边界用例

  • 无边图（流 0）
  • 单条边（流 = 容量）
  • s 与 t 不连通
  • 容量为 0 的边
  • 重边（容量相加）
  • 自环
  • 全 INF 容量

2不变量检查

  • 最大流 = 最小割（必查）
  • 残量网络上 s 不可达 t
  • 每点流量守恒
  • flow ≤ Σ出边容量(s)
  • 闭合子图满足闭合性
  • MCMF 两版 flow / cost 一致
小技巧：随机打乱点编号重跑，答案应不变——能抓出下标类 bug。
最小割自检：遍历所有边，确认 S→T 的容量之和 = 最大流。
