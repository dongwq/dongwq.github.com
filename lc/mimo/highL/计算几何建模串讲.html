02 · CROSS

叉积：一个符号判三态

本页回答：叉积到底在判什么？
符号怎么来的。

核心公式

(b-a) × (c-a) = (bx-ax)(cy-ay) − (by-ay)(cx-ax)

> 0 → c 在 ab 左侧（左转 / 逆时针）
< 0 → c 在 ab 右侧（右转 / 顺时针）
= 0 → 三点共线

为什么不用 EPS

整数坐标下叉积是整数，符号完全精确。只有当坐标是浮点、或经过除法 / 开方之后，才需要 EPS。

心法：能用整数就别用浮点——精度是算出来的，不是调出来的。

点积在判什么

(p-a)·(b-a) > 0 → p 在 a 侧 之后
(p-a)·(b-a) < 0 → p 在 a 侧 之前
叉积判"左右"，点积判"前后"。二者配合 = 点在不在线段上

02 · DOT

点积：投影与距离

本页回答：点积判什么？
与叉积怎么配合。

三个用法

  • 前后：(p-a)·(b-a) 的符号
  • 投影：t = (p-a)·(b-a) / |b-a|²
  • 距离：|(p-a)×(b-a)| / |b-a|

点到线段的距离

t ≤ 0 → 最近点是 a
t ≥ 1 → 最近点是 b
0 < t < 1 → 垂足，距离 = |叉积| / |ab|
先判 t，再算距离——顺序不能反

叉积 vs 点积

叉积点积
判什么左右（方位）前后（投影）
公式x₁y₂ − x₂y₁x₁x₂ + y₁y₂
几何有向面积投影长度
典型共线、相交、方向距离、垂足、夹角

易错

  • 忘了判垂足区间 → 垂足落在线段外也当垂足
  • 距离开方过早 → 精度丢失，应全程用平方直到最后
  • 把点积当叉积用 → 方位判反
心法：叉积管"哪边"，点积管"多远"，两个一起用才完整。
02 · TEMPLATE

模板二：线段相交

本页回答：跨立试验怎么写？
退化情况怎么处理。

三个关键

  • 严格相交：o1*o2 < 0 and o3*o4 < 0
  • 退化（端点 / 共线重叠）单独特判

02 · PRECISION

精度处理：整数化优先

本页回答：误差从哪来？
怎么规避。
来源风险规避策略
整数 + 叉积无直接比较，不要套 EPS
浮点加减法灾难性抵消避免 a + b - a 类运算；用 long double
浮点乘除相对误差累积控制运算次数；用 decimal / 有理数
开方 / 三角函数不可逆全程用平方比较，最后才开方
排序比较不一致导致 TLE / RE比较器必须严格弱序，EPS 不参与排序
坐标范围大int64 溢出Python 任意精度安全；C++ 用 __int128 / long double
退化（重合 / 共线）分母为 0特判或符号扰动（微小随机偏移）
输出精度格式错误按题目要求固定小数位，不要自己猜

整数化技巧

  • 坐标乘以 10^k 转整数
  • 距离比较用平方
  • 面积用叉积和（精确）

EPS 该怎么定

  • 相对误差：abs(a-b) < EPS * max(1, abs(a), abs(b))
  • 常见 1e-9（double）、1e-12（long double）
  • 绝不参与排序

终极方案

  • 有理数精确算术（分数类）
  • 符号扰动处理退化
  • Shewchuk 的精确谓词库
心法：精度是设计出来的——能用整数就用整数，非用浮点就全程平方比较。

03 · POINT LOCATION

点定位：射线法 vs 转角法

本页回答：两种判定怎么选？
绕数是什么。

射线法（Ray Casting）

  • 向右发射水平射线
  • 统计与边的交点个数
  • 奇数 → 内部，偶数 → 外部
  • 边界点单独判（on_segment）
技巧：条件写成 (a.y > p.y) != (b.y > p.y)，自动处理顶点重复计数。

转角法（Winding Number）

  • 累加有向转角（或绕数）
  • wn == 0 → 外部；否则内部
  • 比射线法更稳（退化边多时）

对比

射线法转角法
返回内外（可含边界）绕数（含嵌套信息）
退化需特判水平边天然稳健
复杂度O(n)O(n)
适用简单多边形简单 / 带孔

易错

  • 忘记判边界点 → 答案少一个状态
  • 射线方向恰好过顶点 → 重复计数
  • 多边形不简单（自交）→ 两种方法都不对

升级

多边形固定时，预处理成梯形剖分或三角剖分，可用二分做到 O(log n) 定位。

核心

半平面 = 直线的一侧（线性不等式）
a·x + b·y ≤ c ⇔ 一个半平面
n 个半平面的交 = 凸多边形（或空）

算法骨架

  • 按极角排序
  • 同一极角只保留最内侧
  • 双端队列维护候选边界
  • 收尾时两头再清理一遍
心法：把"约束"编码成半平面，把"可行"编码成交集，把"最优"编码成顶点枚举。

三个易错

  • 同极角没保留最内侧 → 队列错乱
  • 没加包围盒 → 无界区域返回空
  • EPS 取太大 → 真实顶点被误删

04 · BINARY SEARCH

二分答案：最优 → 判定

本页回答：什么时候能二分？
判定怎么做。

适用条件

  • 目标单调：最小化最大 / 最大化最小
  • 判定问题容易（比原问题简单得多）
  • 值域有界、可离散或可实数二分

骨架

while lo < hi:
  mid = (lo + hi) // 2
  if check(mid): hi = mid
  else: lo = mid + 1
check = 一个几何判定（叉积 / 凸包 / 半平面交）

几何里的典型判定

  • 能否用半径 T 的圆覆盖所有点？
  • 所有点到某直线的距离是否 ≤ T？
  • 是否存在一条线把两类点分开且间距 ≥ T？
  • 可行域在目标方向上是否非空？

易错

  • 二分实数时终止条件写成 == → 死循环
  • 判定函数不单调 → 答案错
  • 取 mid 用 (lo+hi)/2 但没处理负数 → floor 语义错
  • 忘了扩大值域（初值上下界太窄）
心法：先证明单调性，再写二分——证不出来就换方法。

05 · CROSS B

同题三解 B：最大面积三角形 · 最小圆覆盖

本页回答：同一模式（凸包 + 极值）
怎么迁移到不同目标。

最大面积三角形

  • 暴力 O(n³) ✅ 小数据
  • 凸包 + 暴力 O(h²) ✅ 三点都在包上
  • 凸包 + 卡壳 O(h²) ✅ Fischer-Heun
  • 半平面交 ❌ 不适用
模式：与 A 题完全同构——先凸包化，再在包上找极值。

最小圆覆盖

  • 随机增量（Welzl） O(n) 期望 ✅ 最优
  • 凸包预处理 ✅ 边界点必在包上，常数优化
  • 二分答案 + 判定 ⚠️ 理论可行但判定本身 O(n)，不划算
模式：与 A 题不同构——最优圆的边界点不必是对径点，卡壳不适用。

最小圆覆盖（Welzl 随机增量）

核心：三点定圆（外接圆）
circumcircle(a,b,c) → 圆心 + 半径
共线时退化为最远两点的直径圆

期望 O(n)：随机打乱点序，逐点检查；不在当前圆内的点成为新边界点，递归重算。

关键差异

  • 直径：凸包 + 卡壳（确定性）
  • 最小圆：随机增量（随机算法）
  • 最大三角形：凸包 + 枚举（同一模式）
心法：识别"最优值的边界点在哪"——在凸包上？在对径点上？在三点上？答案不同，工具就不同。
05 · CROSS C

同题三解 C：多约束可行性

本页回答："求交"归谁？

Q1可行域是什么？

题意：给 n 条线性约束 aᵢx + bᵢy ≤ cᵢ，求可行域。

  • 半平面交 ✅ 直接
  • 凸包 ❌（不是点集问题）
  • 卡壳 ❌（没有凸包）

答案：可行域多边形 / 面积。

Q2最优在哪取到？

题意：在可行域上最大化 px·x + qy·y。

  • 半平面交 + 顶点枚举 ✅
  • 二分答案 + 判定 ✅
  • 凸包 ❌（可行域不是点集）

答案：最优值（在顶点取到）。

Q3最小距离？

题意：可行域内一点到定点 s 的最小距离。

  • 凸包 + 卡壳 ✅（若可行域是凸包）
  • 二分答案 + 判定 ✅
  • 半平面交 ⚠️ 需先求交再算

答案：最小距离。

一句话对照

"求交"问的是形状，用半平面交；"求极值"问的是最优，用卡壳 / 二分。两者方向不同，不能互换。

凸包在哪

Q1 上完全用不上凸包——凸包是"点集的最小凸集"，不是"约束的交"。强行套凸包，答非所问。

提醒：工具不是越多越好，选对一个比套三个更重要。
心法：问"要求形状还是求最优"——这一个词就能定工具。

05 · IRREPLACEABLE

什么时候必须用哪个

本页回答：三个"不换不行"的场景。

叉积

  • 所有几何判定的原子：O(1) 精确
  • 共线 / 相交 / 方向的基础
  • 整数坐标下零误差
  • 浮点版本也能做，但会丢精度

换掉会：精度崩坏，边界全错。

凸包

  • 极值压缩：n → h 个点
  • 直径 / 宽度 / 面积 / 包含
  • 线性函数最值的唯一入口
  • 最小圆覆盖的边界点也在包上

换掉会：慢 2~3 个数量级，或根本做不了。

半平面交

  • 多线性约束的可行域：唯一自然解
  • 线性规划的几何入口
  • 可行域面积 / 顶点 / 包含
  • 最大内切圆的候选顶点

换掉会：问题无解（其他工具表达不了）。

  • 把最近点对当凸包问题 → 答案错
  • 把圆约束塞进半平面交 → 无意义解
  • 用浮点 == 0 判共线 → 边界全崩

决策口诀

先问判定什么，再问要不要压缩，最后问要求交还是求极值。三问定工具。

06 · NUMERICS

数值稳定性：设计出来的

本页回答：误差从哪来？
怎么在设计期规避。

五条铁律

  • 整数优先：叉积、面积、行列式全用整数
  • 平方比较：距离、半径全程平方，最后才开方
  • 符号扰动处理退化（重合点、共线）
  • 相对误差：abs(a-b) < EPS * max(1, |a|, |b|)
  • 绝不让 EPS 参与排序

误差累积链

加减 → 灾难性抵消（a+b-a）
乘除 → 相对误差累积
开方 / 三角 → 不可逆，最后再算
运算次数越多，误差越大——减少运算

各精度方案对比

方案精度速度适用
整数坐标精确最快题目允许
long double高快常规浮点
有理数 / 分数精确慢必须精确
符号扰动精确判定快退化多
精确谓词库精确快竞赛终极

典型翻车

  • 浮点 == 0 判共线
  • 排序比较器含 EPS → 不严格弱序 → sort 报错
  • int64 溢出（C++）→ Python 安全
  • 面积取 abs 后丢掉方向信息
心法：精度是设计出来的——在写第一行代码前就定好"用什么数、怎么比"。
06 · PITFALLS

易错清单 Checklist

叉积 / 判定

06 · VERIFY

怎么验证工具选对了

本页回答：三种工具怎么互相对拍？
边界用例有哪些。

1跨工具对拍

能用两种工具解的题，必须对拍。brute_diameter2 vs hull_diameter2，答案必须相等——这是最强的正确性检查。

3边界用例

  • 空点集 / 单点 / 两点
  • 全部共线 / 全部重合
  • 正方形 / 矩形 / 正三角形
  • 凸包只有 2 个点（退化卡壳）
  • 半平面交空集 / 无界
  • 大坐标（10⁹，测溢出）
  • 小数坐标（测 EPS）

2不变量检查

  • 凸包正确性：所有点在包内或包上（orient ≥ 0）
  • 直径 = 暴力（必查）
  • 最近点对 = 暴力（必查）
  • 射线法 ≡ 转角法（非边界点）
  • 鞋带面积 ≡ 三角剖分面积
  • 半平面交：每个顶点满足所有约束
  • 最小圆：所有点在圆内，至少 2~3 点在圆上
小技巧：随机整体旋转 / 平移点集重跑，答案应不变（旋转卡壳对刚体变换不变）。
最强自检：能用两种工具的题，一定对拍；不能的题，用暴力小数据对拍。

07 · SUMMARY

带走这 五句话

本页回答：如果只能记住一页，
就记这一页。
1
几何建模 = 把几何描述翻译成代数判定。问清楚"要判定什么"。
2
整数优先。叉积、面积、行列式全用整数，精确比较不套 EPS。
3
先凸包化，再找极值。线性函数最值在顶点，直径宽度在对径点。
4
约束求交是半平面交的主场。凸包是点集的最小凸集，不是约束的交。
5
最近点对不在凸包上。识别"最优值的边界点在哪"，工具就定了一大半。
升华：几何建模最值得学的不是模板，而是"把几何翻译成代数"的判断力——方向、极值、约束、单调，四个词定一切。这一条判断力，比任何单个算法都值钱。
