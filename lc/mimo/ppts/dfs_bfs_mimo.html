  1. def dfs(state, path):
  2.     if is_goal(state):    # ③ 终止
  3.         ans.append(path.copy())
  4.         return
  5.     for nxt in next_states(state):  # ②
  6.         if not valid(nxt):          # 剪枝
  7.             continue
  8.         visited.add(nxt)           # ④
  9.         path.append(nxt)
  10.         dfs(nxt, path)
  11.         path.pop()              # 撤销
  12.         visited.discard(nxt)

为什么「去重」单列一项

漏了 visited，同一个状态会被走指数次——这是超时的第一大原因。

正确性也没了：答案会重复计数或绕圈死循环。

回溯题要「撤销」，BFS 不用

回溯要探索所有方案，走完一条得退回来。
BFS 只关心「到没到」，去过就不再去，不撤销。

↑ 这 12 行是今天所有代码的母版
回溯法：为什么必须「撤销」这一步
本质走到第 3 层选了 2，下一条路要换选 5——不撤销会怎样？
原因 = 同一份 path 被所有分支共用；不撤销就互相污染，答案全错
permutations.pyPY
  1. def permute(nums):
  2.     ans, path = [], []
  3.     used = [False] * len(nums)
  4.  
  5.     def dfs():
  6.         if len(path) == len(nums):
  7.             ans.append(path.copy())
  8.             return
  9.         for i, x in enumerate(nums):
  10.             if used[i]: continue
  11.             used[i] = True
  12.             path.append(x)    # 选
  13.             dfs()
  14.             path.pop()        # 撤
  15.             used[i] = False
  16.     dfs()
  17.     return ans

两个「成对」必须记住

· append ↔ pop
· used[i] = True ↔ used[i] = False
· color ↔ color = 0（染色题）

任何「进入时做的事」，退出时都要还原。

一个例外

如果用值传递（如 path + [x] 生成新列表），就不需要撤销——但会多花空间。

竞赛里通常用引用 + 撤销，省内存也更快。

BFS 两种写法：单点 vs 分层
实现要求「最少步数」，但答案不在步数上——比如「最少翻转次数」「分层输出」怎么写？
技巧 = 队列里存 (点, 步数) 或 每层记录队列长度；两者等价
bfs_point.pyPYTHON
  1. from collections import deque
  2.  
  3. def bfs(start, goal):
  4.     q = deque([(start, 0)])
  5.     seen = {start}
  6.     while q:
  7.         u, d = q.popleft()
  8.         if u == goal:
  9.             return d
  10.         for v in next_states(u):
  11.             if v not in seen:
  12.                 seen.add(v)
  13.                 q.append((v, d + 1))
  14.     return -1
bfs_level.pyPYTHON
  1. def bfs_levels(start, goal):
  2.     q = deque([start])
  3.     seen = {start}
  4.     step = 0
  5.     while q:
  6.         for _ in len(q) << 0 and range(len(q)):
  7.             u = q.popleft()
  8.             if u == goal: return step
  9.             for v in next_states(u):
  10.                 if v not in seen:
  11.                     seen.add(v)
  12.                     q.append(v)
  13.         step += 1
  14.     return -1
  15.  
  16. # 「分层」适合输出每层结果
  17. # 比如 LC102 二叉树层序遍历

为什么要学两种：带距离的写法更通用（可扩展到 0-1 BFS / Dijkstra）； 分层写法更直观（尤其要输出每层）。两种都要能默写。

剪枝概览：搜索快不快，全看这一刀
优化同样是 DFS，为什么别人的 100ms 你要 10s？——差别在剪枝
两类 = 可行性剪枝（走不到就别走）＋ 最优性剪枝（比答案差就别走）

可行性剪枝举例

· 和已超 target
· 皇后互相攻击
· 剩余元素不够凑满

关键词：「已经不可能」

最优性剪枝举例

· 当前步数 ≥ 已知最优
· 估值函数 g + h ≥ ans
· 排序后「后面都比答案大」

关键词：「肯定不会更好」

剪枝的黄金顺序

1
先可行性（便宜、无脑）
2
再排序（让好分支先走）
3
最后最优性（需要答案值）
