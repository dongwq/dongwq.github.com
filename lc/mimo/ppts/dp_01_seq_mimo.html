两道题的答案，其实是同一张表

你从家到公司，中间要换乘地铁。

你不会每到一站都重新思考一次「整个旅程怎么走最优」。

你会先确定：到第 k 站的最优走法，
再看：从第 k 站出发，下一段怎么走。

最优子结构的意思：
如果整条路线是最优的，那它上面每一段也一定是那一段的最优。
关键不在「聪明」，在于肯不肯记下中间结果
①

存什么？

状态（state）＝ 你要记下来的那个量。

爬楼梯：dp[i] = 到第 i 级的走法数
背包：dp[j] = 容量 j 的最大价值
股票：dp[i][k][0/1]

状态定错，后面全白写。
②

怎么转？

转移（transition）＝ 大的怎么由小的拼出来。

dp[i] = dp[i-1] + dp[i-2]
dp[j] = max(dp[j], dp[j-w]+v)
dp[i][j] = dp[i-1][j-1] + 1

要能「拼」出最优解，且无后效性。
③

从哪开始？

初始条件（base）＝ 最小的那几格。

dp[0]=1, dp[1]=1
dp[0]=0（背包）
dp[i][0]=i（编辑距离）

答案一般在 dp[n]。

记忆化做了什么：
它没有改变递归的想法，只是保证「每个状态只算一次」。
时间从 指数 降到 状态数 × 转移数。
代价：多一个记账本，空间 O(状态数)。
而且每个状态算完要立刻写回，否则白算。
同一句递归代码，只多了三行
情形为什么记忆化更合适
① 递推顺序不好定 比如要「从终点往回走」、区间 DP、树形 DP，自顶向下天然顺着题意，不必先想清楚填表顺序。
② 状态是稀疏的 只有部分状态会被真正访问（如记忆化 DFS、博弈搜索）。 递推会把整张表填满，记忆化只算用到的那几个。
③ 想先保证对 先写暴力递归并验证正确，再加三行记忆化。这是最不容易出错的路线。
反过来，如果状态就是一条直线、顺序一眼可见（爬楼梯、背包）， 递推更短、更快、还能压空间，就用递推。

最后一步，你是怎么停在第 i 级的？

只有两种可能：
从 i−1 迈 1 级上来，或者 从 i−2 迈 2 级上来。

这两类走法互不重叠，所以方案数把它们相加。

dp[i] = dp[i-1] + dp[i-2]
为什么是 + 不是 max？
数「方案数」要把不同类的走法合起来；
求「最值」才用 max / min。
转移式的样子：右边 = 左边已知格子的函数

climb_memo.py · 记忆化搜索
  1. memo = {}
  2. def f(n):
  3. if n <= 1:
  4. return 1
  5. if n in memo:
  6. return memo[n]
  7. memo[n] = f(n - 1) + f(n - 2)
  8. return memo[n]
climb_dp.py · 递推填表
  1. def climb(n):
  2. dp = [0] * (n + 1)
  3. dp[0] = 1
  4. dp[1] = 1
  5. for i in range(2, n + 1):
  6. dp[i] = dp[i - 1] + dp[i - 2]
  7. return dp[n]
climb_o1.py · 压缩到两个变量
  1. def climb(n):
  2. a, b = 1, 1
  3. for i in range(2, n + 1):
  4. a, b = b, a + b
  5. return b
记忆化 O(n) 时间 / O(n) 空间
递推 O(n) 时间 / O(n) 空间
压缩版 O(n) 时间 / O(1) 空间

LeetCode 518 · 凑出 amount 的组合数

dp[j] = 凑出金额 j 的组合数
dp[j] += dp[j - coin]
dp[0] = 1（什么都不取也是一种方案）
为什么是 +=？
因为「最后放的是哪一枚硬币」是互不重叠的分类， 把所有类的方案数加起来。
如果外层循环是硬币、内层正序金额，每种组合只被数一次。
反过来（外层金额）会把顺序不同算成不同方案。
coin_change_2.py
  1. def change(amount, coins):
  2. dp = [0] * (amount + 1)
  3. dp[0] = 1
  4. for c in coins:
  5. for j in range(c, amount + 1):
  6. dp[j] += dp[j - c]
  7. return dp[amount]

  1. def can_partition(nums):
  2. s = sum(nums)
  3. if s % 2:
  4. return False
  5. half = s // 2
  6. dp = [False] * (half + 1)

  9. for j in range(half, x - 1, -1):
  10. dp[j] = dp[j] or dp[j - x]
  11. return dp[half]

lcs.py
  1. def lcs(s1, s2):
  2. n, m = len(s1), len(s2)
  3. dp = [[0] * (m + 1) for _ in range(n + 1)]
  4. for i in range(1, n + 1):
  5. for j in range(1, m + 1):
  6. if s1[i - 1] == s2[j - 1]:
  7. dp[i][j] = dp[i - 1][j - 1] + 1
  8. else:
  9. dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
  10. return dp[n][m]

stock_fee.py
  1. # 每次卖出要交 fee 元手续费
  2. def max_profit(p, fee):
  3. hold = -p[0]
  4. cash = 0
  5. for i in range(1, len(p)):
  6. hold, cash = max(hold, cash - p[i]), \
  7. max(cash, hold + p[i] - fee)
  8. return cash
为什么可以压成两个变量

第 i 天只用到第 i−1 天的两个值，
那就不用 hold[i]、cash[i] 两个数组，两个变量足够。

压维的判断标准：
转移只用到「上一行 / 上一个」的固定几个值， 就可以滚动覆盖。
若两行互相依赖，必须先保存旧值或同时赋值， 否则会用到已被本行更新过的数字。
O(n) → O(1)
