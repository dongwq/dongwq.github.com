两种访问限制：LIFO 与 FIFO

什么时候用栈

问题里出现「嵌套」「配对」「撤销」「最近」「回退」这些词。

典型：括号匹配、表达式、DFS、路径压缩。

什么时候用队列

问题里出现「按顺序」「同时进行」「层次」「最短步数」「公平」这些词。

典型：BFS、拓扑排序、任务调度、滑动窗口。

栈：定义、接口与复杂度
定义只在一端（栈顶）进行插入删除的线性结构
栈接口 = push / pop / top / empty，四操作均 均摊 O(1)

四个接口的语义

1
push(x) 放到栈顶，旧的暂时看不见
2
pop() 取走栈顶，顺序不可跳过
3
top() 只看不取，用于决策
4
empty() 判空，pop 前必查

为什么是「均摊 O(1)」而不是「最坏 O(1)」

数组扩容时一次 push 是 O(n)，但 n 次 push 总代价仍是 O(n)，均摊下来 O(1)。竞赛中直接写 O(1) 就行。

栈的「隐藏能力」

栈顶永远是「最新且未解决」的元素。这个性质是后面单调栈的全部来源——记住这句话。

↑ 这句话后面会反复用到
Python 实现：用 list，但别用错
代码Python 的 list 就是动态数组，append/pop(末尾) 都是均摊 O(1)
用 list.append / list.pop 当栈；禁止 pop(0)（那是 O(n) 的队列行为）

什么时候用 collections.deque

只需要栈时 list 更快；既当栈又当队列时用 deque（两端操作都是 O(1)）。

为什么转变：从「一个栈」到「两个栈」

单栈只能记住「顺序」，但运算还需要记住「等待中的值」。把数据与操作分开放，问题立刻清晰——这是「分而治之」的最小示范。

  3. # ---------- 递归写法 ----------
  4. def inorder_rec(root, res):
  5.     if not root: return
  6.     inorder_rec(root.left, res)
  7.     res.append(root.val)
  8.     inorder_rec(root.right, res)
  9.  
  10. # ---------- 显式栈写法 ----------
  11. def inorder_iter(root):
  12.     st, cur, res = [], root, []
  13.     while cur or st:
  14.         while cur:           # 一路向左，全部入栈
  15.             st.append(cur)
  16.             cur = cur.left
  17.         cur = st.pop()     # 回到最近的未访问节点
  18.         res.append(cur.val)
  19.         cur = cur.right     # 转向右子树
  20.     return res

应用④ 最小栈：栈内「额外维护一个答案」

下一章预告：队列

栈给「最近」，队列给「最早」。当问题从「嵌套」变成「扩散」，就该换结构了。

我们将会看到：为什么 BFS 能保证最短，以及为什么不能用栈代替队列做 BFS。

NEXT · FIFO ORDER & BFS
队列：先来先服务，天然公平
定义只在一端插入（队尾）、另一端删除（队头）的线性结构
队列接口 = enqueue / dequeue / front，均 均摊 O(1)，语义 FIFO
O(n) deque.popleft() 是 O(1) → 队列必用 deque 队列 = 「按发生顺序处理」 所以它天然是公平调度的模型

队列的语义

「谁先来，谁先被处理」。
所有「层次 / 扩散 / 逐层推进」的问题，都落在这个语义上。

与栈的语义对照

维度栈 LIFO队列 FIFO
取出顺序最近入的最早入的
思维模型嵌套 / 回退扩散 / 分层
典型应用括号、表达式、DFSBFS、拓扑、调度
答案性质「最近的匹配」「最近的最短」
Pythonlist 即可必须 deque
← 用 list 当队列是老手也常犯的错
Python 实现：collections.deque 的三种用法
代码deque 两端操作都是 O(1)，队列、栈、双端队列全能覆盖
deque = 双端 O(1)，queue 模块过慢，竞赛一律用 deque

⚠️ 三个坑

1
list.pop(0) 慢，deque 才是正解
2
queue.Queue 带锁，竞赛不要用
3
deque 不支持 任意下标访问（O(n)）

为什么 deque 两端都 O(1)

内部是分块的双向链表（块状数组），两端插入删除只改指针，不搬移元素。代价是随机访问慢。

→ 所以：要顺序处理用 deque，要随机查询用 list / 数组。

竞赛速写模板

from collections import deque
q = deque([start])
while q: u = q.popleft()

这一行 popleft() 就是 BFS 的全部起点。

应用⑤ BFS：网格最短路的万能模板
题意给定 n×m 的 0/1 网格（0 可走），从左上走到右下，每步四方向，求最少步数（不可达返回 -1）
BFS = 队列存「当前层的所有起点」，第一次到达即最短，到达后立刻标记
dist 值，最多相差 1， 且单调不减 —— 这就是「分层」。 ⚠️ 入队时立刻标记 visited， 否则同一格会被重复入队。
grid_bfs.pyPYTHON
  1. from collections import deque
  2.  
  3. def min_steps(grid):
  4.     n, m = len(grid), len(grid[0])
  5.     if grid[0][0] == 1 or grid[n-1][m-1] == 1:
  6.         return -1
  7.  
  8.     q = deque([(0, 0)])
  9.     dist = [[-1]*m for _ in range(n)]
  10.     dist[0][0] = 0
  11.  
  12.     while q:
  13.         x, y = q.popleft()
  14.         if (x, y) == (n-1, m-1):
  15.             return dist[x][y]
  16.         for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
  17.             nx, ny = x+dx, y+dy
  18.             if 0 <= nx < n and 0 <= ny < m \
  19.                 and grid[nx][ny] == 0 \
  20.                 and dist[nx][ny] == -1:
  21.                 dist[nx][ny] = dist[x][y] + 1
  22.                 q.append((nx, ny))
  23.     return -1
  24.  
  25. # 复杂度 O(n·m)：每格最多入队一次
  26. # 加 visited 数组可省去 dist 的 -1 判断
为什么 BFS 一定给出最短路？
证明不理解这一层，BFS 就只是「背模板」——换个题就不会用
性质 = 队列 dist 单调不减 ⇒ 第一次到达即最短；用反证法一步可证

不能用栈代替队列

栈会「深度优先」，先走进一条长路，第一次到达 T 时距离不是最短。

DFS 求最短路需要遍历完所有路径，退化成指数级。

BFS 的三个前提

1
边权相等（通常为 1）
2
入队时立即标记，防止重复
3
要记录路径时，额外存 parent

边权不等时怎么办？

换 Dijkstra + 堆（下一章），或 0-1 BFS（双端队列，见下一页）。

这是「为什么要转变」的典型例子：边权一变，队列就不够用了。

做法：权 0 走队头，权 1 走队尾，保持 dist 有序。

下一章：单调结构

栈和队列只解决了「顺序」，还没解决「效率」。当问题里有「下一个更大 / 窗口最值」，朴素做法是 O(n²)。

下一章我们要做的事：把「候选答案集合」裁剪成单调的，让每次查询变成 O(1)。

NEXT · MONOTONE STACK & QUEUE
为什么需要「单调」：把候选集裁掉无用的
动机再看一遍「下一个更大元素」——现在我们知道该怎么想了
单调性 = 栈内元素按值有序；新元素一来，比它小的全 pop 掉，不再有资格
最多入栈一次、 出栈一次。 ⇒ 总操作 2n 次 ⇒ 摊销 O(n)，不是 O(n²)

为什么要裁剪

栈里如果同时存 4 和 2，那么只要 2 在栈里，4 永远轮不到被选。

这种「永远不可能成为答案」的元素，就该立刻扔掉。

如何裁剪

把栈维护成单调（递增或递减，取决于题意）。

新元素入栈前，先把被它「压死」的都 pop 掉。

于是栈内元素按值有序，栈顶就是当前最优候选。

为什么转变：从「存全部」到「存候选」

朴素做法：把所有元素都留下，逐个比较 → O(n²)。

单调做法：只留下还有机会的，其他立刻丢 → O(n)。

这是「用空间换时间」的另一种形态：用「维护有序」换「查询 O(1)」。

← 「出栈即得答案」是单调栈的核心
单调栈：Next Greater Element 的标准推导
题意给定数组 a，对每个 i 求右侧第一个严格大于 a[i] 的元素下标，不存在则为 -1
维护 单调递减栈（存下标）；新元素 > 栈顶 ⇒ 栈顶的答案就是新元素
值单调递减（存下标）

摊销分析：为什么是 O(n) 而不是 O(n²)
证明会写代码还不够，能讲清楚复杂度，才能换题也用得对
摊销 = 单次可能 O(n)，但 n 次总和仍是 O(n)；计数法一步证明
最多 push 一次： P ≤ n 每个下标 最多 pop 一次（pop 后不再回来）： Q ≤ n 总操作数 = P + Q ≤ 2n ⇒ O(n)，与 n² 无关 ⚠️ 常见误解 「while 循环里还有 pop」看起来是嵌套循环， 但每次 pop 都永久减少栈大小，所以不会退化。 同样的分析适用于： 单调队列、并查集路径压缩、KMP

换个角度：势能法

定义势能 Φ = 当前栈大小。

1
push：Φ 增加 1，实际代价 1
2
pop：Φ 减少 1，摊销代价 ≤ 2
3
总摊销代价 = O(n) ∎

为什么一定要理解这个

不知道摊销，就会在 while 循环里加 break，以为「这样会快一点」——反而错。

知道摊销，你就敢放心写经典的 while st and ...: st.pop()骨架。

常见同类题

· 单调栈 / 单调队列
· 并查集路径压缩
· KMP 的 fail 指针回退
· 持续 top() + pop() 的滑动查询

一句话：凡是「回退后不再回来」的结构，都摊销 O(n)。

应用⑥ 直方图最大矩形：单调栈的满分题
题意给定非负数组 heights 表示柱子高度，求能勾出的最大矩形面积（柱宽均为 1）

largest_rectangle.pyPYTHON
  1. def largest_rectangle(heights):
  2.     h = heights + [0]    # 哨兵：清空栈
  3.     st, best = [], 0
  4.  
  5.     for i, v in enumerate(h):
  6.         while st and h[st[-1]] > v:
  7.             top = st.pop()
  8.             left = st[-1] if st else -1
  9.             best = max(best, h[top] * (i - left - 1))
  10.         st.append(i)
  11.  
  12.     return best
  13.  
  14. # 哨兵 +0 的作用：结束时强制清空栈，
  15. # 避免再写一遍「收尾处理」的代码
  16. # 时间 O(n)，空间 O(n)

sliding_window_max.pyPYTHON
  1. from collections import deque
  2.  
  3. def max_sliding_window(nums, k):
  4.     dq, res = deque(), []  # 存下标
  5.  
  6.     for i, v in enumerate(nums):
  7.         while dq and nums[dq[-1]] <= v:
  8.             dq.pop()     # 淘汰无望者
  9.         dq.append(i)
  10.         if dq[0] <= i - k:
  11.             dq.popleft()  # 过期
  12.         if i >= k - 1:
  13.             res.append(nums[dq[0]])
  14.  
  15.     return res
  16.

为什么转变：从「栈」到「队列」

窗口会滑走，所以最早进来的元素可能过期——必须能从左端删。

而「淘汰无望者」需要从右端删。两端都能删 ⇒ deque。

· 存下标，才能判断是否过期
· 出队条件写 <= i-k，别写 <
· 从 i >= k-1 开始收集结果
· 求最小值：把 <= 改 >=

单调队列优化 DP：从「扫窗口」到「取窗口」

  2.  
  3. def max_result(nums, k):
  4.     n = len(nums)
  5.     dp = [0] * n
  6.     dp[0] = nums[0]
  7.     dq = deque([0])  # 存下标，dp 值递减

  12.         dp[i] = dp[dq[0]] + nums[i]
  13.         while dq and dp[dq[-1]] <= dp[i]:
  14.             dq.pop()       # 淘汰无望者
  15.         dq.append(i)
  16.  
  17.     return dp[-1]

扩展：单调栈求「每个元素的管辖范围」
题意给定数组 a，对每个 i，求 a[i] 作为最小值的最长区间 [L, R]（区间内 a[i] 最小）
正向一次求 L（上一个更小），反向一次求 R（下一个更小），两次 O(n) 合并
left[i] 第 2 次：递增栈（反向），求 right[i] 答案 = a[i] × (right[i] - left[i] - 1) WHY USEFUL 「子数组最小值之和」「最大矩形」 都依赖这一步的 L / R 计数。
range_min_span.pyPYTHON
  1. def min_span(a):
  2.     n = len(a)
  3.     left = [-1] * n      # 左侧第一个更小
  4.     right = [n] * n      # 右侧第一个更小
  5.  
  6.     st = []
  7.     for i in range(n):
  8.         while st and a[st[-1]] >= a[i]:
  9.             st.pop()
  10.         left[i] = st[-1] if st else -1
  11.         st.append(i)
  12.  
  13.     st = []
  14.     for i in range(n-1, -1, -1):
  15.         while st and a[st[-1]] > a[i]:
  16.             st.pop()
  17.         right[i] = st[-1] if st else n
  18.         st.append(i)
  19.  
  20. # 注意两次的比较符不同（>= 与 >）：
  21. # 这是为了「相同元素不重复计数」
  22. # 统一用 > 会导致区间重叠、答案翻倍
  23.  
  24.     return left, right

为什么转变：从「队列」到「堆」

队列只能「谁先来谁先走」；但 Dijkstra 里，我们要「当前距离最小的先走」。

顺序被优先级替代 ⇒ 需要能随时取出全局最优的结构 ⇒ 堆。

典型应用

· Top-K：维护大小为 k 的小根堆
· 合并 K 个有序：每次取堆顶最小
· Dijkstra：堆优化到 O((V+E) log V)
· 任务调度 / 中位数：双堆

↑ 大根堆取相反数，是 Python 的固定套路
堆的三大应用：Top-K、合并、Dijkstra
代码三个最常考的堆应用，各一行核心代码就能说清
Top-K 用 大小 k 的小根堆；合并用 元组堆；Dijkstra 用 (距离, 点) 堆

  13.             if d + w < dist[v]:
  14.                 dist[v] = d + w
  15.                 heapq.heappush(h, (d+w, v))
  16.     return dist
  17.  
  18. # 复杂度 O((V+E) log V)
  19. # 边权必须非负

合并 K 个：堆里是「k 条链的队头」

Dijkstra：堆里是「还没确定的候选点」

反向：两队列成栈

入栈：push 到非空的那个队列。出栈：把前 n-1 个搬到另一队，剩下的就是栈顶。

代价比双栈成队更贵（每次出栈都搬），均摊 O(n)——题目多考思路而非效率。

topo_kahn.pyPYTHON
  1. from collections import deque
  2.  
  3. def can_finish(n, edges):
  4.     g = [[] for _ in range(n)]
  5.     deg = [0] * n
  6.     for u, v in edges:  # v → u
  7.         g[v].append(u); deg[u] += 1
  8.  
  9.     q = deque([i for i in range(n)
  10.                     if deg[i] == 0])
  11.     seen = 0
  12.     while q:
  13.         u = q.popleft(); seen += 1
  14.         for w in g[u]:
  15.             deg[w] -= 1
  16.             if deg[w] == 0:
  17.                 q.append(w)
  18.  
  19.     return seen == n
  20.  
  21. # 复杂度 O(V+E)
  22. # 求「字典序最小」拓扑：把 deque 换成堆

为什么用队列，不用栈

拓扑排序里所有入度为 0 的点是平级的，谁先处理都行。用队列保证「按层推进」，让排序结果更稳定可预测。

若用栈，结果虽也合法，但顺序变成 DFS 序——某些题目要求字典序最小时反而要换堆。

真题演练 A：洛谷 P5788 单调栈模板
题意给定长度为 n 的数列 a，对每个 i 输出右边第一个比 a[i] 大的元素的下标（从 1 开始），不存在输出 0
解法 = 从右往左扫，维护单调递减栈；栈顶即「右边第一个更大的下标」

审题三步

1
输出下标，不是值 → 栈存下标
2
下标从 1 开始，不存在输出 0
3
「右边第一个」→ 反向扫描更直接
4
「比它大」→ 严格大于，条件用 <= 清栈

为什么反向扫更简单

正向扫需要「出栈时回填答案」，反向扫则「栈顶直接就是答案」，代码更短，边界更少。

两种都能过，选自己不容易写错的那个。

真题演练 B：LeetCode 239 滑动窗口最大值
题意给定数组 nums 与窗口大小 k，窗口从最左滑到最右（每次右移 1），输出每个窗口的最大值
解法 = 单调递减 deque 存下标；队头过期就出，队尾无望就出

三种解法对比

1
暴力：每窗口扫 k 个 → O(nk) TLE
2
堆：延迟删除，下标判过期 → O(n log n)
3
单调队列 → O(n) ✅ 首选

为什么堆不够好

堆能拿到最大值，但没法知道它是否过期，只能「惰性删除」——pop 时才检查。

单调队列天然有序 + 天然知道边界，是唯一能达到 O(n) 的写法。

拓展

· 求最小值：改比较符
· 求窗口第 k 大：要平衡树 / 二分
· 窗口不同元素数：哈希 + 队列

  1. from collections import deque
  2.  
  3. def maxSlidingWindow(nums, k):
  4.     dq = deque()  # 存下标，对应值递减
  5.     res = []
  6.  
  7.     for i, v in enumerate(nums):
  8.         # 1) 淘汰「无望」的队尾
  9.         while dq and nums[dq[-1]] <= v:
  10.             dq.pop()
  11.         dq.append(i)
  12.  
  13.         # 2) 淘汰「过期」的队头
  14.         if dq[0] <= i - k:
  15.             dq.popleft()
  16.  
  17.         # 3) 窗口成型后收集
  18.         if i >= k - 1:
  19.             res.append(nums[dq[0]])
  20.  
  21.     return res
  22.  
  23. # 时间 O(n)，空间 O(k)
  24. # 每个下标至多进出 deque 各一次
