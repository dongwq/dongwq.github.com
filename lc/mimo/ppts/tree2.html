RECURSION →三行区别
def preorder(n):
    if not n: return
    visit(n)                    # ① 先访问根
    preorder(n.left); preorder(n.right)

def inorder(n):
    if not n: return
    inorder(n.left)
    visit(n)                    # ② 左完访问根
    inorder(n.right)

def postorder(n):
    if not n: return
    postorder(n.left); postorder(n.right)
    visit(n)                    # ③ 最后访问根
KEY · 一句话
三行代码相同，只是 visit 的位置不同。

所以遍历问题，几乎都是「把 visit 放对位置」。

from collections import deque

def level_order(root):
    if not root: return []
    q = deque([root])
    ans = []
    while q:
        level = []
        for _ in range(len(q)):   # 一次一层
            n = q.popleft()
            level.append(n.val)
            if n.left:  q.append(n.left)
            if n.right: q.append(n.right)
        ans.append(level)
    return ans
KEY · 一句话
「按层」是 BFS 的本质：队列保证同层先进先出，所以天然一层一层走。

MORRIS · 09 / 30

Morris 遍历：O(1) 空间

不用栈，也不用递归 —— 把叶子的空指针临时指向「中序后继」。
IDEA · 线索化
D 的右指针平时是 None，Morris 把它临时指向 B（中序后继）。
走完左子树后，顺着这条「假指针」回到 B，就省掉了整个栈。

代价：改动了树结构，访问完必须改回来。
COMPLEXITY
时间 O(n)，空间 O(1)。
（每条边最多走 2 次，总操作仍 ≤ 2n）
SPACE →O(1)TIME →O(n)
def inorder_morris(root):
    cur = root
    while cur:
        if not cur.left:
            visit(cur); cur = cur.right
        else:
            pre = cur.left          # 找左子树最右
            while pre.right and pre.right != cur:
                pre = pre.right
            if not pre.right:
                pre.right = cur     # 建线索
                cur = cur.left
            else:
                pre.right = None    # 拆线索
                visit(cur)
                cur = cur.right

        if target == root.val:

        if target < root.val:

def max_depth(root):
    if not root:              # ① 终止
        return 0
    L = max_depth(root.left)     # ② 左答案
    R = max_depth(root.right)    # ② 右答案

def gain(n):
    global best
    if not n: return 0
    L = max(gain(n.left),  0)  # 负数不要
    R = max(gain(n.right), 0)
    best = max(best, n.val + L + R)  # 拐弯路径

def lca(root, p, q):
    if not root or root == p or root == q:
        return root
    L = lca(root.left,  p, q)
    R = lca(root.right, p, q)
    if L and R: return root   # 两边都找到 → 我是 LCA
    return L or R               # 否则把找到的那个往上传

利用 BST 的有序性

BST 的中序 = 有序。所以「第 k 小」「区间和」「验证」全都能 O(log n) 或 O(n)。
USE →中序 + 计数
# ① 第 k 小：中序遍历第 k 个就是答案
def kth(root, k):
    st, cur = [], root
    while cur or st:
        while cur:
            st.append(cur); cur = cur.left
        cur = st.pop()
        k -= 1
        if k == 0: return cur.val
        cur = cur.right

# ② 验证 BST：中序序列必须严格递增
def is_bst(root):
    prev = None
    def walk(n):
        nonlocal prev
        if not n: return True
        if not walk(n.left): return False
        if prev is not None and n.val <= prev: return False
        prev = n.val
        return walk(n.right)
    return walk(root)
PATTERN · BST 三类套路

B · 二分查找：比根大走右，比根小走左 → O(log n)

C · 递归 + 边界：给子树传上下界 → 验证、剪枝

def traverse(start, get_next, seen):
    # 树：get_next = lambda n: [n.left, n.right]
    # 图：get_next = lambda v: adj[v]
    # 树：seen 可以省；图：必须有
    st = [start]; seen.add(start)

        # 换 deque.popleft() = BFS

陷阱二：递归栈溢出

斜树（退化成链）时，深度 = n，Python 默认约 1000 层就不行了。
RecursionError: maximum recursion depth exceeded
  File "main.py", line 3, in depth
    return 1 + depth(n.left)
FIX · 两条路
import sys
sys.setrecursionlimit(100000)  # 只是把栈做大
# 更稳：显式栈
st = [(root, 1)]
best = 0
while st:
    n, d = st.pop()
    if not n: continue
    best = max(best, d)
    st.append((n.left,  d + 1))
    st.append((n.right, d + 1))
COMPARE · 递归 vs 显式栈
写法栈在哪风险
递归系统调用栈深度受限、慢
显式栈堆内存可控、不炸
KEY · 一句话
递归 = 用系统栈做 DFS。
斜树很深时，改写成显式栈是最稳的写法。
THINK · 什么时候要担心
节点数 n 可能达到 10^5 时，默认别用递归。

TRAP 03 · 25 / 30

陷阱三：结构选错

用数组存稀疏树、用 BST 找极值、用排序求 Top-K —— 都能跑，但代价不同。
✗ 稀疏树用数组存
深度 20 的树，2²⁰ ≈ 100 万个位置，实际只有 21 个节点 → 空间浪费 99%。
✓ 稀疏树用链式存
每个节点 3 个字段，总空间 O(n)。
需求该用别用原因
按序查找BST / 平衡树普通二叉树无序就要 O(n) 扫描
反复取极值堆BST堆取极值 O(1)，BST 要 O(log n)
Top-K大小 k 的小顶堆全排序排序 O(n log n)，堆 O(n log k)
存储完全二叉树数组（2i+1/2i+2）链式数组无指针、缓存友好
深度可能很大的树显式栈 / BFS递归避免 RecursionError

五步解题流程

从「读题」到「交卷」，每一步只回答一个问题。
STEP 1
看节点
单节点、左、右、整树 —— 我要处理哪一层？
STEP 2
选遍历
前 / 中 / 后 / 层？决定「谁先被处理」。
STEP 3
定返回
返回值代表什么问题的答案？（递归第一性问题）
STEP 4
写模板
判空 → 递归左 → 递归右 → 合并。
STEP 5
测边界
空树、单节点、斜树（退化链）、全同值。

一页复习卡

主线收在这里：先处理谁，用谁的答案算我。
CARD 1 · 遍历
前序 根左右；中序 左根右；后序 左右根。
visit 的位置不同，代码只差一行
层序用 deque；Morris 用 O(1) 空间。
CARD 2 · 结构
链式：通用；数组：完全二叉树专用（2i+1 / 2i+2）。
BST 中序 = 有序；AVL 防退化；堆管极值
CARD 3 · 性质
层 i 最多 2^i 个；深度 k 最多 2^(k+1)−1 个；
n₀ = n₂ + 1；n 个节点的形态数 = 卡特兰数
CARD 4 · 分治
判空 → 求左右答案 → 合并成我 → 返回。
路径类：局部链返回，全局答案单独更新
区分「拐弯路径」与「向上链」。
