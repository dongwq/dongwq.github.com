树的定义：五种等价说法，一条也别记错
定义「无环连通图」和「n 个点 n-1 条边」哪个是定义？——它们等价，但用在不同场合
等价 = 连通无环 ⇔ n 点 n−1 边 ⇔ 任意两点一条路；换着用，各有方便
is_tree.pyPYTHON
  1. def isTree(n, edges):
  2.     if len(edges) != n - 1:   # 说法 ②
  3.         return False
  4.     g = [[] for _ in range(n)]
  5.     for u, v in edges:
  6.         g[u].append(v)
  7.         g[v].append(u)
  8.  
  9.     seen = [False] * n
  10.     def dfs(u, p):
  11.         seen[u] = True
  12.         for v in g[u]:
  13.             if v == p: continue
  14.             if seen[v]: return False  # 有环
  15.             if not dfs(v, u): return False
  16.         return True
  17.  
  18.     if not dfs(0, -1): return False
  19.     return all(seen)  # 说法 ①：连通

为什么要知道「五种等价」

因为不同题目的突破口不一样：判树用 ①②，算距离用 ③，写递归用 ④，找祖先用 ⑤。

能互相转换，就是真懂了。

「无根树」与「有根树」

图本身没有根；但算法里常指定一个根（一般取 0 或 1），就变成了有根树。

换根 = 换个视角，树本身没变。换根 DP 就靠这个。

为什么要存 depth

树上几乎所有问题都要「比较谁更深」。第一遍 DFS 把 depth / par / 子树大小 一次性算出来，后面所有算法都用它。

这就是「预处理」的第一次出场。

E997 · 找到小镇的法官入度出度LC ↗ ★3P1352 · 没有上司的晚会邻接表建树LG ↗
← 「第一遍 DFS 预处理」是树上的通行做法
树的遍历就是 DFS / BFS 的特例
抽象上一讲学的搜索，在树上会发生什么变化？——visited 可以不要了！
转变 = 图上要 visited → 树上只需记住「别走回父亲」；少一个参数，快一半

为什么可以不要 visited

因为树无环，不会走回头路。

唯一的「回头」就是走回父亲，判一下就行。

这带来什么好处

1
省一个 visited 数组，常数更小
2
代码更短更不容易错
3
天然支持回溯（进什么样出什么样）

两种顺序

· DFS：深度优先，栈 / 递归

· BFS：层序，队列

树上 BFS 就是「层序遍历」，层数 = 深度。

记住这句转变：图上问「能不能到」，树上问「怎么到」。 树因为唯一路径，问题往往更简单、更结构化——这就是今天所有算法能做下去的前提。

← 「v != p」三个字符顶掉一个数组
递归思维：树 = 根 + 若干子树
核心这是今天最重要的一句话——所有树问题的通用解法
核心 = 「我的答案」由「子树的答案」决定；写出这一句，代码就是翻译

为什么这个模板能通吃

因为子树还是树——同一个函数能调用自己。

只要题目满足「最优子结构」（子树答案能合成父答案），就能套。

四个最常问的「递归问」

1
以 u 为根的子树，答案是多少？
2
u 选 / 不选，分别多少？
3
从 u 向下的最长 / 最大？
4
u 子树里 有几个 满足条件？

选定一个「递归问」，代码就自然出来了。

↑ 「问子树 → 合起来 → 加自己」是万能三步
深度、高度、度：三个最容易混的概念
概念「树的高度是多少」「某点的深度是多少」——两个问题的方向是相反的
区别 = 深度从根往下数，高度从叶往上数；度 = 孩子个数
depth_height.pyPY
  1. # 一次 DFS 同时算出两者
  2. def dfs(u, p):
  3.     h = 0
  4.     for v in g[u]:
  5.         if v != p:
  6.             depth[v] = depth[u] + 1
  7.             h = max(h, dfs(v, u) + 1)
  8.     height[u] = h
  9.     return h
  10.  
  11. # 「度」= 孩子个数
  12. # deg[u] = len(g[u]) 无向
  13. # 叶子 ⇔ deg = 1（无向）/ 0（有根）
  14. # 树高 = height[root]

⚠ 一个约定坑

「深度」有的书从 1 开始，有的从 0。题目没说时自己统一，别混。

竞赛默认根深度 = 1 或 0 都有，看题面例子。

← 「一次 DFS 同时算深度和高度」
建树与判树：题目给的输入怎么变成树
实现输入给的是「n-1 条边」，但算法要「有根树」——怎么转？有环怎么办？
流程 = 建邻接表 → 从任意点 DFS 定根 → 记录 par / depth；一次 DFS 全搞定

  1. import sys
  2. sys.setrecursionlimit(1 << 25)
  3.  
  4. def build(n, edges):
  5.     g = [[] for _ in range(n)]
  6.     for u, v in edges:
  7.         g[u].append(v)
  8.         g[v].append(u)

  10.     par = [-1] * n
  11.     depth = [0] * n
  12.     size = [1] * n
  13.     order = []  # DFS 序
  14.  
  15.     def dfs(u, p):
  16.         par[u] = p
  17.         order.append(u)
  18.         for v in g[u]:
  19.             if v == p: continue
  20.             depth[v] = depth[u] + 1
  21.             dfs(v, u)
  22.             size[u] += size[v]
  23.     dfs(0, -1)  # 0 当根
  24.     return g, par, depth, size, order

这一个函数是后面所有算法的地基

par / depth / size / DFS 序 一次算完。

后面 LCA、直径、差分、重心全都复用它——所以这一页要默写。

记住「根的位置」就够了

根在前 → 前序，根在中间 → 中序，根在最后 → 后序。

不用背三个名字，看代码里 append 在哪。

为什么必须「有中序」

因为中序才分左右。只有前序+后序不能唯一确定二叉树。

例外：完全二叉树，前序/后序都能唯一确定。

最小深度的坑

「为什么不够」是关键一问

朴素法每次最多跳一步。如果能一次跳 2^k 步，就能把 O(n) 降到 O(log n)。

下一页就是这个转变。

← 「一次跳 2^k 步」是下一页的全部
倍增 LCA：一次跳 2^k 步
技巧把「一步一步往上跳」换成「二进制跳跃」——预处理 fa[u][k]，查询 O(log n)
转变 = fa[u][k] = u 的第 2^k 个祖先；预处理 O(n log n)，查询 O(log n)
lca_binary_lift.pyPY
  1. LOG = 20  # n < 2^20
  2. fa = [[-1]*LOG for _ in range(n)]
  3.  
  4. # ① 预处理（一次 DFS + DP）
  5. def dfs(u, p):
  6.     fa[u][0] = p
  7.     for k in range(1, LOG):
  8.         if fa[u][k-1] != -1:
  9.             fa[u][k] = fa[fa[u][k-1]][k-1]
  10.     for v in g[u]:
  11.         if v != p:
  12.             depth[v] = depth[u] + 1
  13.             dfs(v, u)
  14.  
  15. # ② 查询
  16. def lca(u, v):
  17.     if depth[u] < depth[v]: u, v = v, u
  18.     # 先拉到同一深度
  19.     for k in range(LOG-1, -1, -1):
  20.         if depth[u] - (1 << k) >= depth[v]:
  21.             u = fa[u][k]
  22.     if u == v: return u
  23.     for k in range(LOG-1, -1, -1):
  24.         if fa[u][k] != fa[v][k]:
  25.             u = fa[u][k]; v = fa[v][k]
  26.     return fa[u][0]

因为要逼近但不超过目标。二进制贪心：从高位试起，能跳就跳。

反过来（从小到大）就会跳过头。

  4.         self.t = [0] * (4 * self.n)
  5.         self.build(1, 0, self.n-1, a)
  6.  
  7.     def build(self, o, l, r, a):
  8.         if l == r:
  9.             self.t[o] = a[l]; return
  10.         m = (l + r) // 2
  11.         self.build(o*2, l, m, a)
  12.         self.build(o*2+1, m+1, r, a)
  13.         # 合并信息（这里是和）
  14.         self.t[o] = self.t[o*2] + self.t[o*2+1]
  15.  
  16.     def update(self, o, l, r, i, x):
  17.         if l == r: self.t[o] = x; return
  18.         m = (l + r) // 2
  19.         if i <= m: self.update(o*2, l, m, i, x)
  20.         else: self.update(o*2+1, m+1, r, i, x)
  21.         self.t[o] = self.t[o*2] + self.t[o*2+1]

树状数组 vs 线段树

· 树状数组：短、快，但只支持「可差分」操作
· 线段树：通用，最值、异或、乘法、区间赋值都行

↑ 「合并信息」四个字是线段树的全部
并查集：森林里的「认亲」问题
题意初始 n 个点各自成树，多次「合并两个点」与「查询两点是否同树」——怎么快？
技巧 = find 路径压缩 ＋ union 按大小；几乎 O(1)
dsu.pyPYTHON
  1. class DSU:
  2.     def __init__(self, n):
  3.         self.p = list(range(n))
  4.         self.sz = [1] * n
  5.  
  6.     def find(self, x):
  7.         while self.p[x] != x:
  8.             self.p[x] = self.p[self.p[x]]  # 路径减半
  9.             x = self.p[x]
  10.         return x
  11.  
  12.     def union(self, a, b):
  13.         a, b = self.find(a), self.find(b)
  14.         if a == b: return False
  15.         if self.sz[a] < self.sz[b]: a, b = b, a
  16.         self.p[b] = a
  17.         self.sz[a] += self.sz[b]
  18.         return True

两个优化都要有

1
路径压缩：find 时顺手把点挂到根
2
按大小合并：小树挂到大树

两者一起用才到 α(n)；只用一个会退化。

  2. def dfs_tree(n, g):
  3.     tree = [[] for _ in range(n)]
  4.     seen = [False] * n

  7.     def dfs(u, p):

  16.

  18.     return tree, back

最小生成树：Kruskal 的贪心
题意给定带权无向图，求一棵连接所有点、边权和最小的生成树——怎么求？
贪心 = 边从小到大排序，不成环就收；并查集判环，O(E log E)
kruskal.pyPY
  1. def kruskal(n, edges):
  2.     # edges: (w, u, v)
  3.     edges.sort()
  4.     dsu = DSU(n)
  5.     total = 0
  6.     cnt = 0
  7.     for w, u, v in edges:
  8.         if dsu.union(u, v):  # 不成环
  9.             total += w
  10.             cnt += 1
  11.             if cnt == n - 1: break
  12.     return total if cnt == n - 1 else -1
  13.  
  14. # 为什么贪心正确？
  15. # 「切割性质」：任意一种切割，
  16. # 跨越的最小边一定在某个 MST 里
  17. # 反证法 + 交换边即可证明

「贪心为什么对」要能说

用切割性质证：每次挑最小且不形成环的边，一定属于某个 MST。

Prim 与 MST 的另一种思路
对照Kruskal 是「按边挑」，Prim 是「按点扩」——什么时候用哪个？
Prim = 像 BFS 一样扩，每次取「最近的未访问点」；稀疏图用 Kruskal，稠密用 Prim
prim.pyPYTHON
  1. import heapq
  2.  
  3. def prim(n, g):
  4.     # g[u] = [(w, v), ...]
  5.     seen = [False] * n
  6.     h = [(0, 0)]  # (边权, 点)
  7.     total = 0; cnt = 0
  8.     while h and cnt < n:
  9.         w, u = heapq.heappop(h)
  10.         if seen[u]: continue
  11.         seen[u] = True
  12.         total += w; cnt += 1
  13.         for nw, v in g[u]:
  14.             if not seen[v]:
  15.                 heapq.heappush(h, (nw, v))
  16.     return total if cnt == n else -1
  17.  
  18. # Prim ≈ Dijkstra（换合并方式）
  19. # 稠密图用朴素 O(V²) 版更快

什么时候用哪个

· 稀疏图（E ≈ V）：Kruskal，好写
· 稠密图（E ≈ V²）：朴素 Prim O(V²)
· 只求值：两者都行
· 要输出边：Kruskal 更自然
