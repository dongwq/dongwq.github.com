02

问题：静态区间最值

给一个不再变动的数组，反复回答「[l, r] 里最大 / 最小是多少」。这类问题有个标准缩写：RMQ（Range Minimum Query）。

不动，答案其实早就藏在数组里了—— 问题就变成：怎么把「答案」提前算好，又不占太多内存？
FIG.02 · 每次都从头扫，是最大的浪费
THE STATIC CASE三个前提
数组不动
没有「把 a[i] 改成 x」这类操作
询问极多
通常 10⁵ ~ 10⁶ 次
回答要快
最好 O(1) 甚至更快
RMQ
Range Min / Max Query 的统称
KEY IDEA用「倍增」分段缓存

提前算好所有长度为 2 的幂的区间的答案。任意长度都能拆成两个 2 的幂。

要查 7 格？拆成 4 + 4（允许重叠一格）。

◆ 重叠是关键技巧，但只有部分运算能容忍它

04

核心思想：倍增拼块

不用为每个区间都存答案，只存长度是 2 的幂的那些。任意长度都能拼出来。

FIG.04 · 长度 7 = 4 + 4，靠重叠补齐
WHY POWERS OF TWO为什么是 2 的幂

任何正整数都能写成 2 的幂之和：7 = 4 + 2 + 1。但为了O(1) 查询， 我们不逐块加，而是让两个大块重叠——只要能容忍重复贡献就行。

预存
长度 1, 2, 4, 8, … 的块
块数
每种长度 n 个 → 共 n·log n 个
查询
选最大的 ≤ 区间长度的块，用两个
THE OVERLAP TRICK重叠为什么是好事

如果必须严格不重叠，长度 7 就要拆成 4+2+1，三段，查询就变 O(log n) 了。

允许重叠后，永远只需要两段，这才是 O(1) 的来源。

定义：st[i][j]

整张表只有一条定义。下标 i 是起点，j 是 2 的幂指数。

FIG.05 · 同一个起点 i=5，四种长度
DEFINITION唯一的一条定义
st[i][j] = op( a[i] … a[i + 2j − 1] )

读作：从 i 出发，连续 2j 个元素的答案（最值 / gcd / …）。

◆ j 是「幂次」不是长度 · 长度 = 2j
DIMENSIONS表有多大
第一维
起点 i = 1 … n
第二维
幂次 j = 0 … ⌊log₂ n⌋
总格数
n · (⌊log₂ n⌋ + 1)
例
n = 10⁵ → 约 1.7 × 10⁶ 格
06

递推：从两半拼出整段

整张表不是从零算起，而是用短块的答案拼出长块的答案。

FIG.06 · 一段长度 4，由两段长度 2 拼成
RECURRENCE递推公式
st[i][j] = op( st[i][j−1] ,
             st[i + 2j−1][j−1] )

左半从 i 起，长度 2j−1；右半从 i + 2j−1 起，长度同样 2j−1。两半首尾相接，不重不漏。

ORDER填表顺序
  1. 先填 j = 0：就是原数组本身
  2. 再用 j−1 层填 j 层，一层层往上
  3. 最外层循环放 j，内层放 i
◆ 依赖关系只有一层，不会有环
07

查询：两段，不多不少

先算一个 k，然后只读两个格子。这就是 O(1) 的全部内容。

len = r − l + 1→k = ⌊log₂ len⌋→ st[l][k]+st[r−2ᵏ+1][k]
FIG.07 · 两次数组访问，一次 op 运算
THE FORMULA查询公式
k = ⌊log₂(r − l + 1)⌋
ans = op( st[l][k] ,
          st[r − 2k + 1][k] )

左块从 l 起，右块从 r−2k+1 起，两块长度都是 2k。

WHY TWO为什么两块就够
左块
从 l 起，长 2k → 覆盖 [l, l+2k−1]
右块
到 r 止，长 2k → 覆盖 [r−2k+1, r]
覆盖
因为 2k+1 > len ≥ 2k，两块必然盖住全区间
重叠
长度 = 2k+1 − len ≥ 0 格
08

重叠为什么合法：幂等性

这是全篇最容易错的一环。同样是 ST 表，min 可以，sum 不行。

FIG.08 · 同一个查询，运算不同，结果天差地别
IDEMPOTENCE幂等是什么

一个运算 op 若满足 op(x, x) = x，就叫幂等。 幂等意味着重复的元素不改变答案。

min / max
min(7,7)=7 ✓
gcd / lcm
gcd(x,x)=x ✓
AND / OR
x&x=x，x|x=x ✓
sum / xor
x+x=2x ✗
CAREFUL更准确的说法

严格说，条件是「可重复贡献」：把元素任意复制若干份后答案不变。 这比幂等更宽，但对绝大多数题，用幂等来记就够。

◆ 区间和 / 区间异或 / 区间积 / 区间最大子段和 —— 都不能直接用 ST 表
09

哪些运算能用

看到题先问一句：「这个 op，把元素重复几次，答案会变吗？」不变就能用。

GREEN LIST可以用
  • 区间最小值 · min　op(x,x)=x
  • 区间最大值 · max
  • 区间最大公约数 · gcd
  • 区间最小公倍数 · lcm
  • 区间按位与 · AND
  • 区间按位或 · OR
  • 区间最值的下标（谁最大）
◆ 记法：凡是 op(x,x)=x 的，都行
RED LIST不能直接用
  • 区间和　重叠会重复计数
  • 区间异或　重复一次就把值抵消掉
  • 区间乘积　重叠会变平方
  • 最大子段和　答案不只由端点决定
  • 区间众数　无法合并两段
◆ 区间和请用前缀和 · 可修改请用线段树
GREY AREA能，但要换写法

区间异或虽然不能用 ST 表，但前缀异或直接 O(1) 解决： px[r] ^ px[l-1]。

反过来，前缀和能解决的，通常不需要 ST 表。两者是互补关系。

细节：log₂ 怎么算最快

查询时要算 k = ⌊log₂ len⌋。这一小步写不好，会拖慢甚至写错。

TAB.11 · 对照表，一目了然
BEST预处理一个 lg 数组
// lg[i] = ⌊log2(i)⌋　i = 0..n
lg[0] = -1;
for(int i=1; i<=n; i++) lg[i] = lg[i>>1] + 1;

// 查询时 O(1)
int k = lg[r - l + 1];

一次 O(n) 预处理，之后每次查询纯数组读。

ALTERNATIVES其它写法

模板代码 C++

三个函数：build、query。剩下的都是细节。

C++ · 静态区间最小值
const int N = 1e5 + 5;
const int LOG = 17;              // ⌊log2(1e5)⌋ = 16，j 需到 16

int n, a[N], st[N][LOG], lg[N];

void build(){
  for(int i=1; i<=n; i++) st[i][0] = a[i];
  for(int j=1; j<LOG; j++)
    for(int i=1; i + (1<<j) - 1 <= n; i++)
      st[i][j] = min(st[i][j-1],
                    st[i + (1<<(j-1))][j-1]);
}

int query(int l, int r){
  int k = lg[r - l + 1];
  return min(st[l][k], st[r - (1<<k) + 1][k]);
}
MAIN
lg[0]=-1; for(i=1;i<=n;i++) lg[i]=lg[i>>1]+1; build();
READ THE CODE三处细节
循环边界
i + 2^j − 1 ≤ n，越界必须挡住
j 从 1 起
j=0 就是原数组，已在前面赋值
数组大小
LOG ≥ ⌊log₂ n⌋ + 1
THREE MISTAKES最容易写错的三行
  • 循环条件写成 i <= n，末尾几行越界读
  • r − (1<<k) + 1 漏了 +1，起点算错一格
  • LOG 取 16，n = 10⁵ 时越界
SWAP THE OP换运算只改一行

把 min 换成 max / __gcd / (a|b) / (a&b)， 整个结构完全不变。这就是 ST 表的通用性。

模板代码 Python

同一套逻辑，注意 Python 的 bit_length() 正好对应 ⌊log₂⌋ + 1。

PYTHON · 静态区间最小值
import sys

def build(a):
    n = len(a) - 1                 # a 从下标 1 起
    K = n.bit_length()              # = ⌊log2(n)⌋ + 1
    st = [0] * (n + 1)
    for i in range(1, n + 1):
        st[i] = [0] * K
        st[i][0] = a[i]

    for j in range(1, K):
        for i in range(1, n - (1 << j) + 2):
            st[i][j] = min(st[i][j-1],
                           st[i + (1 << (j-1))][j-1])
    return st

def query(st, l, r):
    k = (r - l + 1).bit_length() - 1
    return min(st[l][k],
                st[r - (1 << k) + 1][k])

七个最常见的坑

ST 表本身不难，难的是把这些细节全做对。

WRONG写错就挂的四处
  • 用 区间和 / 区间异或 套 ST 表

  • 先预处理 lg[] 数组，查询纯查表
  • LOG 常量按 20 / 25 给足余量
