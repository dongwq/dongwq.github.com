三个操作

除此之外没有别的动作。查询 same(a,b) 只是 find 的组合。

OP 01make_set(x)

把 x 放进一个只含自己的集合。

OP 02find(x)

返回 x 所在集合的代表元。

OP 03union(a, b)

先各找根，再挂根。不是把 a 挂到 b。

same(a, b) = ( find(a) == find(b) )
并查集不保存成员列表，只保存「谁的父节点是谁」，成员靠 find 现算。

06

find：一直往上走

从 x 出发，只要 parent[x] ≠ x 就往上跳。走到头就是根。

FIG.06 · find(3) 的完整过程
PSEUDOCODE · NAIVE FIND
function find(x)
    while parent[x] != x
        x = parent[x]        # 往上跳一格
    return x               # 走到头，就是根
COST代价

走了多少步 = 这个节点的深度，也就是树有多高。

NOTE注意

路径上的每个节点都顺路经过了。这句话是「路径压缩」的伏笔。

07

union：先找根，再挂根

合并的是两个集合，所以要挂的是两个根，不是随便两个节点。

FIG.07 · union(2, 6) 的前后对照
PSEUDOCODE · UNION
function union(a, b)
    ra = find(a)         # 各自找根
    rb = find(b)
    if ra == rb: return  # 已同组
    parent[rb] = ra      # 根挂到根
COMMON MISTAKE常见错误

写成 parent[a] = b。这是把 a 挂到 b 上， 如果 a 原本有子树，整棵子树的归属就被搞乱了。

10

优化二：路径压缩

find 的路上，顺手把路径上每个节点直接挂到根上。下一次再找，就是一步。

SIGNATURE DEMO · 点击播放
find(4)：4 步 → 1 步
FIG.10 · 五个节点从一条链被压成一颗星
PSEUDOCODE · PATH COMPRESSION
function find(x)
    if parent[x] != x
        parent[x] = find(parent[x])
    return parent[x]
ONE LINE一句话

走过的每个点，都直连根。递归返回时改写 parent[]， 代价一次遍历，收益永久。

路径减半
parent[x] = parent[parent[x]]，只跳一半
路径分裂
每个点直接指向祖父，效果接近压缩

合体：O(α(n))

两个优化同时用，复杂度掉进反阿克曼函数——实际等同常数。

朴素NAIVE
O(m · n)m 次 find 最坏 m×n
按秩合并BY RANK
O(m · log n)树高 ≤ log n
按秩 + 压缩RANK + COMPRESS
O(m · α(n))实际就是常数
TAB.11 · 约数；n 涨到 10^80（宇宙原子数），树高也只到 5
FORMULA公式
m 次 find ≈ O( m · α(n) )

α(n) 是反阿克曼函数，增长慢到「宇宙级」，任何现实规模下 α(n) ≤ 4。

PRACTICE工程结论

直接把 find / union 当 O(1) 用，整个算法的复杂度就变成 读入数据本身的复杂度。

记不住就记：该合并就合并，该找根就找根，剩下的交给压缩。

模板代码

背下来即可。比赛 / 面试里逐字默写，不要现场发挥。

C++ · 按秩合并 + 路径压缩
int fa[N], rnk[N];

void init(int n) {
  for (int i=1; i<=n; i++) fa[i]=i, rnk[i]=0;
}
int find(int x) {
  return fa[x]==x ? x : fa[x]=find(fa[x]);  // 压缩
}
void merge(int a, int b) {
  int ra=find(a), rb=find(b);
  if (ra==rb) return;
  if (rnk[ra]<rnk[rb]) swap(ra,rb);
  fa[rb]=ra;
  if (rnk[ra]==rnk[rb]) rnk[ra]++;
}
SIZE
想统计人数，再开 sz[]，查询用 sz[find(x)]
PYTHON · 迭代写法（递归版可能爆栈）
fa = list(range(n + 1)); rnk = [0] * (n + 1)

def find(x):
    while fa[x] != x:
        fa[x] = fa[fa[x]]      # 路径减半
        x = fa[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb: return
    if rnk[ra] < rnk[rb]: ra, rb = rb, ra
    fa[rb] = ra
    if rnk[ra] == rnk[rb]: rnk[ra] += 1
COUNT
想数集合个数，cnt = n，真正合并成功才 cnt -= 1

解题套路 与 常见坑

拿到题先跑这五步；写完再对照右边四个坑检查一遍。

SOLVING ROUTINE五步套路
  1. 题目出现「连通 / 同类 / 合并 / 分组」，先想并查集。
  2. 确定元素编号范围，init(n) 一次。
  3. 每条关系 = 一次 union。
  4. 每个询问 = 一次 find。
  5. 需要统计时，加 sz[] 或最后数根。
PITFALLS四个最常见的坑
  • 忘了 init，parent[] 里是垃圾值。
  • 合并写成 parent[a] = b，没挂根。
  • 不写路径压缩，链状数据直接 TLE。
  • 下标 0 / 1 混用，编号和数组长度对不上。
