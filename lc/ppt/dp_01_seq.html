01
DP 是什么？—— 爬楼梯引入
总原则
DP 不是背公式，而是回答四个问题：

① 状态定义

dp[i] 表示什么？

② 状态转移

dp[i] 怎么从前面的状态得到？

③ 初始化

最开始几个状态是什么？

④ 遍历顺序

从前往后还是反向？

爬楼梯问题

楼梯：0 → 1 → 2 → 3 → 4 → 5
每次走 1 步或 2 步
问：走到第 5 层有多少种方法？

关键观察

5
↙ ↘
3   4
dp[5] = dp[3] + dp[4]
DP = 状态 + 状态转移 + 记忆已经计算过的结果。 把大问题拆成小问题，保存小问题答案，避免重复计算。

03
一维线性 DP：爬楼梯 & 打家劫舍
经典模型

爬楼梯 (LeetCode 70)

状态定义dp[i] = 爬到第 i 阶的方法数
最后一步从 i-1 走 1 步，或从 i-2 走 2 步
转移方程dp[i] = dp[i-1] + dp[i-2]
初始化dp[1] = 1, dp[2] = 2
遍历顺序从前往后
i：  1  2  3  4  5
dp： 1  2  3  5  8

打家劫舍 (LeetCode 198)

房子：[2] [7] [9] [3] [1]
相邻不能同时偷，问最多偷多少？
状态定义dp[i] = 考虑前 i 个房子最多偷的钱
不偷dp[i-1]
偷dp[i-2] + nums[i]
转移方程dp[i] = max(dp[i-1], dp[i-2] + nums[i])
典型的选择决策：偷或不偷。
04
一维 DP 的共同结构 & 识别信号
模式识别

共同结构

当前问题 │ ┌────────┴────────┐ ↓ ↓ 之前的状态 之前的状态 │ │ └────────┬────────┘ ↓ dp[i]

识别信号

看到以下组合，考虑一维 DP：
数组 当前位置 i 前面状态影响后面 最大 / 最小 / 方案数
常见形式
dp[i] = dp[i-1] + dp[i-2]
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
dp[i] = min(dp[i-1], dp[i-2] + cost[i])
05
0/1 背包：模型 & 转移方程
第二类模型

问题模型

背包容量 W = 4
物品：
① 重量 2，价值 3
② 重量 1，价值 2
③ 重量 3，价值 4
每个物品最多选一次，最大价值？
每个物品只有两个选择： 0 = 不选 / 1 = 选

二维 DP 定义

状态dp[i][j] = 只考虑前 i 个物品，容量为 j 时的最大价值
不选dp[i-1][j]
选dp[i-1][j-w[i]] + v[i]
转移方程：
dp[i][j] = max(
  dp[i-1][j],
  dp[i-1][j-w[i]] + v[i]
)

07
一维优化 & 容量从大到小（重点坑）
滚动数组

空间压缩

转移只依赖上一行：
dp[i][j] = max(dp[i-1][j],
              dp[i-1][j-w] + v)
压缩为：dp[j]
空间：O(nW) → O(W)

关键坑：容量必须从大到小

for each item:
    for (int j = W; j >= weight; j--)
        dp[j] = max(dp[j],
                    dp[j-weight] + value);
从小到大：本轮更新的 dp[j-weight] 可能被再次使用 → 同一物品被重复选择。
从大到小：使用的永远是上一轮的旧值 → 保证每个物品只用一次。
0/1 背包一维写法：容量从大到小遍历。

两类 DP 对比 & 判断 DP 三问
总结与识别
对比项一维线性 DP0/1 背包
状态dp[i]dp[i][j] → 优化 dp[j]
维度一维二维 → 一维
关键前 i 个位置前 i 个物品 + 容量 j
选择通常无显式选择不选 / 选

① 大问题能拆吗？

dp[5] ← dp[4], dp[3]

② 最优子结构？

小问题最优解 → 大问题最优解

③ 重复计算？

暴力递归中同一子问题多次出现

最终总结 & 5 分钟 PPT 结构
收尾
🎯 核心思维
先定义“我要求的答案”是什么，再想这个答案怎么从更小的问题得到。
不要把 DP 当成一堆需要背诵的公式。
真正应该掌握的是：“这个 dp[i] 到底代表什么？”

DP 四步法

1 定义状态 ↓ 2 状态转移 ↓ 3 初始化 ↓ 4 遍历顺序 ↓ 答案
