02
起点：暴力递归
0/1 背包

问题定义

物品 i：重量 w[i]，价值 v[i]
背包容量 W
每个物品：选 / 不选
dfs(i, cap) = 从第 i 个物品开始，剩余容量 cap，能获得的最大价值

状态转移

dfs(i, cap) = max(
    dfs(i + 1, cap),                // 不选
    v[i] + dfs(i + 1, cap - w[i])   // 选
)
dfs(0, W) / \ 不选 0 选 0 / \ dfs(1, W) dfs(1, W-w[0]) / \ / \ ... ... ... ...
问题：dfs(5, 10) 可能从不同路径反复计算 → 重叠子问题。
03
记忆化搜索：递归 + 缓存
Top-Down DP

核心思想

memo[i][cap] = dfs(i, cap) 的答案 
fn dfs(i, cap):
    if 已经计算:
        return memo[i][cap]

    ans = dfs(i + 1, cap)          // 不选
    if cap >= w[i]:
        ans = max(ans, v[i] + dfs(i + 1, cap - w[i]))

    memo[i][cap] = ans
    return ans

优缺点

接近原始思考过程
状态转移自然
容易从暴力递归推导
递归调用开销
可能栈溢出
不容易进一步优化空间
递归 + 缓存状态 = 记忆化搜索 = Top-Down DP
04
二维 DP：显式填表
自底向上

状态定义

dp[i][j] = 考虑前 i 个物品，容量为 j 时的最优答案
dp[i][j] = max(
  dp[i-1][j],            // 不选
  dp[i-1][j-w[i]] + v[i]  // 选
)

依赖关系

dp[i][j] / \ 不选 选 │ │ ↓ ↓ dp[i-1][j] dp[i-1][j-w[i]] + v[i]
当前行只依赖上一行。
05
一维压缩：为什么只依赖上一行
滚动数组

空间压缩

计算第 i 行只依赖第 i-1 行：
dp[i][j] ← dp[i-1][j]
         ← dp[i-1][j-w]
所以只用一个 dp[j]：
二维 dp[i][j] → 一维 dp[j]
空间 O(NW) → O(W)

直观理解

上一行： 0 1 2 3 4 5 ─────────────── 当前行： 0 1 2 3 4 5 不需要保存所有历史行 只需要一个 dp[j]
这就是 滚动数组 / 一维状态压缩。
06
关键坑：0/1 为什么必须倒序
核心语义

正序（错误）

物品重量 2，价值 3，容量 4 
开始：dp = [0, 0, 0, 0, 0]

j = 2: dp[2] = dp[0] + 3 = 3
       → [0, 0, 3, 0, 0]

j = 4: dp[4] = dp[2] + 3 = 6
       dp[2] 已是当前物品更新后的值
       等于同一个物品用了两次！

倒序（正确）

for j = W down to w:
    dp[j] = max(dp[j], dp[j-w] + v)
容量：W → W-1 → W-2 → ... → w ← ← ← ← ← ← ← ← ←
0/1 背包：倒序，因为每个物品只能用一次。

08
0/1 vs 完全：同一个公式，不同方向
核心对比
类型每件物品容量遍历dp[j-w] 含义
0/1 背包 0 次或 1 次 倒序 上一轮物品的状态
完全背包 无限次 正序 当前物品已使用的状态

0/1 背包

for item:
    for j = W down to w:
        dp[j] = max(dp[j], dp[j-w] + v)
倒序 = 当前物品不能重复使用

完全背包

for item:
    for j = w to W:
        dp[j] = max(dp[j], dp[j-w] + v)
正序 = 当前物品可以重复使用
同一个公式，不同的遍历顺序，决定了 dp[j-w] 的语义。
09
多重背包：二进制拆分
有限次数

问题定义

第 i 个物品最多使用 c[i] 次。
例如：A 最多 3 个，B 最多 5 个，C 最多 2 个。
最朴素：枚举使用 0 个、1 个、…、c 个。

二进制优化

13 个 → 拆成 1 + 2 + 4 + 6
可组合出 0~13 任意数量。
13 个相同物品 ↓ 二进制拆分 4 个“新物品”（1,2,4,6） ↓ 每个只能选一次 使用 0/1 背包
倍增思想：1, 2, 4, 8, ... 通过二进制分组降低复杂度。
10
目标变化：最大 / 最小 / 可行 / 方案数
同一背包，不同问题
目标状态定义转移初始化
最大值 容量 ≤ j 的最大价值 max(dp[j], dp[j-w]+v) dp[j]=0
最小值 凑出 j 的最少数量 min(dp[j], dp[j-w]+1) dp[0]=0, 其他=INF
可行性 是否能凑出 j dp[j] OR dp[j-w] dp[0]=true
方案数 凑出 j 的方案数 dp[j] += dp[j-w] dp[0]=1

为什么 dp[0]=1？

什么都不选，凑出 0，本身是一种方案。

典型题目

322 零钱兑换（最小值）
416 分割等和子集（可行性）
518 零钱兑换 II（方案数）
11
方案数坑：组合 vs 排列 & 递归统一理解
循环语义

组合 vs 排列

硬币 [1, 2]，目标 3：
不考虑顺序：1+1+1, 1+2 → 2 种（组合）
考虑顺序：1+1+1, 1+2, 2+1 → 3 种（排列）
组合物品在外，容量在内
排列容量在外，物品在内

从递归统一理解

0/1dfs(i+1, cap-w)以后不能用
完全dfs(i, cap-w)还能继续用
多重dfs(i, cap, remain)还需知道剩多少
分组dfs(group+1, cap)进入下一组
最底层的区别是：选择当前物品后，状态如何变化？
