01
Python → C++，到底要转换什么？
总原则
不是重新学算法，也不是系统学 C++，而是把 Python 算法思维映射到 C++ 高频工具上。

推荐路线

语法映射 ↓ 容器映射 ↓ 算法库 ↓ 语言机制 ↓ 性能意识 ↓ 代码模板

不推荐路线

C++ 基础语法 → 面向对象 → 类/继承/模板 → STL → 算法
太慢，容易消耗耐心，且偏离算法竞赛目标。
核心目标：看到算法题，能自然用 C++ 表达 Python 算法思想。

04
核心容器：vector / map / set
STL 基石

📦 list → vector

a.append(4) → a.push_back(4)
a.pop() → a.pop_back()
len(a) → a.size()
sort(a) → sort(a.begin(), a.end())
begin(), end() 表示整个数组

🗺️ dict → map / unordered_map

cnt = {} → unordered_map<int,int> cnt;
cnt[x] += 1 → cnt[x]++;
if x in cnt → if (cnt.count(x))
遍历 → for (auto [k,v] : cnt)
只查哈希 → unordered_map；有序 → map

🔷 set → set / unordered_set

s = set() → unordered_set<int> s;
s.add(x) → s.insert(x);
if x in s → if (s.count(x))
只关心有没有 → unordered_set；有序 → set
选择原则：需要顺序用有序版本，只查存在用无序版本（平均 O(1)）。

算法库：sort / lower_bound
algorithm 头文件

Python

a.sort()

a.sort(key=lambda x: x[1])

bisect_left(a, x)
bisect_right(a, x)

C++

sort(a.begin(), a.end());

sort(a.begin(), a.end(),
     [](const auto& x, const auto& y) {
         return x.second < y.second;
     });

lower_bound(a.begin(), a.end(), x)
upper_bound(a.begin(), a.end(), x)
迭代器转下标： int pos = lower_bound(a.begin(), a.end(), x) - a.begin();
lambda 就是“告诉 sort 两个元素怎么比较”，不要怕。
07
C++ 特有重点：引用 / 溢出 / 快速 IO
必须补的差异

🔗 引用 &

Python 默认传引用，C++ 默认传值。
void add(vector<int>& a) 修改原对象
void solve(const vector<int>& a) 只读不复制

⚠️ 整数溢出

int ≈ 2×10⁹
long long ≈ 9×10¹⁸
安全乘法：1LL * a * b

⚡ 快速 IO

ios::sync_with_stdio(false);
cin.tie(nullptr);
加速 cin/cout

❌ 危险写法

int a = 100000, b = 100000;
long long ans = a * b; // 可能溢出

✅ 安全写法

long long ans = 1LL * a * b;
08
性能意识 & 同题双写
最有效学习法

性能意识

  • 同样 O(N²)，C++ 常数更小
  • 但复杂度仍是第一决定因素
  • C++ 优化常数，不能改变复杂度
算法复杂度第一，C++ 加速是辅助。

同题双写流程

1. Python 已经会的题 ↓ 2. 用 C++ 重写 ↓ 3. 遇到不会的语法，只学这个语法 ↓ 4. 继续做题
Two Sum 示例

Python

def two_sum(nums, target):
    pos = {}
    for i, x in enumerate(nums):
        if target - x in pos:
            return [pos[target - x], i]
        pos[x] = i

C++

vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> pos;
    for (int i = 0; i < nums.size(); i++) {
        int x = nums[i];
        if (pos.count(target - x)) {
            return {pos[target - x], i};
        }
        pos[x] = i;
    }
    return {};
}
算法思想不变，变的只是容器、循环、类型、语法。
